# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) screening model for poor compaction along the foundation or
abutment contact in the System Response library. The model computes a system response probability (SRP) as a function of headwater elevation for
concentrated leak erosion through a zone of poorly compacted embankment fill placed against the foundation or an abutment. It is a screening-level
model: it applies simplifications intended to reduce input burden while avoiding false negatives, and any application that performs
screening-level risk analysis can use it.

The model is one of eight CLE screening models that share one event tree, one flaw-scoring scheme, one initiation analysis for compaction flaws,
and one set of failure-pathway and progression rules. Those common methods are documented once, in the
[Concentrated Leak Erosion Common Methods Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/preface),
and the continuation node is evaluated by the shared method of the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/preface).
This manual documents only what is specific to the foundation or abutment compaction mechanism — its flaw, its inputs, where it departs from the
common event tree, and its assumptions — and refers to the specific chapters of the two shared manuals for the rest.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is required.

- **[Model Overview](./02-model-overview.mdx)** — The model's purpose and intended use, a summary of its execution pathway, its engineering basis,

- **[Input Parameters](./03-input-parameters.mdx)** — The inputs specific to the mechanism: the choice between a foundation and an abutment

- **[Flaw Assessment](./04-flaw-assessment.mdx)** — The base-of-flaw elevation, the three scored factors and their likelihood factors, the

  probabilities.
- **[Event Tree](./05-event-tree.mdx)** — How the model populates each of the eight nodes, where it follows and where it departs from the common
  tree, and how the SRP is computed.
- **[Assumptions and Limitations](./06-assumptions-and-limitations.mdx)** — Each assumption specific to the mechanism, with its engineering
  basis, its effect on results, and the conditions under which it may not hold.
- **[Output and Interpretation](./07-output-and-interpretation.mdx)** — The flaw-assessment results the model reports, how they bound the system
  response curve, and how to read and check a result.
