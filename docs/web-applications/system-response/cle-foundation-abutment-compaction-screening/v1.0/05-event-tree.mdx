# Event Tree

The model evaluates the eight-node event tree shared by the CLE screening models, documented in the
[Event Tree](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/event-tree) chapter of the common methods manual. It is a
compaction model: the flaw sits at one elevation, so only initiation varies with pool level and every other node is the same at every pool level
(see [Pool Dependence](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/event-tree#pool-dependence)). The tree is
evaluated at every supplied headwater value and at the intermediate pool levels described in
[Headwater Grid](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/event-tree#headwater-grid).

<TableReference tableKey="cle-foundation-abutment-screening-table-12" /> summarizes how the model populates each node. The sections that follow
state the question each node answers, link the section of the shared manuals that documents it, and note what is specific to this mechanism.

## Node 1: Flaw

*Question:* Does a continuous zone of poorly compacted fill exist along the foundation or abutment contact?

The flaw probability $P_{flaw}$ is the result of the flaw assessment documented in [Flaw Assessment](./04-flaw-assessment.mdx). It is the same at
every pool level, never exceeds about 5.6 × 10<sup>-3</sup>, and is negligible for a well-prepared surface or for special compaction methods with
good documentation.

## Node 2: Initiation

*Question:* At each pool level, does the flow through a pipe of initial diameter $D$ at the base of the flaw exert a hydraulic shear stress on the
pipe wall that exceeds the critical shear stress $\tau_c$ assigned through the core soil classification?

The model hands the question to the cylindrical-pipe initiation analysis shared by the four compaction models, documented in
[Delegated Method: Cylindrical Pipe Initiation](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/initiation#delegated-method-cylindrical-pipe-initiation)
in the common methods manual. The analysis computes the heads above the pipe invert, the hydraulic gradient along the seepage path, and the shear
stress on the pipe wall, and reports the fraction of Monte Carlo realizations of $\tau_c$ and $D$ in which the shear stress exceeds the critical
shear stress, which is the initiation probability $P_{init}(h)$ at pool level $h$. This model supplies to it:

- **The pipe invert** — the base of the flaw $z_f$ of
  [Base-of-Flaw Elevation](./04-flaw-assessment.mdx#base-of-flaw-elevation): the embankment–foundation contact for a foundation flaw, or the
  normal-pool heuristic elevation for an abutment flaw. Initiation is zero, and the SRP negligible, at pool levels at or below it.
- **The seepage path length** — unless the user supplies it, the horizontal length through the section at $z_f$ (see
  [Seepage path length](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/initiation#seepage-path-length) in the common
  methods manual). For a foundation flaw whose contact elevation is the lowest segment bottom of the section, this is the full base width of the
  section; an abutment flaw, higher in the section, has a shorter path and so a steeper gradient for the same net head.
- **The critical shear stress** — the default range for the core soil classification, or the user's distribution (see
  [Critical shear stress](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/initiation#critical-shear-stress) in the
  common methods manual). One soil is classified for the pipe wall, although the pipe lies against both the contact-zone fill and the
  foundation or abutment surface; which soil the classification describes is requested at marker IN-14 in
  [Initiation Default](./03-input-parameters.mdx#initiation-default). The clean and nearly clean sand and gravel classes are not accepted as the
  classification, even when the user supplies a critical shear stress distribution in place of the default range, so a contact whose erodible
  material is a clean sand or gravel cannot be represented by its own classification.
- **The initial pipe diameter** — the model's default triangular distribution of 2, 3, and 5 mm, or the user's distribution (see
  [Initiation Default](./03-input-parameters.mdx#initiation-default)).

The screening-level adjustments to the toolbox method are those common to the compaction models (see
[Screening-level adjustments](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/initiation#screening-level-adjustments)
in the common methods manual); the model makes none of its own.

## Node 3: Continuation

*Question:* Does an unfiltered exit allow erosion along the contact to continue?

Continuation is one value at every pool level, set by the filter-presence selection (see
[Filter Presence and Continuation](./03-input-parameters.mdx#filter-presence-and-continuation)):

<Equation
  equationKey="cle-foundation-abutment-screening-eq-5"
  equation="P_{cont} = \begin{cases} P_{ce} & \text{a filter intercepts the pathway at the contact} \\[4pt] 1.0 & \text{no filter} \end{cases}"
/>

where $P_{ce}$ is the probability of continuing erosion computed by the shared continuation method from the filter and base-soil description: the
largest probability over the base soils the filter protects (see
[Governing Base Soil](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/method-selection-and-governing-base-soil#governing-base-soil)
and [Node Result](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/output-and-interpretation#node-result) in the continuation
manual). When no filter is present, the continuation method is not evaluated. Filter presence is stated by the user and is not compared with the
base-of-flaw elevation (see
[Node 3: Continuation](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/failure-pathway-and-progression#node-3-continuation)
in the common methods manual).

## Node 4: Progression — Roof Support

*Question:* Does the material over the enlarging pipe hold a roof, so that the pipe stays open?

The roof-support probability $P_{roof}$ is the minimum over the embankment materials the pipe passes through, read from the table of
[Node 4: Progression — Roof Support](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/failure-pathway-and-progression#node-4-progression--roof-support)
in the common methods manual. Only the materials the user lists enter the minimum; the model does not add the foundation material to them.

:::warning[INPUT NEEDED IN-13 — Applicability]
State which materials the user should list for a pipe along the foundation or abutment contact. The pipe lies between the embankment fill and the
foundation or abutment, so its roof may be the contact-zone fill, while an erodible soil foundation forms its floor. State whether the foundation
soil (for a soil foundation) should be listed with the fill, and whether only the contact-zone fill or every embankment zone the contact passes
beneath should be listed.
:::

## Node 5: Progression — No Crack Filling

*Question:* Does the enlarging pipe remain unfilled by material from upstream?

The probability $P_{nf}$ is read from the embankment type, as documented in
[Node 5: Progression — No Crack Filling](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/failure-pathway-and-progression#node-5-progression--no-crack-filling)
in the common methods manual.

## Node 6: Progression — No Flow Limitation

*Question:* Does the flow into the enlarging pipe remain unrestricted by upstream seepage-limiting elements?

The probability $P_{nl}$ is the minimum over the applicable upstream elements, with the walls gated once against the base of the flaw, as for every
compaction model except conduit compaction (see
[Walls that stop below the crest](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/failure-pathway-and-progression#walls-that-stop-below-the-crest)
in the common methods manual):

- When no top-of-wall elevation $z_{tw}$ is given, or $z_{tw} \ge z_f$, every listed element applies.
- When $z_{tw} < z_f$, the walls drop out and only an upstream facing element, if listed, applies.

For a foundation flaw the comparison is with the contact elevation, so a cutoff wall rising from the foundation to any height above the contact
applies. For an abutment flaw the comparison is with the heuristic elevation above normal pool, so a wall whose top lies below that elevation gives
no credit.

## Nodes 7 and 8: Unsuccessful Intervention and Breach

*Questions:* Do detection and intervention fail (Node 7)? Does an uncontrolled release of impounded water occur (Node 8)?

The user-specified probabilities $P_{int}$ and $P_{br}$, each one value at every pool level and each defaulting to 1.0, as documented in
[Nodes 7 and 8](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/event-tree#nodes-7-and-8-unsuccessful-intervention-and-breach)
in the common methods manual.

## SRP Computation

The SRP at each pool level $h$ is the product of the eight nodes (see
[SRP Computation](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/event-tree#srp-computation) in the common methods
manual). In this model only initiation varies with pool level, so the SRP is the initiation curve scaled by one constant:

<Equation
  equationKey="cle-foundation-abutment-screening-eq-6"
  equation="\mathrm{SRP}(h) = P_{init}(h) \times \bigl(P_{flaw} \times P_{cont} \times P_{roof} \times P_{nf} \times P_{nl} \times P_{int} \times P_{br}\bigr)"
/>

Where the product is zero, or smaller than the negligible value, the SRP is reported as the negligible value.
