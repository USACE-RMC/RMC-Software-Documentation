# Event Tree

The concentrated leak erosion (CLE) wall or cliff compaction model evaluates the eight-node event tree shared by every CLE screening model, documented in
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="event-tree">Event Tree</DocLink> in the CLE Common Methods manual, at every pool
level of the headwater grid described there. This chapter documents how the wall or cliff compaction model populates each node. Because the flaw
sits at one elevation, the base of the flaw $z_f$, only the initiation node varies with pool level; the other seven nodes are the same at every pool
level (see <DocLink doc="web-applications/system-response/cle-common-methods-screening" page="event-tree" anchor="pool-dependence">Pool Dependence</DocLink>).

## Node 1: Flaw

*Question:* Does a continuous zone of poorly compacted fill exist along the wall or cliff, through the embankment?

The flaw probability $P_{flaw}$ is the result of the assessment documented in [Flaw Assessment](./04-flaw-assessment.mdx): the raw flaw probability
from the weighted sum of the three factor scores, multiplied by the flaw-continuity probability, or 1.0 when leakage adjacent to the wall is
reported.

## Node 2: Initiation

*Question:* At each pool level, does the flow through a pipe of initial diameter $D$ at the base of the flaw exert a hydraulic shear
stress on the pipe wall that exceeds the critical shear stress $\tau_c$ of the fill against the wall?

The model hands this question to the cylindrical-pipe initiation analysis documented in
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="initiation" anchor="delegated-method-cylindrical-pipe-initiation">Delegated Method: Cylindrical Pipe Initiation</DocLink>
in the CLE Common Methods manual, whose theory is in the
[Cylindrical Pipe](/docs/toolbox-technical-manuals/internal-erosion-suite/concentrated-leak-erosion-initiation/v1.0/cylindrical-pipe) chapter
of the Concentrated Leak Erosion Initiation manual. The initiation probability $P_{init}(h)$ at each pool level is the fraction of Monte Carlo
realizations in which the shear stress exceeds the critical shear stress. The model supplies the analysis with:

- **Pipe invert** — the base of the flaw, $z_f = z_c - h_w$ (see [Flaw Assessment](./04-flaw-assessment.mdx#base-of-flaw-elevation)). At pool levels at
  or below it, initiation is zero.
- **Hydraulic loading** — each pool level and its tailwater, which together set the net head across the pipe.
- **Seepage path length** — the supplied length, or else the length of a horizontal line at $z_f$ across the core section when one is
  supplied and across the shell section otherwise, as documented in
  <DocLink doc="web-applications/system-response/cle-common-methods-screening" page="initiation" anchor="seepage-path-length">Seepage Path Length</DocLink>. The same length
  applies at every pool level.
- **Critical shear stress** — the supplied distribution, or else the triangular distribution for the core soil classification documented in
  <DocLink doc="web-applications/system-response/cle-common-methods-screening" page="initiation" anchor="critical-shear-stress">Critical Shear Stress</DocLink>. Whether or
  not a critical shear stress distribution is supplied, the clean and nearly clean sands and gravels are not accepted as the soil of the fill
  against the wall.
- **Initial pipe diameter** — the supplied distribution, or else this model's default triangular distribution, described below.

The default initial pipe diameter is a triangular distribution with a low value of 5 mm, a most likely value of 5 mm, and a high value of 10 mm.
Because its most likely value equals its low value, the probability density is greatest at 5 mm and falls linearly to zero at 10 mm, and the mean
diameter is

<EquationNoRef equation="\bar{D} = \frac{5 + 5 + 10}{3} \approx 6.7\ \text{mm}" />

The default is listed with the defaults of the other compaction models in
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="initiation" anchor="initial-pipe-diameter">Initial Pipe Diameter</DocLink>
in the CLE Common Methods manual, where the engineering basis of every default range is requested.
The shape of the distribution places most realizations near 5 mm. Because the shear stress is proportional to the diameter, those smaller pipes
need a higher pool to initiate than pipes near 10 mm. A site-specific distribution replaces the default.

The screening-level adjustments the compaction models make to the toolbox method — the cylindrical-pipe geometry only, the probabilistic analysis
always, and the default distributions and derived seepage path length — apply unchanged (see
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="initiation" anchor="screening-level-adjustments">Screening-Level Adjustments</DocLink>).

## Node 3: Continuation

*Question:* Where a filter intersects the failure pathway at the base of the flaw, does erosion continue past it?

When a filter is stated to intersect the flaw, the continuation probability $P_{cont}$ is the probability of continuing erosion $P_{ce}$, the node
result of the Continuation (Filter Evaluation) Screening model (written $P_{cont}$ in that manual), computed from the filter and base-soil
description (see
<DocLink doc="web-applications/system-response/continuation-screening" page="output-and-interpretation" anchor="node-result">Node Result</DocLink>
in that manual). The continuation method selects the evaluation method the supplied information supports and the governing base soil, as documented
in <DocLink doc="web-applications/system-response/continuation-screening" page="method-selection-and-governing-base-soil">Method Selection and Governing Base Soil</DocLink>
in that manual. When no filter is stated, the exit is unfiltered, $P_{cont} = 1.0$, and the continuation method is not evaluated. The value is the
same at every pool level; this is the compaction-model form of the node documented in
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="failure-pathway-and-progression" anchor="node-3-continuation">Node 3: Continuation</DocLink>
in the CLE Common Methods manual. The model applies the continuation method's result without adjustment.

## Node 4: Progression — Roof Support

*Question:* Does the material over the enlarging pipe hold a roof, so that the pipe stays open?

The roof-support probability $P_{roof}$ is the minimum roof-support probability across the listed embankment materials, by the table of
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="failure-pathway-and-progression" anchor="node-4-progression--roof-support">Node 4: Progression — Roof Support</DocLink>
in the CLE Common Methods manual. It is the same at every pool level.

## Node 5: Progression — No Crack Filling

*Question:* Does the enlarging pipe remain unfilled by material carried in from upstream?

The probability of no crack filling $P_{nf}$ depends only on the embankment type, by the table of
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="failure-pathway-and-progression" anchor="node-5-progression--no-crack-filling">Node 5: Progression — No Crack Filling</DocLink>
in the CLE Common Methods manual.

## Node 6: Progression — No Flow Limitation

*Question:* Does the flow into the enlarging pipe remain unrestricted by upstream seepage-limiting elements?

The probability of no flow limitation $P_{nl}$ is the probability of the upstream facing element times that of the governing cutoff wall (the most
effective of the walls listed), counting only the elements that reach the flaw; an element that is absent or does not reach the flaw contributes
1.0, so $P_{nl}$ is 1.0 when none is listed. The values come from the table of
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="failure-pathway-and-progression" anchor="node-6-progression--no-flow-limitation">Node 6: Progression — No Flow Limitation</DocLink>
in the CLE Common Methods manual. When a top-of-wall elevation $z_{tw}$ is supplied for an upstream cutoff wall, the cutoff wall is compared once with the
base of the flaw, as documented in
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="failure-pathway-and-progression" anchor="walls-that-stop-below-the-crest">Walls That Stop Below the Crest</DocLink>:

- When $z_{tw} \ge z_f$, the cutoff wall reaches the flaw and every listed element applies.
- When $z_{tw} < z_f$, the walls drop out and only an upstream facing element, if listed, still limits the flow.

Because $z_f = z_c - h_w$, a cutoff wall limits flow through the flaw only when its top reaches at least the foot of the wall or cliff. The result is
one value applied at every pool level.

## Nodes 7 and 8: Unsuccessful Intervention and Breach

*Questions:* Do detection and intervention fail (Node 7)? Does an uncontrolled release of impounded water occur (Node 8)?

The probabilities of unsuccessful intervention $P_{int}$ and of breach $P_{br}$ are the user-specified values documented in
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="input-parameters" anchor="intervention-and-breach">Intervention and Breach</DocLink>,
each applied at every pool level.

## SRP Computation

The system response probability (SRP) at each pool level $h$ is the product of the eight node probabilities of
<TableReference tableKey="cle-wall-cliff-compaction-screening-table-8" />, as documented in
<DocLink doc="web-applications/system-response/cle-common-methods-screening" page="event-tree" anchor="srp-computation">SRP Computation</DocLink>
in the CLE Common Methods manual. For this model, every node except initiation is the same at every pool level. The SRP is never reported below a
negligibly small floor: wherever the product falls below that floor — including where it is zero, at pool levels at or below the base of the flaw —
the SRP is reported at the floor instead. Mechanically compacted fill slightly wet of optimum always gives a product below the floor, because its
negligible flaw-continuity probability sits at that floor before the other nodes multiply it (see
[Flaw-Continuity Stage](./04-flaw-assessment.mdx#flaw-continuity-stage)), so its SRP is the floor at every pool level.
