# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) wall or cliff compaction screening model in the System
Response library. The model computes a system response probability (SRP) as a function of headwater elevation for concentrated leak erosion
through a zone of poorly compacted fill placed against a wall or a cliff that the embankment abuts. It is a screening-level model: it applies simplifications intended to reduce input burden while avoiding false negatives,
and any application that performs screening-level risk analysis can use it.

The model is one of eight CLE screening models. All eight evaluate the same eight-node event tree, seven of the eight (all but cross-valley differential
settlement) share a scoring scheme for the probability of a flaw, and all eight share the treatment of initiation, continuation, and progression that their flaw geometry calls for. Those common methods are documented
once, in the
[CLE Common Methods Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/preface), and
the continuation node is evaluated by the shared method documented in the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/preface).
This manual documents what is specific to the wall or cliff compaction mechanism — its flaw, its inputs, how it populates each node of the common
event tree, and its assumptions — and links the chapter of the shared manuals that documents each common step.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is required.

- **[Flaw Assessment](./04-flaw-assessment.mdx)** — The scoring of the three flaw factors, the conversion of their weighted sum to a raw flaw

- **[Event Tree](./05-event-tree.mdx)** — How the model populates each of the eight nodes, including the cylindrical-pipe initiation analysis and
  the continuation method it delegates to, and how the SRP is computed.
- **[Assumptions and Limitations](./06-assumptions-and-limitations.mdx)** — Each assumption specific to this model with its engineering basis,
  its effect on results, and the conditions under which it may not hold.
- **[Output and Interpretation](./07-output-and-interpretation.mdx)** — The results the model produces, how to read the system response curve
  for this mechanism, which inputs shape it, and the role of screening results relative to detailed analysis.
