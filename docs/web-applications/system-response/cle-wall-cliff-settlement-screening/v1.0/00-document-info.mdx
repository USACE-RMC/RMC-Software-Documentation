reportAbstract: Technical reference documenting the concentrated leak erosion (CLE) wall or cliff settlement screening model in the System Response library. The model computes a system response probability (SRP) at each headwater level for concentrated leak erosion through a transverse crack opened near the crest by differential settlement of the embankment against a steep wall or cliff. The probability of a continuous crack is estimated by risk-factor and likelihood-factor scoring of three site factors (the ratio of the bench width to the wall or cliff height, the post-construction settlement ratio, and the abutment slope below the wall or cliff), and the crack depth is estimated from tabulated relationships for the effective wall height and the normalized crack depth. The crack depth sets the headwater level above which initiation is taken as certain. The remaining nodes of the eight-node event tree follow the methods shared by the concentrated leak erosion screening models, which are documented in a companion manual.
