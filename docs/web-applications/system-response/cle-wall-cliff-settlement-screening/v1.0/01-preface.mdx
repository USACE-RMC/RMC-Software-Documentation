# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) wall or cliff settlement screening model in the System
Response library. The model computes a system response probability (SRP) as a function of headwater elevation for concentrated leak erosion
through a transverse crack near the crest, opened by differential settlement of the embankment fill against a steep wall or cliff at an
abutment. It is a screening-level model: it applies simplifications intended to reduce input burden while avoiding false negatives, and any
application that performs screening-level risk analysis can use it.

The model is one of eight CLE screening models in the library. The eight share one event tree and most of its nodes. Those shared methods are
documented once, in the
[Concentrated Leak Erosion Common Methods Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/preface),
and the continuation node is evaluated by the shared method documented in the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/preface).
This manual documents what is specific to the wall or cliff settlement mechanism: its flaw assessment, which estimates both the probability of a
continuous crack and the depth of that crack, its inputs, and how it populates the shared event tree. Each shared method is referenced at the
chapter and section that documents it.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is required.
