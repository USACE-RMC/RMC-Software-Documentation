# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) conduit compaction screening model in the System Response
library. The model computes a system response probability (SRP) as a function of headwater elevation for concentrated leak erosion through a zone
of poorly compacted earthfill adjacent to a conduit that passes through an embankment. It is a screening-level model: it applies simplifications
intended to reduce input burden while avoiding false negatives, and any application that performs screening-level risk analysis can use it.

The model is one of eight CLE screening models. All eight share one event-tree structure and one set of failure-pathway and progression
conventions; seven of the eight share one scoring scheme for the flaw probability, and the four compaction models among them share one initiation
analysis. The exception to the shared scoring scheme is the cross-valley settlement model, which derives its flaw probability from settlement and
crack-strain relationships.
Those common methods are documented once, in the
[CLE Common Methods Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/preface). The
continuation node, where a filter is present, is evaluated by the shared continuation method documented in the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/preface).
This document covers what is specific to the conduit compaction model — the flaw and the four conduit factors that score it, the bottom-of-conduit
flaw elevation, the observation of leakage adjacent to the conduit, the diaphragm filter that gates continuation, the default initial pipe
diameter, the absence of a flow-limitation node, the assumptions specific to the mechanism, and the results the model reports — and cites the
specific chapters of those two manuals for the rest.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is required.
