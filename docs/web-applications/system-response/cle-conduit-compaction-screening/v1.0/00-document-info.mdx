reportAbstract: Technical reference documenting the concentrated leak erosion (CLE) conduit compaction screening model in the System Response library. The model computes a system response probability (SRP) at each headwater level for concentrated leak erosion through a zone of poorly compacted earthfill adjacent to a conduit through an embankment. The probability of a continuous flaw is estimated by risk-factor and likelihood-factor scoring of four conduit factors, namely the conduit type and surround, cutoff collars, the compaction of the fill adjacent to the conduit, and the conduit trench details, and an observation of leakage adjacent to the conduit can override it. The flaw is placed at the bottom of the conduit and idealized as a cylindrical pipe, for which the initiation probability is evaluated by Monte Carlo simulation. A diaphragm filter around the conduit, when present, is evaluated by the shared continuation method, and the progression, intervention, and breach nodes follow the conventions of the CLE screening family, with no credit taken for flow limitation by upstream elements. The methods shared with the other CLE screening models are documented in the CLE Common Methods Screening Technical Reference Manual.
