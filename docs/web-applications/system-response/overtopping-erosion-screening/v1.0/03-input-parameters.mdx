# Input Parameters

The user provides the embankment geometry, the embankment material (an erodibility classification or site-specific property distributions), the
grass cover condition on the downstream face and the overtopping duration at a reference depth. The hydraulic coefficients, the hydrograph shape, the
material property correlations and the erosion formulation have defaults that the user may change. The user also selects the unit system and the range
of overtopping depths over which the system response curve is evaluated.

## Unit System

The user selects the unit system for all dimensional inputs and results:

- **US Customary** — lengths in feet, stresses in pounds per square foot (psf), unit weights in pounds per cubic foot. This is the default.
- **SI** — lengths in meters, stresses in pascals (Pa), unit weights in newtons per cubic meter.

The unit system also selects the unit-dependent constants: the unit weight of water, the Manning's equation coefficient, the reference depth for
duration scaling ([Chapter 4](./04-hydrograph-generation.mdx)) and the minimum critical erosion depth ([Chapter 5](./05-erosion-model.mdx)). Default material property distributions are tabulated in US
Customary units and converted when SI is selected.

## Embankment Geometry

The model represents the embankment as a homogeneous section with a uniform downstream slope (Assumption 1 in [Chapter 7](./07-assumptions-and-limitations.mdx)).

- **Embankment height** $H_d$ — the height of the embankment from the downstream toe to the crest. The height is a required input but does not
  enter the erosion or breach calculation; the breach criterion depends only on the crest width and the downstream slope ([Chapter 5](./05-erosion-model.mdx)).
- **Downstream slope ratio** $Z$ — the horizontal distance per unit vertical rise of the downstream face; $Z = 3$ is a 3H:1V slope. The model works
  with the slope gradient $S = 1/Z$ (vertical over horizontal) in its erosion-phase equations (flow depth and shear stress), and with the slope angle
  $\theta = \arctan(S)$ in the grass cover phase (Assumption 13 in [Chapter 7](./07-assumptions-and-limitations.mdx)). Slopes steeper than 1H:1V are unusual for earth embankments and
  should be checked (engineering judgment; attribution pending, IN-16).
- **Crest width** $W_c$ — the width of the dam crest. Together with the downstream slope, it sets the critical erosion depth at which breach occurs
  ([Chapter 5](./05-erosion-model.mdx)).

Confirm how the document should present it: as a required descriptive input with no effect on results (as written above), or with an intended role
the model is expected to adopt.
:::

## Embankment Material

Material properties are not entered as single values. The model samples three properties for each Monte Carlo realization: the erodibility
coefficient $k_d$, the critical shear stress $\tau_c$ and Manning's roughness coefficient $n$ of the downstream face. Their distributions come from an
erodibility classification or from distributions supplied by the user.

### Erodibility Classification

The user selects one of the following classifications, each defined by Unified Soil Classification System (USCS) soil types and fines content (FC):

- **Very Erodible** — SP, SW, and SM with FC &lt; 30%.
- **Erodible** — SM with FC ≥ 30%, SC with FC &lt; 30%, ML, and SC-ML. This is the default.
- **Moderately Resistant** — SC with FC ≥ 30% and CL-ML.
- **Resistant** — MH, CL, and CL/CH.
- **Very Resistant** — CH.
- **Custom** — no default distributions; the user supplies distributions for all three properties (see Site-Specific Material Distributions below).

For the five standard classifications, $k_d$ and $\tau_c$ follow PERT (Program Evaluation and Review Technique) distributions defined by a minimum, most likely (mode) and maximum value, and $n$
follows a Uniform distribution between a minimum and a maximum. The mapping of soil types to erodibility categories and the $k_d$ and $\tau_c$
ranges follow the published erodibility charts and soil erodibility testing<Citation citationKey="Briaud2019" /><Citation citationKey="Hanson2011" /><Citation citationKey="Wibowo2018" />.

### Site-Specific Material Distributions

The user may replace the default distribution of any of the three properties with a site-specific distribution, for example one developed from jet
erosion tests or hole erosion tests on embankment samples<Citation citationKey="Wahl2008" />.

- With a **standard classification**, each supplied distribution replaces the default for that property alone; the other properties keep their
  classification defaults.
- With the **Custom** classification, distributions for all three properties are required.
- Each distribution may be a constant value, or a Uniform, Normal, Triangular or PERT distribution. Every value the distribution can produce must be
  positive, because the model accepts a distribution only if its samples, after any bounds are applied, cannot be zero or negative. A Uniform,
  Triangular or PERT distribution therefore needs a positive minimum or a positive lower bound, and a Normal distribution, which is unbounded below,
  needs a positive lower bound.
- Each distribution may carry an optional lower bound, upper bound, or both. A sample that falls outside the bounds is set to the nearest bound, so a
  bound concentrates probability at that value rather than reshaping the distribution.

Site-specific distributions are sampled within the same correlation structure as the defaults ([Chapter 6](./06-monte-carlo-simulation.mdx)).

## Grass Cover Condition

The user selects the condition of the grass cover on the downstream face. The condition sets the two parameters of the grass cover removal phase
([Chapter 5](./05-erosion-model.mdx)): the critical velocity $u_c$, the flow velocity above which grass damage begins, and the erosional limit $G_f$, the cumulative overflow
work that removes the cover. The categories and parameter values follow the CIRIA-based method for tolerable time-varying overflow on grass-covered
slopes<Citation citationKey="Hughes2015" /><Citation citationKey="Thornton2014" />.

- **No Grass Cover** — the soil is exposed from the onset of overtopping; the grass cover removal phase is skipped.
- **Poor Cover** — bare spots and shallow roots.
- **Average Cover** — moderate root depth.
- **Good Cover** — dense growth and deep roots. This is the default.
- **More Robust Cover** — reinforced grass or turf reinforcement mats; the same erosional limit as Good Cover with a higher critical velocity.

## Overtopping Duration and Hydrograph Shape

These inputs define the synthetic overtopping hydrograph at each overtopping depth ([Chapter 4](./04-hydrograph-generation.mdx)).

  tableKey="overtopping-screening-table-hydrograph"

  headers={[[{ value: 'Parameter' }, { value: 'Symbol' }, { value: 'Units' }, { value: 'Valid Range' }, { value: 'Default' }]]}
  columns={[

    ['4.0', '3.5'],

/>

- **Base duration** $t_0$ — the duration of overtopping at the reference depth of 0.5 ft (US Customary) or 0.15 m (SI). The model scales it to every
  other depth with a power law ([Chapter 4](./04-hydrograph-generation.mdx)). It is the main input controlling how long the embankment is exposed to overtopping flow, and the user
  should set it from the reservoir's expected overtopping behavior. Durations longer than one week (168 hours) are unusual and should be checked
  (engineering judgment; attribution pending, IN-16).
- **Hydrograph shape parameter** $a$ — the shape parameter of the gamma function that defines the hydrograph. Values greater than 1 give a
  hydrograph that rises to a single peak and recedes; the basis for the default is pending (IN-11, [Gamma Hydrograph Shape](./04-hydrograph-generation.mdx#gamma-hydrograph-shape) in Chapter 4).

:::warning[INPUT NEEDED IN-05 — Engineering Basis]
The default base duration $t_0$ = 4.0 hours at the reference depth has no stated engineering basis. Provide the literature source or the
engineering-judgment attribution for this default, or confirm that the document should present the base duration as a required site-specific input
with no recommended default.
:::

### Critical Shear Stress in the Erosion Equation

The user selects whether the erosion equation includes the critical shear stress:

- **Include** — the erosion rate is driven by the shear stress in excess of the critical shear stress, $\varepsilon = k_d \max(\tau - \tau_c, 0)^\alpha$.
  Erosion occurs only when the applied shear stress exceeds $\tau_c$. This is the default.
- **Exclude** — the critical shear stress is set to zero, $\varepsilon = k_d \tau^\alpha$. Erosion occurs at any non-zero applied shear stress, which
  produces equal or higher erosion rates than the Include option for the same sampled properties.

:::warning[INPUT NEEDED IN-08 — Applicability]
The document does not state when an engineer should choose to exclude the critical shear stress from the erosion equation. Provide the conditions
under which the Exclude option is appropriate (for example, a conservative bounding analysis, or materials whose critical shear stress is negligible or
poorly known) and the basis for that guidance.

Proposed (unconfirmed): the Overtopping Erosion Toolbox Notes state that, in the WinDAM C evaluation process, the critical shear stress is typically
conservatively assumed to be zero for efficiency.
:::

## Material Property Correlations

The three sampled material properties are correlated ([Chapter 6](./06-monte-carlo-simulation.mdx)). The user specifies two correlation coefficients; the third is implied.

  columns={[

    ['—', '—'],
    ['−1 &lt; ρ &lt; 1', '−1 &lt; ρ &lt; 1'],
    ['−0.6', '−0.2'],

/>

- A negative $\rho_{k_d,\tau_c}$ means that soils with a higher erodibility coefficient tend to have a lower critical shear stress.
- A negative $\rho_{\tau_c,n}$ means that soils with a higher critical shear stress tend to have a lower surface roughness.
- The correlation of $k_d$ and $n$ is not specified separately. It is the product of the two specified correlations,
  $\rho_{k_d,n} = \rho_{k_d,\tau_c} \cdot \rho_{\tau_c,n}$, which is 0.12 with the defaults (Assumption 11 in [Chapter 7](./07-assumptions-and-limitations.mdx)).

:::warning[INPUT NEEDED IN-09 — Engineering Basis]
The default correlation coefficients $\rho_{k_d,\tau_c}$ = −0.6 and $\rho_{\tau_c,n}$ = −0.2 have no stated engineering basis. The previous edition
described the negative $k_d$–$\tau_c$ correlation as "consistent with field observations" without a source. Provide the literature source (with full
bibliographic details) or the engineering-judgment attribution for each value.

Proposed (unconfirmed): the inverse relationship between $k_d$ and $\tau_c$ reported by Hanson and Simon (2001), "Erodibility of cohesive streambeds
in the loess area of the midwestern USA," Hydrological Processes 15:23–38, which was listed in the previous bibliography but not cited.
:::

## Overtopping Depth Range

The user specifies the minimum and maximum overtopping depths over which the system response curve is evaluated. The model evaluates evenly spaced
depths across that range, so the range should span the overtopping depths of interest to the risk analysis. At a depth of zero there is no overtopping
flow and the breach probability is zero.
