# Model Overview

## Purpose

The overtopping erosion screening model computes a system response curve for the overtopping erosion failure mode as a function of overtopping depth.
The system response probability (SRP) at each depth is the conditional probability of embankment breach by erosion, given that the reservoir overtops
the dam crest by that depth. The model produces a curve of SRP values across a range of overtopping depths that characterizes the embankment's
vulnerability to breach from overtopping flow.

## Intended Use

The model is a screening-level assessment of overtopping erosion. It makes simplifying assumptions with two goals:

- **Rapid estimates** — The model generates its own overtopping hydrographs and draws material properties from default distributions, so a
  screening can be completed without hydrograph development or detailed site characterization.
- **Reduced input burden** — The model requires only embankment geometry, an erodibility classification, the grass cover condition and an
  overtopping duration. Material properties are drawn from default distributions for the selected erodibility classification unless the user
  supplies site-specific distributions.

The model is not intended for detailed or semi-quantitative risk assessments. For those analyses, engineers should use detailed overtopping erosion
analysis software such as WinDAM C (U.S. Department of Agriculture, Natural Resources Conservation Service), DLBreach or EMBREA, which accept
site-specific hydrographs, zoned embankment geometry and calibrated erosion parameters.

## How the Model Works

The model runs a Monte Carlo simulation that determines whether breach occurs for each combination of sampled material properties and overtopping
depth. The execution pathway has four stages:

## Physics Basis

The model combines several established engineering methods:

- **Broad-crested weir equation** for computing overtopping discharge from overtopping depth<Citation citationKey="Fell2015" />
- **Gamma-shaped hydrograph** for representing the time history of overtopping flow ([Chapter 4](./04-hydrograph-generation.mdx))
- **CIRIA (Construction Industry Research and Information Association) grass cover erosion resistance** for modeling the removal of protective vegetation under sustained overtopping<Citation citationKey="Hughes2015" /><Citation citationKey="Thornton2014" />
- **Excess shear stress erosion equation** for computing erosion of the exposed embankment soil, following the approach used in WinDAM C (USDA
  NRCS)<Citation citationKey="Hanson2011" />
- **Erodibility categories by soil type** for the default material property distributions<Citation citationKey="Briaud2019" /><Citation citationKey="Wibowo2018" />
