# Preface

This document is the technical reference for the overtopping erosion screening model in the System Response Library. The model computes a system
response curve relating overtopping depth to the probability of embankment breach by erosion. It is a screening-level
model: it applies simplifications to provide rapid estimates of overtopping erosion response for embankment dams, and any application that performs
screening-level risk analysis can use it.

The document is written for dam safety engineers evaluating whether the model is appropriate for an assessment and for peer reviewers checking the
technical basis of a screening result. It describes the model's execution pathway from inputs to results, the equations evaluated at each step, the
inputs the user provides and the options available, the assumptions the model makes with their engineering basis, and how to read the results.
