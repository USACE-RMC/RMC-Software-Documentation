# Preface

This document provides a technical reference for the continuation (filter evaluation) screening model in the System Response library. The model
computes the probability of continuing erosion — the probability that a filter or transition zone downstream of an eroding base soil fails to
stop the erosion — for the continuation node of an internal-erosion event tree. It is a screening-level model: it accepts whatever filter
information is available, from a construction date alone to full gradation envelopes, and selects the most informative method that information
supports. It is mechanism-neutral, so any internal-erosion screening model whose event tree includes a continuation node can use it.

The intended audience includes dam and levee safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers
checking the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis and
filter design — event trees, particle-size distributions, and filter retention criteria — but no familiarity with the software implementation is
required.

The document covers the model's complete execution pathway: how a method is selected for each base soil from the information supplied, how each
of the three methods computes a probability of continuing erosion, how the results for several base soils are combined into one node probability,
the assumptions made along the way with their engineering bases, the inputs the user provides and the options available, and the results the
model produces. The underlying filter evaluation procedures are documented in the
[Filter Evaluation (Continuation) Toolbox](/docs/toolbox-technical-manuals/internal-erosion-suite/filter-evaluation-continuation/v1.0/preface)
technical manual; this document links the chapter of that manual each step follows and documents only what the screening model adds, fixes, or
simplifies.

## Document Organization

- **[Model Overview](./02-model-overview.mdx)** — The model's purpose and intended use, a summary of its execution pathway from inputs to
  results, its engineering basis, a comparison with the full filter evaluation procedure, and how several base soils are treated.
- **[Input Parameters](./03-input-parameters.mdx)** — Every user input: the base soils and their classifications, gradations, dispersivity, and
  regrading characteristics; the filter category and gradation; the optional filter segregation adjustment; the confidence interval; and the
  year of construction, with units, valid ranges, defaults, and the choices available for each selection.
- **[Method Selection and Governing Base Soil](./04-method-selection-and-governing-base-soil.mdx)** — The rule that selects one of the three
  methods (or the no-information default) for each base soil, and how the governing probability of continuing erosion is chosen across base
  soils.
- **[Year-of-Construction Method](./05-year-of-construction-method.mdx)** — The probability of continuing erosion assigned from the period in
  which the embankment was built.
- **[Soil Classification Method](./06-soil-classification-method.mdx)** — The Monte Carlo comparison of the filter with the no-erosion particle
  retention criterion, using particle-size ranges for the base soil classification and the filter category, or values taken from a single
  supplied gradation.
- **[Gradation Method](./07-gradation-method.mdx)** — The full filter evaluation from the base and filter gradation envelopes: the derived
  regrading characteristics, the particle retention check, the Foster and Fell erosion-boundary evaluation, and the screening-level combination
  of its probabilities.
- **[Assumptions and Limitations](./08-assumptions-and-limitations.mdx)** — Each modeling assumption with its engineering basis, its effect on
  results, and the conditions under which it may not hold.
- **[Output and Interpretation](./09-output-and-interpretation.mdx)** — The results the model produces, how to read them, how to tell which
  method and which base soil govern, and the role of screening results relative to a detailed filter evaluation.
