# Year-of-Construction Method

The year-of-construction method assigns the probability of continuing erosion from the period in which the embankment was built. It is the least
informative of the three methods and is used for a pair only when neither the gradation method nor the soil classification method can be
selected (see [Method Selection and Governing Base Soil](./04-method-selection-and-governing-base-soil.mdx)). It uses no property of the base
soil or the filter, so every pair evaluated by this method receives the same probability.

:::warning[INPUT NEEDED IN-04 — Engineering Basis]
The four construction periods (before 1950, 1950 to 1970, 1971 to 1985, after 1985) and the probability of continuing erosion assigned to each
(0.9, 0.5, 0.25, and 0.1) require an engineering basis. Provide a literature citation (full bibliographic details for the bibliography) or the
engineering-judgment attribution to state, including the reasoning for each period boundary and for the assigned probabilities.

Proposed (unconfirmed): the periods follow the development of filter design practice for embankment dams — filters designed before the modern
no-erosion criteria were established from laboratory filter tests in the mid-1980s are progressively more likely to be too coarse to retain the
base soil the earlier they were designed.
:::

The probability decreases with later construction, so a later year never increases $P_{cont,j}$. Because the method uses only the construction
period, it does not distinguish a fine base soil from a coarse one, a dispersive base soil from a non-dispersive one, or a designed filter from an
adjacent zone that was never intended as one; any of these differences can move the true probability far from the period value. Where
gradations or classifications are available, the soil classification and gradation methods take precedence automatically, provided the filter
side is also resolved, through a filter gradation or a filter category other than Unknown. A base soil gradation or classification with neither
still falls to this method.
