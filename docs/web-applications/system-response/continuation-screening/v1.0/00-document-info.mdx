reportAbstract:
  Technical reference documenting the continuation (filter evaluation) screening method in the System Response library. The method computes the
  probability of continuing erosion at the continuation node of an internal-erosion event tree, given that erosion has initiated in a base soil
  upstream of a filter or transition zone. It selects, for each base soil, the most informative of three methods the available information
  supports — a year-of-construction prior, a Monte Carlo comparison of the filter with the no-erosion particle retention criterion using soil
  classification ranges, or a full-gradation Foster and Fell evaluation — and reports the largest probability across the base soils. The method
  is mechanism-neutral and provides a screening-level assessment for internal-erosion failure modes.
