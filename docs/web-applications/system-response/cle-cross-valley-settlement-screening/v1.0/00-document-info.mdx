reportAbstract: Technical reference documenting the concentrated leak erosion (CLE) cross-valley settlement screening model in the System Response library. The model computes a system response probability (SRP) at each headwater level for concentrated leak erosion through a transverse crack opened at the crest by differential settlement of the embankment across the valley. The flaw assessment converts the normalized crest settlement and the abutment slope, with an optional abutment step, into a localized tensile strain, and from that strain into the probability of a continuous transverse crack, the crack width, and the crack depth. The bottom of the crack gates initiation, and the remaining nodes of the eight-node CLE event tree follow the methods shared by the CLE screening models. The flaw assessment is deterministic, and the model applies simplifications appropriate for screening-level risk analysis.
