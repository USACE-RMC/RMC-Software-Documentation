# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) cross-valley settlement screening model in the System
Response library. The model computes a system response probability (SRP) as a function of headwater elevation for concentrated leak erosion
through a transverse crack that differential settlement of the embankment across the valley opens at the crest. It is a screening-level model: it
applies simplifications intended to reduce input burden while avoiding false negatives, and any application that performs screening-level risk
analysis can use it.

The model is one of eight CLE screening models that share one event tree and most of their methods. Those shared methods — the event-tree
structure, the headwater gate that governs initiation in a crest crack, the failure-pathway conventions behind the continuation and progression
nodes, and the form of the results — are documented once in the
[Concentrated Leak Erosion Common Methods Screening Technical Reference Manual](/docs/web-applications/system-response/cle-common-methods-screening/v1.0/model-overview).
The continuation node is evaluated by the shared continuation method documented in the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](/docs/web-applications/system-response/continuation-screening/v1.0/model-overview).
This manual documents what is specific to cross-valley settlement — its flaw assessment, its inputs, how its flaw sets the elevations the
downstream nodes use, and its assumptions — and refers to the specific chapters of those two manuals for the rest.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, embankment cracking, and probability concepts — but no familiarity with the software implementation is
required.
