reportAbstract: Technical reference documenting the concentrated leak erosion (CLE) core compaction screening model in the System Response library. The model computes a system response probability (SRP) at each headwater level for concentrated leak erosion through a continuous zone of poorly compacted soil within the embankment core. The probability of the flaw is estimated by risk-factor and likelihood-factor scoring of the core compaction category, the width and width-to-height ratio of the embankment section, and borrow variability, followed by a flaw-continuity stage keyed to the compaction category; an observation of embankment leakage or wet spots overrides the flaw probability to certainty and sets the flaw elevation. Initiation is evaluated by a Monte Carlo cylindrical-pipe hydraulic shear stress analysis at the base of the flaw, and the remaining nodes of the eight-node CLE event tree follow the methods shared by the CLE screening family. The model applies simplifications appropriate for screening-level risk analysis.
