# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) core compaction screening model in the System Response
library. The model computes a system response probability (SRP) as a function of headwater elevation for concentrated leak erosion through a
continuous zone of poorly compacted soil within the embankment core. It is a screening-level model: it applies simplifications intended to reduce
input burden while avoiding false negatives, and any application that performs screening-level risk analysis can use it.

The model is one of eight CLE screening models that share one event tree and most of their methods. Those shared methods are documented once, in
the [Concentrated Leak Erosion Common Methods Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/preface),
and the continuation node is evaluated by the shared method documented in the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/preface).
This document covers what is specific to the core compaction mechanism: its flaw assessment, its mechanism-specific inputs, how it populates each
node of the shared event tree, the assumptions it adds, and the results it reports. Each section that relies on a shared method links the chapter
that documents it.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is required.

  engineering basis, its effect on results, and the conditions under which it may not hold.
- **[Output and Interpretation](./07-output-and-interpretation.mdx)** — The results the model produces, how to read the flaw assessment and the
  system response curve, checks on a result, and the role of screening results relative to detailed analysis.
