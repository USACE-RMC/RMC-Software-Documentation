# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) desiccation screening model in the System Response library.
The model computes a system response probability (SRP) as a function of headwater elevation for concentrated leak erosion through a transverse
crack that forms when the soil at the embankment crest dries and shrinks. It is a screening-level model: it applies simplifications intended to
reduce input burden while avoiding false negatives, and any application that performs screening-level risk analysis can use it.

The desiccation model is one of eight CLE screening models. The eight share an event-tree structure, an
initiation treatment for cracks open at the crest, failure-pathway rules for the continuation and progression nodes, and the form of their results,
and seven of the eight, this model among them, share a scoring scheme for flaw probabilities.
Those shared methods are documented once, in the
[Concentrated Leak Erosion Common Methods Screening Technical Reference Manual](/docs/web-applications/system-response/cle-common-methods-screening/v1.0/preface),
and the continuation node is evaluated by the shared method documented in the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](/docs/web-applications/system-response/continuation-screening/v1.0/preface).
This document covers what is specific to desiccation cracking: the site factors scored for the probability of a continuous crack, the tabulated
crack depth and the bottom-of-crack elevation that follows from it, the observation that overrides the scored probability, the soils in which the
mechanism does not apply, and how the shared nodes are populated for this mechanism. Each section links the chapter of the shared manuals that
documents the common method it relies on.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is required.
