reportAbstract: Technical reference documenting the concentrated leak erosion (CLE) desiccation screening model in the System Response library. The model computes a system response probability (SRP) at each headwater level for concentrated leak erosion through a transverse crack formed by desiccation (drying and shrinkage) of the soil at the embankment crest. The probability that a continuous desiccation crack exists is scored from three site factors — the surface layer over the core, the climate or the measured net evaporation, and the plasticity of the crest soils — using risk-factor and likelihood-factor scoring. The depth of the crack is taken from tabulated values by climate, soil, and surface layer, and the bottom of the crack sets the pool level above which concentrated leak erosion can begin. The remaining nodes of the eight-node event tree follow the methods shared by the CLE screening models. The model is deterministic, except that the shared continuation method may estimate the continuation node by sampling, and it applies simplifications appropriate for screening-level risk analysis.
