# Preface

This document provides a technical reference for the concentrated leak erosion (CLE) freezing screening model in the System Response library. The
model computes a system response probability (SRP) as a function of headwater elevation for concentrated leak erosion through a transverse crack
opened at the crest of an embankment by freezing (frost cracking). It is a screening-level model: it applies simplifications intended to reduce
input burden while avoiding false negatives, and any application that performs screening-level risk analysis can use it.

The model is one of eight CLE screening models that share one event tree, one flaw-scoring scheme, one initiation treatment for crest cracks, and
one set of failure-pathway rules. Those shared methods are documented once, in the
[Concentrated Leak Erosion Common Methods Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/cle-common-methods-screening/v1.0/preface),
and the continuation node is evaluated by the shared method documented in the
[Continuation (Filter Evaluation) Screening Technical Reference Manual](https://usace-rmc.github.io/RMC-Software-Documentation/docs/web-applications/system-response/continuation-screening/v1.0/preface).
This document covers what is specific to frost cracking — the flaw assessment, the crack depth that sets where initiation can begin, the
mechanism-specific inputs, and the assumptions that come with them — and links the chapter of the shared manuals that documents each common step.

The intended audience includes dam safety engineers evaluating whether the model is appropriate for their assessment, and peer reviewers checking
the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk analysis — event trees,
concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is required.
