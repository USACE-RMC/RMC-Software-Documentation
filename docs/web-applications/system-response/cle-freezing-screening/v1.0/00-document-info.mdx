reportAbstract: Technical reference documenting the concentrated leak erosion (CLE) freezing screening model in the System Response library. The model computes a system response probability (SRP) at each headwater level for concentrated leak erosion through a transverse crack opened at the crest of an embankment by freezing. The probability of a continuous frost crack is scored by risk-factor and likelihood-factor weighting of three site factors — the freeze-duration climate, the soils the crack crosses at the crest, and the surface cover over the core — and an observation of continuous frost cracking overrides it to certainty. The crack depth is taken from the climate, and initiation is certain once the pool rises above the bottom of the crack. The remaining nodes of the eight-node CLE event tree follow the methods shared by the CLE screening family. The model is fully deterministic apart from any Monte Carlo filter evaluation in the continuation node, and applies simplifications appropriate for screening-level risk analysis.
