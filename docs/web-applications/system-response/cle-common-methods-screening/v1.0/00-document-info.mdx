reportAbstract: Technical reference documenting the methods shared by the eight concentrated leak erosion (CLE) screening models in the System Response library. Each model computes a system response probability (SRP) at each headwater level from an eight-node event tree that runs from a flaw through initiation, continuation, three progression conditions, intervention, and breach. This manual documents what the models have in common, namely the event-tree structure and node conventions, the risk-factor and likelihood-factor scoring used to estimate flaw probabilities, the two initiation treatments (a headwater gate at the bottom of an open crest crack, and a cylindrical-pipe hydraulic shear stress analysis for compaction flaws, with its shared critical shear stress table), the failure-pathway conventions that gate continuation, roof support, and flow limitation, and the nodal results the models report. The mechanism-specific flaw assessments are documented in each model's own manual.
