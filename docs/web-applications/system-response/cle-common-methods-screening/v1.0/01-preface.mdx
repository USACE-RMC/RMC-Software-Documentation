# Preface

This document provides a technical reference for the methods shared by the eight concentrated leak erosion (CLE) screening models in the System
Response library. Each model computes a system response probability (SRP) as a function of headwater elevation for one CLE mechanism: cross-valley
differential settlement, differential settlement adjacent to a wall or cliff, poor compaction within the core, poor compaction adjacent to a conduit,
poor compaction adjacent to a wall or cliff, poor compaction along the foundation or abutment contact, desiccation cracking at the crest, and frost
cracking at the crest. The models are screening-level: they apply simplifications intended to reduce input burden while avoiding false negatives, and
any application that performs screening-level risk analysis can use them.

The eight models differ in how they estimate the probability that a flaw exists and in where that flaw sits in the embankment. Everything else is
common to the family: the eight-node event tree and how each node is populated, the scoring scheme used to turn qualitative site factors into a flaw
probability, the two initiation treatments, the failure-pathway rules that decide which filter, materials, and upstream elements apply at each pool
level, and the form of the results. This manual documents those common methods once. Each model's own technical reference manual documents its flaw
assessment and its mechanism-specific inputs, and refers to this manual for the rest. The continuation (filter evaluation) node is evaluated by a
shared continuation method with its own manual, the Continuation (Filter Evaluation) Screening Technical Reference Manual; this manual documents only
when that method is applied.

The intended audience includes dam safety engineers evaluating whether the CLE screening models are appropriate for their assessment, and peer
reviewers checking the technical basis of screening-level results. Readers are assumed to have a general background in internal-erosion risk
analysis — event trees, concentrated leak erosion mechanics, and probability concepts — but no familiarity with the software implementation is
required.

## Document Organization

- **[Model Overview](./02-model-overview.mdx)** — The purpose and intended use of the CLE screening models, a summary of their common execution
  pathway, their engineering basis, a comparison with detailed methods, the two groups the eight models fall into, and their relationship to the
  toolbox methods.
- **[Common Input Parameters](./03-input-parameters.mdx)** — The inputs shared across the family: hydraulic loading, the units and datum
  convention, the embankment description, the failure-pathway inputs, the upstream seepage-limiting elements, the initiation material inputs of the
  compaction models, and the intervention and breach probabilities.
- **[Event Tree](./04-event-tree.mdx)** — The eight event-tree nodes, which nodes vary with pool level, how the headwater grid is formed, and how the
  SRP is computed.
- **[Flaw Conventions](./05-flaw-conventions.mdx)** — The risk-factor and likelihood-factor scoring scheme, the optional flaw-continuity stage,
  observation overrides, and the flaw elevation each model passes to the downstream nodes.
- **[Initiation](./06-initiation.mdx)** — The headwater gate used by the crest-crack models, and the cylindrical-pipe initiation analysis used by
  the compaction models, with its critical shear stress and initial pipe diameter defaults.
- **[Failure Pathway and Progression](./07-failure-pathway-and-progression.mdx)** — How the failure pathway and any intersecting filter gate the
  continuation and roof-support nodes, and how the crack-filling and flow-limitation nodes are evaluated.
- **[Assumptions and Limitations](./08-assumptions-and-limitations.mdx)** — Each common modeling assumption with its engineering basis, its effect
  on results, and the conditions under which it may not hold.
- **[Output and Interpretation](./09-output-and-interpretation.mdx)** — The results the models produce, how to read the system response curve and
  its node breakdown, and the role of screening results relative to detailed analysis.
