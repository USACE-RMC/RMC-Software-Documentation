# PFM-04: CLE due to Poor Compaction within the Core

The PFM-04 page produces the system response probability (SRP) curve for concentrated leak erosion (CLE) along a flaw left in the core by poor
compaction, or along a path where leakage through the embankment has been observed. Potential failure mode 04 (PFM-04) is loaded by the reservoir
pool, and the SRP is plotted against headwater elevation. [Failure Mode Pages](./342-failure-mode-pages.mdx) and
[System Response](./343-system-response.mdx) describe the parts every failure mode page shares.

The user opens a PFM-04 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).
The page heading reads **04 - CLE due to Poor Compaction within the Core**. To evaluate a location:

A PFM-04 location is one embankment cross section. The failure mode may have any number of locations, and **Copy location** copies a location with

## Core Flaw and Seepage Pathway

Where DST places the flaw, and which material governs initiation, are set in the **Core flaw and seepage pathway** section. DST places the flaw at the
observed leakage elevation when leakage through the embankment has been observed, and otherwise one third of the way from normal pool to the crest.
<TableReference tableKey="dst-users-guide-table-pfm-04-inputs" /> describes the inputs.

Choosing a different initiation material is an override with a justification (see
[Characterization](./342-failure-mode-pages.mdx#characterization)); the revert button beside it ("Revert to the most erodible material") restores
the default. The section's inputs save automatically (see [Saving](./040-working-in-dst.mdx#saving)).

### Readings

The readings show the values DST derives, or a dash until the system response has been calculated: **Core compaction** (Well compacted, Poorly
compacted, Very poorly compacted or Unknown, from Failure Mode Screening question 4, with a link to step 4), **Height** and **Width-to-height
ratio** (the base width up to the first drain or filter, divided by the embankment height; shown only when leakage is not observed), **Base of flaw
elevation** and **Seepage path length**.

### Pathway Figure

The drawing shows the selected cross section to scale with the pathway along the flaw. DST reads the pathway from the drawing on the Dam Information
page: it follows the section at the flaw elevation from the upstream face and stops at the first drain or filter, so the seepage path length is the
distance to that filter, or the full width of the embankment when there is none. Changing the drawing changes the pathway.

### Node Assumption Cards

One card per node states how DST treats it at this location: **Flaw** (when leakage is observed, the flaw is assigned a probability of 1),
**Initiation**, **Filter compatibility**, **Roof support**, and, when they reduce the probability, **Flow limitation** and **Crack filling**.

### Advanced Initiation Overrides

**Advanced initiation overrides** replaces the screening defaults for the two initiation parameters with site-specific distributions. Its
description reads "Screening defaults come from the governing initiation material and stay locked until a site-specific distribution is chosen."
<TableReference tableKey="dst-users-guide-table-pfm-04-overrides" /> lists the parameters.

For each parameter, the **Distribution** drop-down offers the default, labeled for example **Default (Triangular)**, and **Deterministic**,
**Uniform**, **Triangular** and **PERT**. The minimum must be greater than zero and less than the maximum, and for Triangular and PERT the most
likely value must lie between them. The section works as described in [Parameter Overrides](./342-failure-mode-pages.mdx#parameter-overrides).

Changing any input in this section recalculates the system response (see
[Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)) and clears the location's verification (see
[Verifying a Location](./342-failure-mode-pages.mdx#verifying-a-location)).

## User-Defined SRP

With **User Defined SRP** selected, the page replaces its sections with a table of **Headwater Elevation (ft)** and **Probability** and its chart.
The table works as described in [User-Defined SRP](./343-system-response.mdx#user-defined-srp).

## Failure Mode Summary

The **Failure mode summary** tray lists the screening answers this location reads that were answered Unknown, the overrides and the nodal revisions
(see [Failure Mode Summary](./342-failure-mode-pages.mdx#failure-mode-summary)). For PFM-04, an Unknown embankment compaction is treated as between
bulldozer compaction and no formal compaction, and an Unknown embankment leakage is treated as not observed.
