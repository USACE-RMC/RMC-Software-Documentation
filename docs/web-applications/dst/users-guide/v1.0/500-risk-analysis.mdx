# Risk Analysis

The Risk Analysis module combines the hazard, the system response of each potential failure mode and the consequences into risk estimates for each
failure mode and for the dam. DST computes the risk with RMC-TotalRisk. The module has two pages, reached from **Risk Analysis** in the module
navigation: [Setup](./501-risk-analysis-setup.mdx), which assigns a consequence function to each failure mode, and [Results](./502-risk-analysis-results.mdx), which shows the risk.

The failure modes, hazards and system responses come from earlier pages: the failure modes selected for evaluation (see
[Failure Mode Selection](./330-failure-mode-selection.mdx)), the hazard pages (see
[Hazards](./200-hazards.mdx)) and the active system response of each location (see
[Failure Mode Evaluation](./340-failure-mode-evaluation.mdx)). The consequence functions come from the Results Data page (see
[Results Data](./406-results-data.mdx)). The risk calculation methods are described in the DST Technical Reference Manual and
the RMC-TotalRisk documentation.

Neither page is verified. Risk recomputes automatically whenever an input changes (see
[Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)), and both pages report missing inputs and warnings in the page messages (see
[Page Messages](./040-working-in-dst.mdx#page-messages)).
