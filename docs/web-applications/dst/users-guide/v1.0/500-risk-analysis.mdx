# Risk Analysis

Use the Risk Analysis module to combine the hazard, the system response of each potential failure mode and the consequences into risk estimates for
each failure mode and for the dam. DST computes the risk with RMC-TotalRisk. The module has two pages, reached from **Risk Analysis** in the module
navigation:

- [Setup](./501-risk-analysis-setup.mdx): assign a consequence function to each failure mode and check that every input is complete.
- [Results](./502-risk-analysis-results.mdx): review the risk of the screening.

The risk analysis takes its inputs from earlier pages:

- the failure modes selected for evaluation (see [Failure Mode Selection](./330-failure-mode-selection.mdx));
- the hazard curves (see [Hazards](./200-hazards.mdx));
- the active system response of each location (see [Failure Mode Evaluation](./340-failure-mode-evaluation.mdx));
- the consequence functions (see [Results Data](./406-results-data.mdx)).

Neither page is verified. The risk recomputes automatically whenever an input changes (see
[Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)), and both pages report missing inputs and warnings in the page messages (see
[Page Messages](./040-working-in-dst.mdx#page-messages)). The risk calculation methods are described in the DST Technical Reference Manual and the
RMC-TotalRisk documentation.
