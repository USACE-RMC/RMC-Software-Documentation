# Response

Use the Response module to describe how the dam responds to its loading. The screening team describes the dam's materials and cross sections,
decides which potential failure modes (PFMs) the screening evaluates, and defines the system response probability (SRP) of each PFM at each of its
locations. The Risk Analysis module combines these system responses with the hazards and the consequences.

The module has four pages, reached from **Response** in the module navigation. Each page reads the ones before it, so the team usually completes them
in this order:

- [Dam Information](./310-dam-information.mdx): the embankment features, materials, cross sections and abutment slopes. Each cross section is drawn
  in one of the [Cross-Section Editors](./311-cross-section-editors.mdx).
- [Failure Mode Screening](./320-failure-mode-screening.mdx): a questionnaire about the dam's foundation, construction, cutoff, environment and
  field observations.
- [Failure Mode Selection](./330-failure-mode-selection.mdx): a recommendation, from those answers and the data entered elsewhere, to evaluate or
  exclude each PFM, and the team's decision for each one.
- [Failure Mode Evaluation](./340-failure-mode-evaluation.mdx): the PFMs selected for evaluation and their locations, with a link to each location's
  failure mode page.

Each failure mode page, from [PFM-01](./351-pfm-01.mdx) through [PFM-23](./369-pfm-23.mdx), has its own page in this guide under Potential Failure
Modes. Several failure mode pages also read the Failure Mode Screening answers directly.
