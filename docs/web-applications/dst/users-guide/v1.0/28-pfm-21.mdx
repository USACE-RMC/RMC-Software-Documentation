# PFM-21: Concrete Dam Instability

Potential failure mode 21 (PFM-21) is sliding instability of a concrete gravity monolith along a preferential sliding plane in or at the top of its
foundation. The reservoir (headwater) loads the monolith from normal pool up to the top of dam. The PFM-21 page takes the monolith from a concrete
cross section, sets the loading and the strength of the sliding plane, and produces the system response probability (SRP) curve for each location.
The parts of the page shared with every potential failure mode page are described in
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#the-failure-mode-page).

The user opens a PFM-21 location from the Failure Mode Evaluation page (**Response > Failure Mode Evaluation**, then the location under PFM-21; see
[Opening a location](./11-failure-mode-evaluation.mdx#opening-a-location)). The page heading reads **21 - Concrete Dam Instability**. The page has
this form when the dam types on the Dam Data page include a concrete gravity or roller-compacted concrete (RCC) type.

:::note

For a concrete dam whose dam types include no gravity or RCC type, for example an arch or buttress dam, the PFM-21 page is an event tree instead,
with the default stages Normal Pool, Spillway Crest and Top of Dam and three nodes: **1 Shear Failure** ("Shear resistance along the preferential
sliding plane is exceeded?"), **2 Unsuccessful Intervention** ("Intervention to arrest monolith movement is unsuccessful?") and **3 Breach**
("Additional resistance within the foundation and shear resistance along vertical monolith joints is exceeded resulting in a moveable block sliding
downstream?"). The event-tree page is described in [Event trees](./11-failure-mode-evaluation.mdx#event-trees).

:::

[The page toolbar](./11-failure-mode-evaluation.mdx#the-page-toolbar). <TableReference tableKey="dst-users-guide-table-pfm-21-toolbar" /> lists its

## Section Figure

The section figure, in a rail beside the input sections on a wide screen and above them on a narrower one, draws the selected monolith to scale.
Callouts give the elevation of the **Crest** (or **Spillway crest** for an overflow or gated section), the **Top of dam** when it differs from the
section crest, the **Top of gate** of a gated section, the **Design pool** when entered, and the **Base**. The caption reads "Drawn to scale from the
selected cross section." with the elevation units, or "Select a concrete cross section to see the evaluated monolith." when none is selected.

## System Response

The **System Response** section shows the PFM-21 SRP curve, its table and the three nodal tables, as described in
[System Response](./11-failure-mode-evaluation.mdx#system-response), [SRP charts](./11-failure-mode-evaluation.mdx#srp-charts) and
[Nodal tables](./11-failure-mode-evaluation.mdx#nodal-tables). The chart plots **System Response Probability** on a logarithmic axis from 1E-6
against **Headwater Elevation (ft)**, and **Download SRP curves as a CSV file** exports the curves. The nodal tables are **Node 1 - 2D Instability**,
**Node 2 - Intervention** and **Node 3 - 3D Effects**, and each varies with headwater. Revising a node is described in
[Nodal revisions](./11-failure-mode-evaluation.mdx#nodal-revisions), and a notice about out-of-date results in
[Calculation currency](./11-failure-mode-evaluation.mdx#calculation-currency).

The location's verification appears as "PFM-21 SRP —" followed by the location name (see
[Verifying a location](./11-failure-mode-evaluation.mdx#verifying-a-location)).

## User-Defined SRP

With **User Defined SRP** selected, the section figure and the input and system response sections are replaced by a grid of headwater elevations and
probabilities and its chart, with **Headwater Elevation (ft)** on the x axis. The grid and the switch between modes are described in
[User-defined SRP](./11-failure-mode-evaluation.mdx#user-defined-srp) and [Active SRP](./11-failure-mode-evaluation.mdx#active-srp).

## Failure Mode Summary

The Failure mode summary tray at the bottom of the page is described in
[Failure mode summary](./11-failure-mode-evaluation.mdx#failure-mode-summary) and [Summary Tray](./04-working-in-dst.mdx#summary-tray). Its **Parameter overrides** section lists the uncracked drain
effectiveness and the foundation allowable bearing capacity when they are overridden.
