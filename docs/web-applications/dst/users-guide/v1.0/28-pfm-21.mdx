# PFM-21: Concrete Dam Instability

Potential failure mode 21 (PFM-21) is sliding instability of a concrete gravity monolith along a preferential sliding plane in or at the top of its
foundation. The loading is the reservoir (headwater) from normal pool up to the top of dam. The PFM-21 page takes the monolith from a concrete cross
section, sets the loading and the strength of the sliding plane, and produces the system response probability (SRP) curve for each location.
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#the-failure-mode-page) describes the parts of the page that every failure mode page shares.

The user opens a PFM-21 location from the Failure Mode Evaluation page (**Response > Failure Mode Evaluation**, then the location under PFM-21; see
[Opening a location](./11-failure-mode-evaluation.mdx#opening-a-location)). The page heading reads **21 - Concrete Dam Instability**. The page has
this form when the dam types on the Dam Data page include a **Gravity** or **Roller-Compacted Concrete** type.

:::note

For a concrete dam whose dam types include no **Gravity** or **Roller-Compacted Concrete** type, for example an arch or buttress dam, the PFM-21
page is an event tree instead. Its toolbar has no **Cross Section** drop-down. It has the default stages Normal Pool, Spillway Crest and Top of Dam,
and three nodes (see [Stages](./11-failure-mode-evaluation.mdx#stages) for the stage sources): **1 Shear Failure** ("Shear resistance along the preferential
sliding plane is exceeded?"), **2 Unsuccessful Intervention** ("Intervention to arrest monolith movement is unsuccessful?") and **3 Breach**
("Additional resistance within the foundation and shear resistance along vertical monolith joints is exceeded resulting in a moveable block sliding
downstream?"). [Event trees](./11-failure-mode-evaluation.mdx#event-trees) describes the event-tree page.

:::

## Section Figure

The section figure, in a rail beside the input sections on a wide screen and above them on a narrower one, draws the selected monolith to scale.
Callouts give the elevation of the **Crest** (or **Spillway crest** for an overflow or gated section), the **Top of dam** when it differs from the
section crest, the **Top of gate** of a gated section, the **Design pool** when entered, and the **Base**. The caption reads "Drawn to scale from the
selected cross section." with the elevation units, or "Select a concrete cross section to see the evaluated monolith." when none is selected.

## System Response

The **System Response** section shows the PFM-21 SRP curve, its table and the three nodal tables, as described in Chapter 11, Failure Mode Evaluation ([System Response](./11-failure-mode-evaluation.mdx#system-response), [SRP charts](./11-failure-mode-evaluation.mdx#srp-charts), [Nodal tables](./11-failure-mode-evaluation.mdx#nodal-tables)). The chart plots **System Response Probability** on a logarithmic axis from 1E-6
against **Headwater Elevation (ft)**, and **Download SRP curves as a CSV file** exports the curves. <TableReference tableKey="dst-users-guide-table-pfm-21-nodes" /> lists the nodes. [Nodal revisions](./11-failure-mode-evaluation.mdx#nodal-revisions) describes revising a node, and [Calculation currency](./11-failure-mode-evaluation.mdx#calculation-currency) describes the notice about out-of-date results.

## User-Defined SRP

With **User Defined SRP** selected, the page replaces the section figure and the input and system response sections with a grid of headwater elevations and
probabilities and its chart, with **Headwater Elevation (ft)** on the x axis. [User-defined SRP](./11-failure-mode-evaluation.mdx#user-defined-srp) and [Active SRP](./11-failure-mode-evaluation.mdx#active-srp) describe the grid and the switch between modes.

## Failure Mode Summary

[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#failure-mode-summary) describes the **Failure mode summary** tray at the bottom of the page. Its **Parameter overrides** section lists the uncracked drain
effectiveness and the foundation allowable bearing capacity when they are overridden.
