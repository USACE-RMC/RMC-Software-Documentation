# PFM-05: CLE due to Poor Compaction Adjacent to a Conduit

Potential failure mode 05 (PFM-05) evaluates concentrated leak erosion (CLE) along a flaw in poorly compacted fill beside a conduit through the
embankment. The loading is the reservoir pool, and the page plots the system response against headwater elevation. [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#the-failure-mode-page) describes the parts of the page that every failure mode page shares.

The user opens a PFM-05 location from **Response > Failure Mode Evaluation**. The page heading reads **05 - CLE due to Poor Compaction Adjacent to
a Conduit**. <FigReference figKey="dst-users-guide-fig-pfm-05-page" /> shows the page, and

## Location and Cross Section

A PFM-05 location is one conduit, evaluated at an embankment cross section through it. The failure mode may have any number of locations, and
**Copy location** copies a location with all of its inputs, overrides and results (see
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#locations)).

### Pathway figure and readings

The drawing shows the selected cross section with the conduit and the pathway along it. Beside the drawing, the readings show **Observed leakage**
(Yes, No, Unknown or Not answered, from Failure Mode Screening question 13, with a link to step 13), **Conduit base** and **Embankment base**
(elevations from the Dam Information page, with a note when the conduit lies below an embankment toe) and **Diaphragm filter** (the conduit filter
material, Recorded when a filter exists without a description or type, or None).

### Node assumption cards

Below the drawing, one card per node states how DST treats it at this location: **Flaw** (when leakage is observed), **Initiation**, **Filter
compatibility**, **Roof support**, and, when it reduces the probability, **Crack filling**.

### Advanced initiation overrides

The collapsed **Advanced initiation overrides** section holds two initiation parameters. Its description reads "Screening defaults come from the
governing initiation material and stay locked until a site-specific distribution is chosen."

[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#verifying-a-location)).
