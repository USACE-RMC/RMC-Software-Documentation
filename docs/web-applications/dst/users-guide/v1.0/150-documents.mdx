# Documents

The Documents module keeps the screening's reference files (reports, drawings, photographs, spreadsheets and any other file the team relies on)
in one place and links each file to the pages it supports, such as Dam Data or a failure mode location. A linked document appears in the
Supporting documents section of that page's summary tray. When a screening is copied, its documents and their page links go with it, except links to
failure mode locations.

## The Documents Page

The module has a single page, **Documents**, reached by selecting **Documents** in the module navigation.

:::note[Availability]
Everyone on the screening can open and download its documents. The Facilitator, Team Members and administrators can also add, edit, link and delete
documents, including while the screening is under review; the documents become read-only once the screening is complete.
:::

The page has nothing to verify and does not count toward Submission Readiness. Before any document is added, the page reads "No documents uploaded yet".

:::tip

Files dragged from the computer onto the Documents page open the Add Documents dialog with those files already listed; the page reads "Drop files to
add them to Documents" while they are over it. On a touch screen, files are added with **Add Document**.

### Following an Upload

While files upload, an upload panel reads, for example, "Uploaded 1 of 3 files" with a progress bar and the note "Keep this tab
open until uploads finish." **Show details** lists each file, with a button to cancel it, and **Cancel all** cancels every upload. When the uploads
finish, the panel reports the result, for example "3 files uploaded" or "2 uploaded, 1 failed", and the new documents appear on the page. The panel
closes on its own when every file succeeds; when a file fails, it stays until the user closes it.

Uploads continue while the user moves to other DST pages or to another screening. Closing or reloading the browser tab, or leaving DST for another
site, stops the uploads that have not finished; the browser asks first. Logging out while files are uploading asks "Stop uploading?";
**Keep uploading** returns to DST, and **Stop and log out** ends the uploads and the session.

## Finding Documents

The toolbar above the documents narrows and arranges the list. It appears once the screening has at least one document.

- **Search documents** matches any part of a file name, description, the name of the user who uploaded it or the name of a linked page.
- **File type** shows one kind of file, from the groups in <TableReference tableKey="dst-users-guide-table-documents-file-types" />, or **All types**.
- **Linked to** shows the documents linked to one page, those linked to no page (**Unlinked**), or **All pages**.
- **List view** and **Grid view** switch between a list and a grid of thumbnails. DST remembers the choice in that browser.
- **Rows per page** (list view) or **Files per page** (grid view) shows 15, 25 or 50 documents.

When the filters hide every document, the page reads "No documents match your filters." The search and filters reset each time the Documents page
opens.

In list view, each row shows the file name, description, linked pages, uploader, size and upload date. Each linked page appears as a chip with its
locator, for example "Dam Data · p. 12"; selecting the chip opens that page. In grid view, each document is a tile with a thumbnail or file-type icon,
its name, its linked pages and a **⋮** menu holding the same actions as the list's row buttons
(<FigReference figKey="dst-users-guide-fig-documents-grid" />).

## Opening and Downloading

PNG and JPG images open in an image viewer over the page, with the file name, the image and its description. **Previous** and
**Next**, or the <kbd>←</kbd> and <kbd>→</kbd> arrow keys, move among the images in the current list, and the viewer's buttons open the image in a new
browser tab or download it. Every other kind of file, including TIFF and GIF images, downloads when the user selects its name or **Download**.

## Editing and Linking Documents

**Edit** opens the **Edit Document** dialog, which holds the document's **Description** (up to 2,000 characters) and its page links. **Save**
applies the changes. The file itself cannot be replaced; a new version is added as a new document.

The links list, headed **Linked to**, reads "Not linked to any page" until a link is added. Each link names its page and has a locator box and a
**Remove link** button:

- **Add link to a page…** chooses a page to link. The pages are Dam Data, Operational Data, Flood Hazard, Stage Duration, Seismic Hazard, Dam
  Information, Failure Mode Screening, Failure Mode Selection, each failure mode location, Inundation Geometry, Inundation Analysis, Consequence Data,
  Consequence Analysis, Results Map, Results Data, Risk Analysis Setup, Risk Analysis Results, Risk Characterization, Major Uncertainties, Summary of
  Findings and Recommendations.
- **Locator** (optional, up to 200 characters) says where to look in the file for that page, for example "p. 47, Table 6".

:::tip

To link several documents to one page at once, the user selects their check boxes in the list or the grid and chooses the page in **Link selected to
a page…** in the selection bar, which counts the selection, for example "3 selected". In grid view, **Select all** selects every document that
matches the filters.

:::

## Deleting Documents

**Delete** on a document opens the **Delete Document** dialog: "Delete" followed by the file name and "This can't be undone." When the document is
linked to pages, the dialog names them. **Delete** confirms.

:::caution

Deleting a document removes the file from the screening permanently, along with its links to every page. It cannot be restored. To remove a document
from one page only, the user unlinks it instead (see [Supporting Documents](#supporting-documents)).

:::

To delete several documents, the user selects them and selects **Delete** in the selection bar. The **Delete Documents** dialog lists the files and
notes when they are linked to pages; its button names the count, for example **Delete 3 documents**.

## Supporting Documents

Every summary tray ends with a **Supporting documents** section, described as "Files from the screening's Documents that support this page." The
section allows files to be attached to the current page without leaving that page. It shows the documents linked to that page as tiles, with their locators
(<FigReference figKey="dst-users-guide-fig-documents-supporting" />). [Summary Tray](./040-working-in-dst.mdx#summary-tray) describes how the summary
tray itself works.

<Figure
  figKey="dst-users-guide-fig-documents-supporting"
  src="figures/web-applications/dst/users-guide/v1.0/figures/documents-supporting.png"
  alt="The Supporting documents section of the Dam data summary tray of Thistlewood Dam Screening, with the description 'Files from the screening's Documents that support this page.' and Link existing and Upload buttons. Two PDF tiles each show a file name and a menu button. The first also shows its other link, 'Dam Information · p. 34, Plate 5', above an empty Page or section box; the second tile's Page or section box holds the locator 'p. 12'."
  caption="Supporting documents in a summary tray."
  width="70%"
/>

:::note[Availability]
The Facilitator, Team Members and administrators only.
:::

The section offers:

- **Link existing** — opens **Link documents to** followed by the page name, a selection list of the screening's documents with the same search and filters as
  the Documents page. Documents already linked are marked **Linked**. The user selects documents and selects the button that names the count, for
  example **Link 2 documents**.
- **Upload** — opens **Add Documents to** followed by the page name. It works like the Add Documents dialog, except that every file is linked to this
  page and each file row has a **Locator** box ("Locator, e.g. p. 47", up to 200 characters).
- **Page or section** — the locator box under each tile, which saves when the user leaves it.
- **Unlink** — in each tile's menu, removes the document from this page only; the document stays in Documents and on its other pages.
- **Delete** — in each tile's menu, deletes the document from the screening. Its dialog also offers **Unlink instead**.

Other users see the tiles and their locators, and can open and download the files. With nothing linked, the section reads "No documents linked to
this page yet."
