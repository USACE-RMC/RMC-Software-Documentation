# Hazards

The Hazards module defines the loading against which the screening is evaluated. The module has three pages, reached from **Hazards** in the
module navigation:

- [Flood Hazard](./201-flood-hazard.mdx): the reservoir stage for each annual exceedance probability. The flood-loaded failure modes use it.
- [Stage Duration](./202-stage-duration.mdx): the percent of time the reservoir is at or above each stage, and the normal pool elevation taken from
  it. The seismic failure modes use it as the reservoir level during an earthquake, and the event-tree failure modes use its normal pool.
- [Seismic Hazard](./203-seismic-hazard.mdx): the annual exceedance probability of each level of ground motion. The seismic failure modes use it.

Each page is verified on its own, and changing an input clears that page's verification (see
[Human Verification](./040-working-in-dst.mdx#human-verification)). When a change makes the results of a later page out of date, DST clears those
results and says so (see [Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)). Each page's summary tray holds its justification
and supporting documents (see [Summary Tray](./040-working-in-dst.mdx#summary-tray) and [Supporting Documents](./150-documents.mdx#supporting-documents)).
