# PFM-03: CLE due to Differential Settlement Adjacent to a Cliff or Wall

In potential failure mode 03 (PFM-03), the embankment settles differentially against a rigid face such as a
cliff, an excavation, a concrete monolith or a wall, and concentrated leak erosion (CLE) develops through a transverse crack at the crest. The PFM-03
page estimates the system response probability (SRP) for this mechanism. The reservoir pool loads the failure mode, and the page plots the SRP against
headwater elevation. [Failure Mode Pages](./342-failure-mode-pages.mdx) and [System Response](./343-system-response.mdx) describe the parts every
failure mode page shares.

The user opens a PFM-03 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).
The page heading reads **03 - CLE due to Differential Settlement Adjacent to a Cliff or Wall**. To evaluate a location:

## Location and Cross Section

DST creates one PFM-03 location for each structure contact selected in Failure Mode Screening question 5 (see
[Questions](./320-failure-mode-screening.mdx#questions)): **Left Abutment Cliff**, **Right Abutment Cliff**, **Concrete Structure**, **Wall**, and
an Other Location named by the text entered for it. When question 5 names no contact, DST provides a single location, named **Location 1**, that the
team names itself.

:::note[Availability]
The team cannot add or copy PFM-03 locations, and the locations DST creates cannot be renamed or deleted; their **Location** name is
read-only in the toolbar.
:::

:::caution

Clearing a structure contact in question 5 deletes its location with its inputs, results and justifications. A contact eliminated because a cutoff
wall ties into it hides the location instead, until the tie is removed.

:::

## Settlement against the Wall or Cliff and Failure Pathway

The **Settlement against the wall or cliff and failure pathway** section describes the rigid face and the settlement, and presents the resulting
crack and the path that concentrated leak erosion would follow. The information icon beside each geometry input shows a profile with that dimension
highlighted. <TableReference tableKey="dst-users-guide-table-pfm-03-inputs" /> describes the inputs.

PFM-03 uses the Dam Height on the Dam Data page as the dam height.

### Readings

The readings show the values DST calculates for the location, or a dash until the system response has been calculated: **Normalized settlement**
(the maximum post-construction settlement as a percentage of the Dam Height on the Dam Data page), **Bench-to-wall ratio**, **Crack width** (mm),
**Crack depth** and **Bottom of crack** (elevation).

### Pathway Figure

The drawing shows the selected cross section to scale, with the crack from the crest down to the bottom of the crack, the zones the pathway crosses,
and lines for the crest, the top of the filter, the bottom of the crack and the top of any cutoff wall. DST reads the pathway from the drawing on the
Dam Information page, so changing the drawing changes the pathway. When no crack forms, the caption reads "No transverse crack forms against this
wall or cliff, so nothing enters the embankment through the crest."

### Node Assumption Cards

One card per node states how DST treats it at this location: **Flaw** when the flaw probability is zero, **Initiation**, **Filter compatibility**,
**Sidewall support**, and, when they reduce the probability, **Flow limitation** and **Crack filling**. When the bench or the foundation slope rules
out a crack, the Flaw card names the cause, for example "a foundation slope of 25 degrees or less".

Inputs on this page save automatically (see [Saving](./040-working-in-dst.mdx#saving)), the system response recalculates automatically (see
[Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)), and a change clears the location's verification (see
[Verifying a Location](./342-failure-mode-pages.mdx#verifying-a-location)).

## System Response

The **System Response** section shows the SRP against **Headwater Elevation (ft)** on a logarithmic probability axis, as a table of up to eight
headwaters and a chart. It works as described in [System Response](./343-system-response.mdx).

## User-Defined SRP

With **User Defined SRP** selected, the page replaces its sections with a table of **Headwater Elevation (ft)** and **Probability** and its chart.
The table works as described in [User-Defined SRP](./343-system-response.mdx#user-defined-srp).

## Failure Mode Summary

The **Failure mode summary** tray works as described in [Failure Mode Summary](./342-failure-mode-pages.mdx#failure-mode-summary). PFM-03 has
no parameter overrides, so the tray holds justifications only for nodal revisions.
