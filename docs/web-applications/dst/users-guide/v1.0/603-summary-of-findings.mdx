# Summary of Findings

The Summary of Findings page, at **Major Findings > Summary of Findings**, holds the team's key findings. Its purpose statement reads "Summarize the
team's key findings from this screening." The page is required.

**What to consider** lists:

- What the team observed about the dam's condition and performance
- What each observation means for risk
- What reviewers should take away

The page uses the layout shared by every Major Findings page: the purpose statement, the **What to consider** button and the text editor (see
[The Major Findings Pages](./600-major-findings.mdx#the-major-findings-pages)).
While the editor is empty, it shows the placeholder "Summarize the findings…".
