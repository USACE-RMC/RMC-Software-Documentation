# Summary of Findings

The Summary of Findings page (**Major Findings > Summary of Findings**) condenses the team's key findings and is required. Its purpose statement reads
"Summarize the team's key findings from this screening."

**What to consider** lists:

- What the team observed about the dam's condition and performance
- What each observation means for risk
- What reviewers should take away

While the editor is empty, it shows "Summarize the findings…", and the page messages report "Write the summary of findings." For writing, saving
and verifying the text, see [Writing a Major Findings Page](./600-major-findings.mdx#writing-a-major-findings-page).
