# Risk Characterization

Use the Risk Characterization page, at **Major Findings > Risk Characterization**, to write the team's case for the risk estimate. The page is
required. Its purpose statement reads "Tie the hazards, system response and consequences together to build the case for the risk estimate."

**What to consider** lists:

- Which failure modes and loading ranges drive the risk, and why
- How the hazard, system response and consequences combine in the estimate
- The evidence behind the key estimates

While the editor is empty, it shows "Characterize the risk for this screening…", and the page messages report "Write the risk characterization."
For writing, saving and verifying the text, see [Writing a Major Findings Page](./600-major-findings.mdx#writing-a-major-findings-page).
