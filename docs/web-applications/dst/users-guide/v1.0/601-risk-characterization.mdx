# Risk Characterization

The Risk Characterization page, at **Major Findings > Risk Characterization**, holds the team's case for the risk estimate. Its purpose statement
reads "Tie the hazards, system response and consequences together to build the case for the risk estimate." The page is required.

**What to consider** lists:

- Which failure modes and loading ranges drive the risk, and why
- How the hazard, system response and consequences combine in the estimate
- The evidence behind the key estimates

The page uses the layout shared by every Major Findings page: the purpose statement, the **What to consider** button and the text editor (see
[The Major Findings Pages](./600-major-findings.mdx#the-major-findings-pages)).
While the editor is empty, it shows the placeholder "Characterize the risk for this screening…".
