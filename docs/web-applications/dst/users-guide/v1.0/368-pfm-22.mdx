# PFM-22: Gate Failure

PFM-22, Gate Failure, concerns a spillway gate: the loading on the gate overstresses its strut arms, girders or
diaphragms, and the load cannot be redistributed to other members. The loading is the reservoir pool on the gate, evaluated at stages from the
spillway crest through the top of gates to the top of dam. The PFM-22 page estimates the SRP at one location with an
event tree.

The user opens a PFM-22 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).
[Event Trees](./344-event-trees.mdx) describes the parts that every event-tree page shares, and
[Failure Mode Pages](./342-failure-mode-pages.mdx) the parts that every failure mode page shares. To evaluate a location:

When no gated section is selected, or the gate has no closed top elevation, DST places the Top of Gates stage a third of the way from the spillway
crest to the top of dam.

Each PFM-22 location has its own cross section, stages, node probabilities and results, and PFM-22 has no limit on the number of locations. A copied
location keeps the cross section, stages, node probabilities and rationales of the original (see [Copying a Location](./341-locations.mdx#copying-a-location)).

## Stages to Evaluate

The **Stages to evaluate** section lists the pool elevations at which DST evaluates the PFM-22 event tree, lowest first. DST places the three default
stages in <TableReference tableKey="dst-users-guide-table-pfm-22-default-stages" /> from other pages. To change a default stage's elevation, the user
changes the value on its source page, then selects **Move stage to** in the notice that appears on this page. [Stages](./344-event-trees.mdx#stages) describes the zero point and adding, editing and deleting stages.

## User-Defined SRP

With **User defined** selected in the toolbar, the user enters the SRP curve as **Pool Elevation (ft)** and **Probability** pairs in place of the
event tree. DST keeps the stages, node probabilities and rationales, and shows them again when the user selects **Event tree** (see
[User-Defined SRP](./343-system-response.mdx#user-defined-srp)).

## Common Problems

Problems every event-tree page shares, such as "No system response curve yet", a stage that reads Source missing, a default stage that
cannot be edited or a refused cross section, are described in [Common Problems](./344-event-trees.mdx#common-problems) on the Event Trees
page. Problems every failure mode page shares, such as no usable cross sections or a deleted cross section, are described in
[Common Problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages page. This page adds its own.
