# PFM-18: Concrete Lined Spillway Failure

The PFM-18 page evaluates potential failure mode PFM-18, Concrete Lined Spillway Failure: failure of a concrete-lined spillway, where stagnation pressure and scour, with or without slab uplift, undermine the spillway and advance to breach. The loading is the reservoir pool above the spillway crest, evaluated at stages from the spillway crest to the top of dam. The user estimates a probability for each node
of the PFM-18 event tree at each stage, and DST combines them into the location's system response probability (SRP) at each stage, which Risk
Analysis uses for the location.

The page layout, locations and the parts every event tree page shares are described in [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#event-trees).
This chapter documents what is particular to PFM-18: its stages, nodes and results.

The user opens the page from the Failure Mode Evaluation page by selecting a PFM-18 location (see [Opening a location](./11-failure-mode-evaluation.mdx#opening-a-location)).
The page opens only when PFM-18 is selected for evaluation on the Failure Mode Selection page; otherwise it reads "PFM-18 isn't being evaluated".
<FigReference figKey="dst-users-guide-fig-pfm-18-page" /> shows the page, and <TableReference tableKey="dst-users-guide-table-pfm-18-regions" /> describes each numbered region.

## Stages to Evaluate

The **Stages to evaluate** section lists the pool elevations at which the PFM-18 event tree is evaluated, lowest first. PFM-18 has three
default stages, which DST places from other pages. <TableReference tableKey="dst-users-guide-table-pfm-18-default-stages" /> lists them with the text of their
**Source** column. The user cannot edit a default stage's elevation on this page. When its source is missing, the stage's elevation reads
"Source missing" and the page messages name the input to complete (see [Page Messages](#page-messages)).

zero point is the lowest stage; the user may choose another stage. Nodes take probabilities at every stage above the zero point.

## Event Tree Evaluation

on the left and ends at breach, marked by a red triangle, on the right. The section header counts the complete nodes, for example "13 of 15 nodes complete"; a node is
complete when it has a probability at every stage above the zero point and an estimate rationale. <FigReference figKey="dst-users-guide-fig-pfm-18-event-tree" /> shows
the tree with Node 2b selected.

The tree branches at Node 1, Slab Uplift. The upper row follows its Yes outcome and the lower row its No
outcome, and each row ends at breach. Branch a, "Slab Uplift = Yes", follows Nodes 1, 2a, 3a, 4a, 5a, 6a, 7a, 8a. Branch b, "Slab Uplift = No", follows Nodes 1 (No), 2b, 3b, 4b, 5b, 6b, 7b, 8b, where "(No)"

Each branch b node from 2b to 8b can mirror the branch a node with the same number, for example Node 2b can mirror Node 2a.

rationale until the user enters a value of its own. Mirroring is off by default. Overriding and re-linking mirrored values are described in
[Mirrored nodes](./11-failure-mode-evaluation.mdx#mirrored-nodes).

the panel reads "No node selected". <TableReference tableKey="dst-users-guide-table-pfm-18-node-inputs" /> describes the panel's inputs, and the typical order of work is:

## System Response

The **System Response** section shows the location's SRP at each stage. It appears once every node has a probability at every stage above the zero
point and the stages and probabilities have no errors; until then the section reads "No system response curve yet". To its left is a table of
the results, described in <TableReference tableKey="dst-users-guide-table-pfm-18-results" />, and to its right a chart of the same values. The information icon in each
column heading explains the column, and the section's layout is described in [Event tree system response](./11-failure-mode-evaluation.mdx#event-tree-system-response).

The chart plots Branch a, Branch b and the Total SRP against Pool Elevation (ft) on a logarithmic System Response
Probability axis. **Download SRP curves as a CSV file** saves the plotted values (see [SRP charts](./11-failure-mode-evaluation.mdx#srp-charts)). The Total SRP is the curve
DST sends to Risk Analysis for the location (see [Active SRP](./11-failure-mode-evaluation.mdx#active-srp)). If the Total SRP decreases from one stage to the next, the table and
chart still show, but the page messages report an error and the curve is not sent to Risk Analysis.

## User Defined SRP

With **User defined** selected in the toolbar, the page replaces Stages to evaluate, Event tree evaluation and System Response with a table of
**Pool Elevation (ft)** and **Probability** pairs and its chart, and the entered curve becomes the location's SRP. The stages, node probabilities and
rationales stay saved and return when the user selects **Event tree** again. The table and chart are described in
[User-defined SRP](./11-failure-mode-evaluation.mdx#user-defined-srp).

## Failure Mode Summary

The failure mode summary tray at the bottom of the page includes a **Node probabilities** section for PFM-18. It shows a table of every node, its
status (Not started, Started or Complete) and its probability at every stage, with one column per stage headed by its elevation and name. A shaded cell
marks a stage that is not one of the node's stages, and "—" marks a stage at or below the zero point. A mirrored value shows a link icon and follows its source node until overridden. The tray itself is
described in [Summary Tray](./04-working-in-dst.mdx#summary-tray), and its other sections, including the **System response rationale**, in
[Failure mode summary](./11-failure-mode-evaluation.mdx#failure-mode-summary).
