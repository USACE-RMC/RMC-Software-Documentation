# PFM-18: Concrete Lined Spillway Failure

Potential failure mode 18 (PFM-18), Concrete Lined Spillway Failure, is failure of a concrete-lined spillway, where stagnation pressure and scour, with or without slab uplift, undermine the spillway and advance to breach. The loading is the reservoir pool above the spillway crest, evaluated at stages from the spillway crest to the top of dam.

[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#event-trees) describes the parts of the page that every failure mode page shares.

The user opens the page by selecting a PFM-18 location on the Failure Mode Evaluation page (see [Opening a location](./11-failure-mode-evaluation.mdx#opening-a-location)).
<FigReference figKey="dst-users-guide-fig-pfm-18-page" /> shows the page, and <TableReference tableKey="dst-users-guide-table-pfm-18-regions" /> describes each numbered region.

text of their **Source** column. The user cannot edit a default stage's elevation on this page. When its source is missing, the stage's elevation reads

The tree branches at Node 1, Slab Uplift. The upper row follows its Yes outcome and the lower row its No outcome, and each row
ends at breach. Branch a, "Slab Uplift = Yes", follows Nodes 1, 2a, 3a, 4a, 5a, 6a, 7a, 8a. Branch b, "Slab Uplift = No", follows Nodes 1 (No), 2b, 3b, 4b, 5b, 6b, 7b, 8b, where "(No)" marks the node whose No
outcome the branch takes.

Each Branch b node from 2b to 8b can mirror the Branch a node with the same number; for example, Node 2b can mirror Node 2a. The check box **Mirror Node 2a** on Node 2b's panel turns mirroring on; it is off by default. Chapter 11 describes how a
mirrored node follows its source and how the user overrides and re-links its values (see [Mirrored nodes](./11-failure-mode-evaluation.mdx#mirrored-nodes)).

Chapter 11 describes the node panel, the probability slider, the estimate rationale, node colors and moving between nodes (see
[Event tree diagram](./11-failure-mode-evaluation.mdx#event-tree-diagram) and [Nodes](./11-failure-mode-evaluation.mdx#nodes)). The **Failure mode summary** tray repeats every node's probabilities
in its Node probabilities section (see [Failure mode summary](./11-failure-mode-evaluation.mdx#failure-mode-summary)).

## User-Defined SRP

With **User defined** selected in the toolbar, the page replaces Stages to evaluate, Event tree evaluation and System Response with a table of
**Pool Elevation (ft)** and **Probability** pairs and its chart, and the entered curve becomes the location's SRP. DST keeps the stages, node
probabilities and rationales, and shows them again when the user selects **Event tree** (see [User-defined SRP](./11-failure-mode-evaluation.mdx#user-defined-srp)).
