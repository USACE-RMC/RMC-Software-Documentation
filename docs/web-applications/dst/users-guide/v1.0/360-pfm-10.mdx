# PFM-10: Foundation Backward Erosion Piping

In potential failure mode 10 (PFM-10), seepage under the embankment exits downstream, erodes a foundation sand layer at an unfiltered exit, and a
pipe works back toward the reservoir: backward erosion piping in the foundation. The loading is the reservoir (headwater). On the PFM-10 page, the
user characterizes the foundation sand, any confining layer, the seepage path, the pipe roof support and the observed seepage at a location in eight
numbered sections, and DST calculates the system response probability (SRP) curve. [Failure Mode Pages](./342-failure-mode-pages.mdx) and
[System Response](./343-system-response.mdx) describe the parts that every failure mode page shares.

The user opens a PFM-10 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).
The page heading reads **10 - Foundation Backward Erosion Piping**. The answers in section 1 decide which inputs the later sections show. To
evaluate a location:

## Downstream Seepage Berm

Section 6, **Downstream seepage berm**, is read-only. It shows the seepage berm drawn in the selected cross section on the Dam Information page; to
change it, the user edits the berm there (see [Berm Tab](./311-cross-section-editors.mdx#berm-tab)). With a berm it shows **Berm length from downstream embankment
toe** (ft) and **Berm-toe ground elevation** (ft), and a "Drawn berm geometry is incomplete" notice when the berm has no usable length. Without one it
shows "No drawn seepage berm"; without a usable cross section it shows "Cross section required".

## Pipe Roof Support

What supports the roof of a developing pipe is set in section 7, **Pipe roof support**. With a confining layer (**Yes**) it reads "The confining layer
supports the pipe roof" and "No embankment material needs to be selected." With **No** or **Unknown** it shows **Materials that can support the pipe
roof**, a card for each material of the selected cross section with its material type ("Type not assigned" when none). The defaults, marked
"(Default)", are the materials along the embankment base, and they start selected. The user selects or clears cards; at least one is required. Any other selection is an override (see [Characterization](./342-failure-mode-pages.mdx#characterization)). When no material qualifies, the section reads "No materials in the cross section can support a pipe roof yet." with a link
to the Dam Information page.

## User-Defined SRP

With **User Defined SRP** selected, the page replaces the characterization and system response sections with a grid of headwater elevations and
probabilities and its chart. [User-Defined SRP](./343-system-response.mdx#user-defined-srp) and [Active SRP](./343-system-response.mdx#active-srp)
describe the grid and switching between modes.
