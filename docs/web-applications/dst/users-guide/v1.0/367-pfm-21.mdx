# PFM-21: Concrete Dam Instability

DST calculates the system response probability (SRP) curve of potential failure mode 21 (PFM-21), Concrete Dam Instability, for one concrete
monolith at each location. PFM-21 is sliding instability of a concrete gravity monolith along a preferential sliding plane in or at the top of its
foundation. The loading is the reservoir (headwater) from normal pool up to the top of dam. [Failure Mode Pages](./342-failure-mode-pages.mdx) and
[System Response](./343-system-response.mdx) describe the parts that every failure mode page shares.

The user opens a PFM-21 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)). The
page heading reads **21 - Concrete Dam Instability**. This page applies when the dam types on the Dam Data page include **Gravity** or
**Roller-Compacted Concrete**.

:::note

For a concrete dam whose dam types include neither **Gravity** nor **Roller-Compacted Concrete**, for example an arch or buttress dam, the PFM-21
page is an event tree instead, with no **Cross Section** drop-down. Its default stages are Normal Pool, Spillway Crest and Top of Dam, and it has three
nodes: **1 Shear Failure** ("Shear resistance along the preferential sliding plane is exceeded?"), **2 Unsuccessful Intervention** ("Intervention to
arrest monolith movement is unsuccessful?") and **3 Breach** ("Additional resistance within the foundation and shear resistance along vertical
monolith joints is exceeded resulting in a moveable block sliding downstream?"). [Event Trees](./344-event-trees.mdx) describes that page.

:::

## Section Figure

The section figure draws the selected monolith to scale, so the user can confirm DST reads the intended section. It labels the **Crest** (or
**Spillway crest** for an overflow or gated section), the **Top of dam** when it differs from the section crest, the **Top of gate** of a gated
section, the **Design pool** when entered, and the **Base**. With no section selected, it reads "Select a concrete cross section to see the evaluated
monolith."

## System Response

The **System Response** section shows the PFM-21 SRP curve, its table and the three nodal tables (see [SRP Charts](./343-system-response.mdx#srp-charts)
and [Nodal Tables](./343-system-response.mdx#nodal-tables)). The chart plots **System Response Probability** on a logarithmic axis from 1E-6 against
**Headwater Elevation (ft)**, and **Download SRP curves as a CSV file** exports the curves. <TableReference tableKey="dst-users-guide-table-pfm-21-nodes" />
lists the nodes. [Nodal Revisions](./343-system-response.mdx#nodal-revisions) describes revising a node, and
[Calculation Currency](./343-system-response.mdx#calculation-currency) describes the notice about out-of-date results.

## User-Defined SRP

With **User Defined SRP** selected, the user enters the SRP curve as headwater elevations and probabilities in place of the section figure and the
input and system response sections; the chart plots **Headwater Elevation (ft)**. [User-Defined SRP](./343-system-response.mdx#user-defined-srp) and
[Active SRP](./343-system-response.mdx#active-srp) describe the grid and the switch between modes.

## Failure Mode Summary

The **Failure mode summary** tray (see [Failure Mode Summary](./342-failure-mode-pages.mdx#failure-mode-summary)) lists the uncracked drain
effectiveness and the foundation allowable bearing capacity in its **Parameter overrides** section when they are overridden.

## Common Problems

Problems every failure mode page shares, such as a system response that does not calculate, no usable cross sections, a deleted cross
section or a refused verification, are described in [Common Problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode
Pages page. This page adds its own.
