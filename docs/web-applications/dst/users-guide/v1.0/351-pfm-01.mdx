# PFM-01: Embankment Overtopping Erosion

Potential failure mode 01 (PFM-01) is erosion of an earth embankment by flow over its crest during a flood, through to breach. Because the depth of
overtopping loads the failure mode, the PFM-01 page estimates the system response probability (SRP) and plots it against overtopping depth rather than
headwater elevation. [Failure Mode Pages](./342-failure-mode-pages.mdx) and [System Response](./343-system-response.mdx) describe the parts every
failure mode page shares.

The user opens a PFM-01 location from **Response > Failure Mode Evaluation** (see [Opening a location](./341-locations.mdx#opening-a-location)).
The page heading reads **01 - Embankment Overtopping Erosion**. To evaluate a location:

### Advanced erodibility overrides

The collapsed **Advanced erodibility overrides** section replaces the screening defaults for erodibility with site-specific distributions.
Its description reads "Screening defaults come from the downstream shell material's erodibility category and stay locked until a site-specific
distribution is chosen." <TableReference tableKey="dst-users-guide-table-pfm-01-overrides" /> lists the parameters.

For each parameter, the **Distribution** drop-down offers the default, labeled with its distribution type, for example **PERT (Default)**, and
**Deterministic**, **Uniform**, **Triangular**, **PERT** and **Normal**. A Deterministic value must be greater than zero. For Uniform, Triangular and
PERT, the minimum must be greater than zero and less than the maximum, and the most likely value must lie between them. For Normal, the mean and the
standard deviation must be greater than zero. The section works as described in
[Parameter overrides](./342-failure-mode-pages.mdx#parameter-overrides).

Changing any input in this section recalculates the system response (see
[Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)) and clears the location's verification (see
[Verifying a location](./342-failure-mode-pages.mdx#verifying-a-location)).

## System Response

The **System Response** section shows the SRP against **Overtopping Depth (ft)**, as a table of up to eight depths and a chart. The SRP table, chart,
node cards and nodal revisions work as described in [System Response](./343-system-response.mdx). DST calculates the system response once a cross
section, a downstream shell material and the overtopping duration are set and the downstream slope protection cover is entered on the Dam
Information page.

### Max overtopping depth evaluated

The **Max overtopping depth evaluated (ft)** box above the table sets the largest overtopping depth the curve covers.

Entering a value changes the badge to **Manual**; the reset button ("Reset to auto") restores the computed value. A depth below the default needs a
justification when the system response at that depth is less than 1.0.

:::caution

When the location has nodal revisions, changing the maximum depth opens the dialog **Clear nodal probability adjustments?**, which states the old
and new depths and that the change clears all manual nodal probability adjustments. **Continue and clear adjustments** applies the change;
**Cancel** keeps the earlier depth. The cleared adjustments cannot be recovered.

:::

## User-Defined SRP

With **User Defined SRP** selected, the page replaces its sections with a table of **Overtopping Depth (ft)** and **Probability** and its chart. The
table works as described in [User-defined SRP](./343-system-response.mdx#user-defined-srp).

## Failure Mode Summary

The **Failure mode summary** tray lists the location's overrides, nodal revisions and rationale (see
[Failure mode summary](./342-failure-mode-pages.mdx#failure-mode-summary)). For PFM-01 the overrides are the erodibility coefficient kd, the
critical shear stress τc and Manning's roughness coefficient n when a distribution is chosen, the downstream shell material when it differs from the
drawing default, and the max overtopping depth evaluated when it is entered. A max depth needs a justification only when it is below the default and
the system response at that depth is less than 1.0.
