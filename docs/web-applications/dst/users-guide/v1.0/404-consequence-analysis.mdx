# Consequence Analysis

LifeSim simulates the life loss and damages of each loading level of each inundation analysis on the Consequence Analysis page (**Consequences >
Consequence Analysis**). The page also sets when the hazard occurs and how much notice people have at each loading level. The page lists every
analysis from the Inundation Analysis page; with none, it reads "Nothing to run yet" and links to **Open Inundation Analysis**.

## Set the Advanced Notice

The advanced notice is how long before the hazard occurs the threat is identified
(<TableReference tableKey="dst-users-guide-table-consequence-analysis-advanced-notice" />). It has no default. It is set for each analysis, and **Set by loading
level** sets a level differently. **Add the basis** records why the notice was chosen, up to 2000 characters.

Beside each choice, a sentence says what the notice means, for example "Identified 4 to 8 hours before the breach starts." A loading level set on
its own reads "Set for this level:"; the others read "Same as the analysis".

When the screening has a non-failure hazard zone, the zone has its own row, marked **Every analysis**. Its notice is optional:

- Until one is chosen, the zone takes each analysis's notice: "Not chosen: the zone takes each analysis's notice below until it is."
- Once one is chosen, it applies in the zone for every analysis and loading level, and each analysis's notice covers only the rest of the model
  area. **Use each analysis's notice** clears the zone's choice.
- When no loading level has the zone turned on, the row reads "Not in use: no loading level has the zone turned on."

## Run

The **Run** panel states how many loading levels are ready to run, or, under "Cannot run yet", what is missing, with a link such as **Open
Consequence Data** to the page that resolves it. The consequence simulations start only when the user starts them, and none of the controls asks for
confirmation:

- **Run all** (**Run all [N]** when some levels are ready) runs every ready loading level that has no current result.
- **Run**, **Run 1 level** or **Run [N] levels**, beside each analysis, runs that analysis's ready levels.
- The play button beside a loading level runs that level again, whatever its status.
- **Cancel** or **Cancel [N]** cancels the runs in progress, at the top or beside an analysis, and the stop button beside a level cancels that
  level.

Each level shows its mean life loss, with warning and evacuation, or its status. In the order a run goes through them, the statuses are:

- **Not run**, or **Waiting on inputs** while an input is missing.
- **Starting**, **Waiting for a model server**, then **Queued**, while the run waits for a model server.
- **Preparing**, **Simulating** (with a percentage) and **Writing results**, while LifeSim runs.
- **Cancelling**, after a cancel, for a few seconds.
- **Reading results**, then the mean life loss.
- **Result not read**, **Failed**, **Cancelled** or **Could not start** when the run did not produce a result.

A result marked **Out of date** was simulated with inputs that have since changed; it stays until the level runs again. Selecting a level's status
opens its details: the run's status and timing, any errors and warnings, the result over its 1,000 iterations (mean, median, 5th to 95th
percentile and range of life loss, the mean population at risk and the mean damages), and the hazard and notice it ran with.
