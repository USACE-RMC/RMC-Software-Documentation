# PFM-02: CLE due to Cross Valley Differential Settlement

Where the embankment settles differentially across the valley at a steep abutment slope or bench, a transverse crack can open at the crest and
concentrated leak erosion (CLE) can develop through it. The PFM-02 page estimates the system response probability (SRP) for this mechanism, potential
failure mode 02 (PFM-02). The reservoir pool loads the failure mode, and the page plots the SRP against headwater elevation. [Failure Mode
Pages](./342-failure-mode-pages.mdx) and [System Response](./343-system-response.mdx) describe the parts every failure mode page shares.

The user opens a PFM-02 location from **Response > Failure Mode Evaluation** (see [Opening a location](./341-locations.mdx#opening-a-location)).
The page heading reads **02 - CLE due to Cross Valley Differential Settlement**. To evaluate a location:

## Location and Cross Section

DST creates the PFM-02 locations from the abutment slopes and benches entered on the Dam Information page (see
[Abutment Slopes](./310-dam-information.mdx#abutment-slopes)):

- one location for each abutment whose top slope is between 15° and 65°, named **Left Abutment** or **Right Abutment**;
- one location for every bench on either abutment, named for example **Left Abutment Bench 1**.

An abutment into which a cutoff wall reaching the crest ties (Failure Mode Screening question 7a) has no locations. When no abutment yields a
location, DST provides a single location, named **Location 1**, that the team describes itself, with its own abutment slope. The team cannot add or
copy PFM-02 locations, and the locations DST creates cannot be renamed or deleted; their **Location** name is read-only in the toolbar.

:::caution

When an abutment's top slope leaves the range 15° to 65°, or a bench is removed, on the Dam Information page, DST deletes that location with its
inputs, results and justifications. A location dropped because a cutoff wall now ties into its abutment (question 7a) is hidden instead, and returns
with its inputs when the tie is removed.

:::

## Cross-Valley Settlement and Failure Pathway

The crack, and the path that concentrated leak erosion would follow through the embankment, derive from the settlement or an observed crack depth. The
**Cross-valley settlement and failure pathway** section holds those inputs and presents the resulting crack and pathway for review.

PFM-02 uses the Dam Height on the Dam Data page as the dam height for every location.

### Readings

The readings show the values DST calculates for the location, or a dash until the system response has been calculated: **Normalized settlement**
(the maximum post-construction settlement as a percentage of the dam height), the slope (**Top abutment slope**, **Slope below Bench N** or
**Abutment slope**), **Localized tensile strain**, **Crack width** (mm), **Crack depth** and **Bottom of crack** (elevation).

### Pathway figure

The drawing shows the selected cross section to scale, with the crack from the crest down to the bottom of the crack, the zones the pathway crosses,
and lines for the crest, the top of the filter, the bottom of the crack and the top of any cutoff wall. DST reads the pathway from the drawing on
the Dam Information page, so changing the drawing changes the pathway. When no crack forms, the caption reads "No transverse crack forms at this
settlement, so nothing enters the embankment through the crest."

### Node assumption cards

One card per node states how DST treats it at this location: **Flaw** (when continuous cracking is observed), **Initiation**, **Filter
compatibility**, **Sidewall support**, and, when they reduce the probability, **Flow limitation** and **Crack filling**. For example, the Initiation
card reads "Initiation is assumed to occur for all pools that exceed the bottom of the crack elevation. A probability of zero is assigned for all
pools below the bottom of the crack."

Inputs on this page save automatically (see [Saving](./040-working-in-dst.mdx#saving)), the system response recalculates automatically (see
[Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)), and a change clears the location's verification (see
[Verifying a location](./342-failure-mode-pages.mdx#verifying-a-location)).

## User-Defined SRP

With **User Defined SRP** selected, the page replaces its sections with a table of **Headwater Elevation (ft)** and **Probability** and its chart.
The table works as described in [User-defined SRP](./343-system-response.mdx#user-defined-srp).

## Failure Mode Summary

The **Failure mode summary** tray lists the screening answers this location reads that were answered Unknown (see
[Failure mode summary](./342-failure-mode-pages.mdx#failure-mode-summary)). For PFM-02, an Unknown cracking cause is treated as settlement
cracking. PFM-02 has no parameter overrides.

## Common problems

Problems every failure mode page shares, such as a system response that does not calculate, no usable cross sections or a refused verification,
are described in [Common problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages page. This page adds its own.

**An abutment or bench has no location, or a location disappeared.** DST creates a location only for an abutment whose top slope is between 15°
and 65°, and for each bench. An abutment into which a cutoff wall reaching the crest ties (Failure Mode Screening question 7a) has none. The team
checks the abutment slopes on the Dam Information page and the answer to question 7a.

**Add location, Copy location, Rename location and Delete location are not offered.** PFM-02 locations follow the abutment slopes and benches; the
team changes those on the Dam Information page instead.

**"No settlement value and no year of construction".** DST needs either the maximum post-construction settlement or the Year Completed on the Dam
Data page. The user enters **Max. settlement**, or the Year Completed on the [Dam Data](./102-dam-data.mdx) page.

**"This location's top abutment slope comes from the Dam Information page."** An abutment or bench location reads its slope from the Dam
Information page. The user enters the slope there (see [Abutment Slopes](./310-dam-information.mdx#abutment-slopes)).

**Max. settlement and the abutment slope cannot be edited.** An observed crack depth is entered, so DST uses it in place of settlement and slope.
The revert button beside **Observed crack depth** restores the calculated depth and enables them again.

**"The selected cross section is taller than the Dam Height on the Dam Data page."** The section's crest minus its downstream toe exceeds the Dam
Height. The user corrects the Dam Height on the Dam Data page or the section's geometry on the Dam Information page.

**No crack forms at a bench.** The warning "The step height at this bench (dam height minus section height) is less than 40% of the
dam height…" means the model finds too little strain at that bench for a crack; the low result is expected.
