# Preface

The Dam Screening Tool (DST) is a web application for screening-level risk analysis of dams. This User's Guide explains how to operate DST: how to
create a screening, enter its information, evaluate its potential failure modes, assemble its risk results, and take it through review. It documents
each page, input and status indicator in the application, and the workflow that connects them.

The guide is written for dam safety engineers and analysts who build screenings, and for the reviewers who read and comment on them. It assumes a
working knowledge of dam safety risk analysis; terms specific to the DST interface are defined where they first appear.

The User's Guide describes how to use DST, not the engineering behind it. The calculations DST performs are documented in the DST Technical Reference
Manual and in the System Response Library manuals for each screening model.

The example screenings and dams shown in the figures are fictional, except Blue Marsh Dam, a real dam whose National Inventory of Dams (NID) data is
public.

## Document Organization

The guide follows the layout of DST. After the opening pages, it has one section for each screening module, in the order of the module navigation,
with one page for each of the module's pages. The guide's pages fall into the following groups.

- **Getting started.** [Introduction](./020-introduction.mdx) describes what DST is and the modules of a screening.
  [Getting Started](./030-getting-started.mdx) covers accounts, signing in, the Dashboard, creating and copying screenings, the screening team and
  the Profile page. [Working in DST](./040-working-in-dst.mdx) covers the navigation and the behaviors shared by every screening page: saving,
  automatic calculation, page messages, tables, the summary tray, verification, Submission Readiness, the input lock and editing conflicts.
- **Screening information and hazards.** [Screening Information](./100-screening-information.mdx) covers the Overview, Dam Data, Operational Data,
  Screening Management and Screening Activity pages. [Documents](./150-documents.mdx) covers the screening's document library.
  [Hazards](./200-hazards.mdx) covers the Flood Hazard, Stage Duration and Seismic Hazard pages.
- **Response.** [Response](./300-response.mdx) covers the dam information and its cross-section editors, failure mode screening and selection, and
  the Failure Mode Evaluation page with the parts every failure mode page shares. The Potential Failure Modes pages each document one potential
  failure mode (PFM) page, from [PFM-01](./351-pfm-01.mdx) through [PFM-23](./369-pfm-23.mdx).
- **Consequences, risk and findings.** [Consequences](./400-consequences.mdx) covers the inundation and consequence pages.
  [Risk Analysis](./500-risk-analysis.mdx) covers the Setup and Results pages. [Major Findings](./600-major-findings.mdx) covers the screening
  team's findings and recommendations.
- **Review.** [Review](./700-review.mdx) describes taking a screening through review, for screening teams and reviewers.
- **References and appendices.** [References](./900-references.mdx) lists the works cited. The appendices give the
  [acronyms](./910-appendix-acronyms.mdx), a [glossary](./920-appendix-glossary.mdx) and a
  [quick reference to the PFM pages](./930-appendix-pfm-quick-reference.mdx).
