# Preface

The Dam Screening Tool (DST) is a web application for screening-level risk analysis of dams. This User's Guide explains how to operate DST: how to
create a screening, enter its information, evaluate its potential failure modes, assemble its risk results, and take it through review. It documents
each page, input and status indicator in the application, and the workflow that connects them.

The guide is written for dam safety engineers and analysts who build screenings, and for the reviewers who read and comment on them. It assumes a
working knowledge of dam safety risk analysis; terms specific to the DST interface are defined where they first appear.

The User's Guide describes how to use DST, not the engineering behind it. The calculations DST performs are documented in the DST Technical Reference
Manual and in the System Response Library manuals for each screening model.
