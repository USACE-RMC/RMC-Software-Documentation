# Preface

The U.S. Army Corps of Engineers (USACE) Risk Management Center (RMC) developed the Dam Screening Tool (DST) to support screening-level risk
analysis of dams within the USACE Dam Safety Program. DST is a web application in which a screening team documents a dam, evaluates its potential
failure modes, estimates consequences and risk, and takes the screening through review.

This document is a guide to performing a screening in DST. It describes the inputs each page requires, the results and messages each page reports,
and solutions to common problems.
