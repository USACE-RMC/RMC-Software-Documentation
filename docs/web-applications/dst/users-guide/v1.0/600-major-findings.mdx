# Major Findings

The Major Findings module holds the screening team's written conclusions: the characterization of the risk, the uncertainties that matter most, a
summary of the findings and the team's recommendations. Each is written as formatted text on its own page. Reviewers read these pages with the rest
of the screening during review (see [Review](./700-review.mdx)).

The module has four pages, reached from **Major Findings** in the module navigation: [Risk Characterization](./601-risk-characterization.mdx),
[Major Uncertainties](./602-major-uncertainties.mdx), [Summary of Findings](./603-summary-of-findings.mdx) and
[Recommendations](./604-recommendations.mdx). The first three are required before the screening can be submitted; Recommendations is optional. All four pages share one
layout, described below, and differ only in their purpose and prompts.

## The Major Findings Pages

Each Major Findings page has a purpose statement, a **What to consider** button and a text editor.

### The text editor

The editor accepts paragraphs, line breaks within a paragraph, bold and italic text, and bulleted and numbered lists, which can be nested with
**Indent** and **Outdent**. Text pasted from another program keeps only these formats. The editor saves the text after the user pauses typing and again when the user leaves the editor (see
[Saving](./040-working-in-dst.mdx#saving)). A page's text that grows too long to store is not saved, and DST reports the problem with the page's name first, for example
"Risk characterization: The text is too long to save." Moving to another Major Findings page, or leaving the module, also saves the text of the
page being left.

The four pages are saved together, as one record. When any of them has been saved from another session since the page was loaded, for example by
another team member, the save does not go through. DST shows the warning "Major Findings were changed in another session. The latest text has been
loaded; review it and make your change again." and reloads the pages with the latest text. The change that could not be saved is not kept, and must
be made again if it is still wanted (see [Editing Conflicts](./040-working-in-dst.mdx#editing-conflicts)). A conflict when verifying a page gives the
message "Major Findings were changed by another user. Reload the page and try again."

Changing a page's text clears that page's verification only; the other Major Findings pages keep theirs (see
[Human Verification](./040-working-in-dst.mdx#human-verification)). While the screening's inputs are locked, the editor is read-only (see
[Input Lock](./040-working-in-dst.mdx#input-lock)).

### Page messages

An empty required page reports a required input in the page messages (see [Page Messages](./040-working-in-dst.mdx#page-messages)), and the page is
Incomplete on the Submission Readiness page until it holds text. <TableReference tableKey="dst-users-guide-table-major-findings-messages" /> lists
the messages.
