# Major Findings

The Major Findings module records the screening team's conclusions: the characterization of the risk, the uncertainties that matter most, a
summary of the findings and the team's recommendations. Reviewers read these pages with the rest of the screening during review (see
[Review](./700-review.mdx)).

The module has four pages, reached from **Major Findings** in the module navigation:

- [Risk Characterization](./601-risk-characterization.mdx) (required)
- [Major Uncertainties](./602-major-uncertainties.mdx) (required)
- [Summary of Findings](./603-summary-of-findings.mdx) (required)
- [Recommendations](./604-recommendations.mdx) (optional)

The required pages must hold text before the screening can be submitted. All four pages work the same way, as described below.

## Writing a Major Findings Page

Each page has a purpose statement with a **Required** or **Optional** tag, a **What to consider** button and a text editor. To write a page, the
user selects **What to consider** for the prompts, writes the text in the editor, and verifies the page when the text is final.

The editor accepts paragraphs, line breaks, bold and italic text, and bulleted and numbered lists, which **Indent** and **Outdent** nest.

:::tip

Text can be drafted in another program and pasted in. The editor keeps its paragraphs, lists, bold and italic, and drops other formatting.

:::

The editor saves the text after the user pauses typing, when the user leaves the editor, and when the user moves to another page (see
[Saving](./040-working-in-dst.mdx#saving)). While the screening's inputs are locked, the editor is read-only (see
[Input Lock](./040-working-in-dst.mdx#input-lock)).

Changing a page's text clears that page's verification only; the other Major Findings pages keep theirs (see
[Human Verification](./040-working-in-dst.mdx#human-verification)).

    },
    {
      title: 'A change is lost because another team member edited the findings.',
      child: (
        <>
          <p>
            The four pages are saved together. When any of them was saved from another session since the page was loaded, the save does not complete,
            and DST shows "Major Findings were changed in another session. The latest text has been loaded; review it and make your change again." The
            change that could not be saved is not kept; the user makes it again on the reloaded text (see <Link
            to="/docs/web-applications/dst/users-guide/v1.0/working-in-dst#editing-conflicts">Editing Conflicts</Link>). A conflict when verifying
            reads "Major Findings were changed by another user. Reload the page and try again."
          </p>
        </>
      ),
    },
    {
      title: 'The text is not saved.',
      child: (
        <>
          <p>
            DST does not save text too long to store, and names the page, for example "Risk characterization: The text is too long to save." The user
            shortens the text.
          </p>
        </>
      ),
    },
  ]}
/>
