# Failure Mode Screening

The user opens the page from **Response > Failure Mode Screening**. The questionnaire covers earth and rockfill embankments, so the page applies only
when an earth or rockfill dam type is selected on the Dam Data page (see [Dam Data](./102-dam-data.mdx)).
Otherwise the page reads "No screening questions apply to this dam", gives the reason, for example "Failure Mode Screening covers earth and rockfill
embankments, and no earth or rockfill dam type is selected on the Dam Data page.", and links to **Review the dam types on the Dam Data page**.

The questionnaire is a series of steps, one question per step. <FigReference figKey="dst-users-guide-fig-failure-mode-screening-page" /> shows a
step, and <TableReference tableKey="dst-users-guide-table-failure-mode-screening-and-selection-screening-regions" /> describes each numbered region.

## Working through the questionnaire

The questionnaire opens on an introduction that lists the five topic groups and how the steps work. **Begin Screening** opens the first step. The
user then answers each step and moves on:

  items={[
    { title: <>The user selects an answer for each sub-question of the step. The answer saves as soon as it is selected.</> },
    { title: <>The next arrow at the right is highlighted once the step is complete. The user selects it, or presses the Right Arrow key.</> },
    {
      title: (
        <>
          After the last step, the summary reads <strong>Failure Mode Screening Complete</strong> with a link to{' '}
          <strong>Continue to Failure Mode Selection</strong>, or <strong>Failure Mode Screening In Progress</strong> with the number of steps
          remaining.
        </>
      ),
    },
  ]}
/>

The arrows and keys move between steps whether or not the current step is answered; the highlight on the next arrow only signals that the step is
done. The Right Arrow and Down Arrow keys go to the next step, and the Left Arrow and Up Arrow keys to the previous one, from the introduction
through the summary. The keys do nothing while the cursor is in a text box or a drop-down, such as the **Location name** box of question 5.

The user may answer the steps in any order by selecting them in the step list. A step that does not apply to the dam, based on the screening's
other data, is grayed with a dash in the step list. Its card states the reason, such as "No core trench is recorded in Dam Information.", and reads
"This step doesn't apply to this dam, so no response is needed." Answers save automatically (see
[Saving](./040-working-in-dst.mdx#saving)). The page messages list each unanswered question that applies as a required input, for example
"Answer question 1a on the Failure Mode Screening page." (see [Page Messages](./040-working-in-dst.mdx#page-messages)).

A link from a failure mode page to a screening question, such as **Failure Mode Screening, step 4**, opens the questionnaire at that step.

Each location selected in question 5 becomes a location of the failure modes evaluated at cliffs and walls, and those pages use its name.
An answer of **Unknown** is carried forward: the Failure Mode Selection page explains how it affected each recommendation, and the failure mode pages
list the Unknown answers they read (see [Failure mode summary](./342-failure-mode-pages.mdx#failure-mode-summary)).

## Questions that do not apply

DST marks a question as not applying when the dam's other data, or an earlier answer, already settles it. A question that does not apply needs no
answer, and the recommendations and failure modes that read it ignore any answer it holds. The answer is kept, not deleted, and counts again if the
question applies again. A step none of whose questions apply is left out of the progress count. The rules are:

- **Foundation.** When every embankment cross section on the Dam Information page is founded on rock, questions 1a, 1b and 2a do not apply ("Every
  embankment cross section is founded on rock (Dam Information)."). When every one is founded on soil, questions 1c and 2b do not apply ("Every
  embankment cross section is founded on soil (Dam Information).").
- **Core trench.** Question 3 applies only when Dam Information records a core trench ("No core trench is recorded in Dam Information.") and question
  1a applies and is not answered No ("Question 1a reports no sandy layers.").
- **Cutoff wall.** Questions 7a to 7d apply only when Dam Information records a cutoff or seepage barrier wall ("No cutoff or seepage barrier wall is
  recorded in Dam Information."). Each of 7b, 7c and 7d also follows the question about the deposit it asks the wall to cut off: 7b does not apply
  when 1c is No ("Question 1c reports no rock defects."), 7c when 1a is No, and 7d when 1b is No ("Question 1b reports no open-work gravel, cobble, or
  boulder deposits.").
- **Cracking.** Question 9b applies only when 9a is answered Yes ("Question 9a does not report transverse cracking.").
- **Walls and cliffs.** Question 12a applies only when question 5 names at least one location ("Question 5 reports no wall or cliff contact."), and
  12b only when 12a is Yes ("Question 12 does not report leakage.") and question 5 names two or more locations.
- **Conduit.** Questions 13 and 14 apply only when Dam Information records a conduit through the embankment ("No conduit through the embankment is
  recorded in Dam Information.").

An Unknown answer to an earlier question keeps the later questions open. When the earlier question does not apply itself, the later one does not
apply either and gives the same reason; for example, with a core trench on a rock foundation, question 3 gives the rock-foundation reason.

When only some of a step's sub-questions do not apply, the step stays open: those sub-questions show their reason above grayed answers, and the
step is complete once the others are answered. When none of them applies, the whole step is grayed and reads as described in
[Working through the questionnaire](#working-through-the-questionnaire).

## What an answer updates

Each saved answer updates the pages that depend on the screening. DST recalculates the recommendations on the Failure Mode Selection page (see
[Recommendation changes](./330-failure-mode-selection.mdx#recommendation-changes)) and, when the answer changes where a failure mode is evaluated,
such as the locations of question 5 or a cutoff wall that ties into an abutment in question 7a, the locations of PFM-02, PFM-03 and PFM-06. When a
recommendation changes for a failure mode the team has already decided, a notice names it, for example "The DST recommendation changed for PFM-08.
Confirm your decision on the Failure Mode Selection page."

The answer itself always saves. If an update after it cannot finish, a warning says what was left and when it catches up:

- "Failure Mode Selection recommendations could not be updated because another session changed Failure Mode Selection. They are recalculated the
  next time Failure Mode Selection is opened."
- "Failure Mode Selection recommendations could not be updated. They are recalculated the next time Failure Mode Selection is opened."
- "Some failure mode evaluation locations could not be updated because another session changed them. They are updated by the next Failure Mode
  Screening or Dam Information change."
- "Some failure mode evaluation locations could not be updated. They are updated by the next Failure Mode Screening or Dam Information change."

:::caution

Changing an answer after failure modes have been evaluated changes their inputs. DST clears the affected system responses, nodal revisions and
verifications and recalculates them, and the Failure Mode Selection recommendations may change.

:::

## Verifying the screening answers

The screening team verifies the page as a whole with the verification badge in the sub-navigation bar (see
[Human Verification](./040-working-in-dst.mdx#human-verification)). Changing any answer clears its verification. A page that does not apply to
the dam has nothing to verify.
