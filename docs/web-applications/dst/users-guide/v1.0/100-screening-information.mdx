# Screening Information

The Screening Information module holds the description of the screening, the dam's data and the reservoir's operating curves, together with the
screening team, the review levels and the screening history. A screening opens on this module's Overview page.

The module has five pages:

- [Overview](./101-overview.mdx): the screening's description and the dam's location on a map.
- [Dam Data](./102-dam-data.mdx): the dam's identity, types, dimensions, key elevations and reservoir data.
- [Operational Data](./103-operational-data.mdx): the stage-storage, stage-outflow and tailwater curves.
- [Screening Management](./104-screening-management.mdx): the screening team, access requests and review levels (Facilitator and administrators
  only).
- [Screening Activity](./105-screening-activity.mdx): a history of the screening's milestones and team changes.

The Hazards, Response and Consequences modules start from the dam data and key elevations entered here, and the operating curves feed the
consequence routing and some failure mode evaluations. The screening team verifies Dam Data and Operational Data (see
[Human Verification](./040-working-in-dst.mdx#human-verification)); the other three pages have nothing to verify.
