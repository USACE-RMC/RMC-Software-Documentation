# PFM-18: Concrete Lined Spillway Failure

A concrete-lined spillway can fail when stagnation pressure and scour, with or without slab uplift, undermine the spillway and advance to breach.
PFM-18, Concrete Lined Spillway Failure, represents this sequence, and the PFM-18 page estimates its SRP at one location with an event tree. The loading is the reservoir pool above the spillway crest, evaluated at stages from the
spillway crest to the top of dam.

The user opens a PFM-18 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).
[Event Trees](./344-event-trees.mdx) describes the parts that every event-tree page shares, and
[Failure Mode Pages](./342-failure-mode-pages.mdx) the parts that every failure mode page shares. To evaluate a location:

The tree branches at Node 1, Slab Uplift. Branch a, "Slab Uplift = Yes", follows Nodes 1, 2a, 3a, 4a, 5a, 6a, 7a and 8a. Branch b, "Slab Uplift
= No", follows Nodes 1 (No), 2b, 3b, 4b, 5b, 6b, 7b and 8b, where "(No)" marks the node whose No outcome the branch takes.

Each Branch b node from 2b to 8b can mirror the Branch a node with the same number. To copy a Branch a node's probabilities, the user selects the
Branch b node and checks **Mirror Node [n]a** in its panel; mirroring is off by default (see [Mirrored Nodes](./344-event-trees.mdx#mirrored-nodes)).

:::tip

When the two branches share most of their judgments, mirroring the Branch b nodes saves entering the same probabilities and rationales twice. The
user then overrides only the stages that differ; each override applies to that stage alone.

:::

[Nodes](./344-event-trees.mdx#nodes) describes entering probabilities and rationales and moving between nodes. The **Failure mode summary** tray
repeats every node's probabilities (see [Failure Mode Summary](./342-failure-mode-pages.mdx#failure-mode-summary)).

## User-Defined SRP

With **User defined** selected in the toolbar, the user enters the SRP curve as **Pool Elevation (ft)** and **Probability** pairs in place of the
event tree. DST keeps the stages, node probabilities and rationales, and shows them again when the user selects **Event tree** (see
[User-Defined SRP](./343-system-response.mdx#user-defined-srp)).

## Common Problems

PFM-18 has no problems of its own beyond those every event-tree page shares, such as "No system response curve yet", a stage that reads
Source missing or a default stage that cannot be edited (see [Common Problems](./344-event-trees.mdx#common-problems) on the Event Trees
page), and those every failure mode page shares (see [Common Problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages
page).
