# Risk Analysis

The Risk Analysis module combines the hazard, the system response of each potential failure mode and the consequences into risk estimates for each
failure mode and for the dam. DST computes the risk with RMC-TotalRisk. The module has two pages, reached from **Risk Analysis** in the module
navigation: **Setup**, which assigns a consequence function to each failure mode, and **Results**, which shows the risk.

The failure modes, hazards and system responses come from earlier pages: the failure modes selected for evaluation (see
[Chapter 10, Failure Mode Screening and Selection](./10-failure-mode-screening-and-selection.mdx)), the hazard pages (see
[Chapter 7, Hazards](./07-hazards.mdx)) and the active system response of each location (see
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx)). The consequence functions come from the Results Data page (see
[Chapter 31, Consequences](./31-consequences.mdx#results-data)). The risk calculation methods are described in the DST Technical Reference Manual and
the RMC-TotalRisk documentation.

Neither page is verified. Risk recomputes automatically whenever an input changes (see
[Automatic Calculation](./04-working-in-dst.mdx#automatic-calculation)), and both pages report missing inputs and warnings in the page messages (see
[Page Messages](./04-working-in-dst.mdx#page-messages)).

## Setup

The Setup page, at **Risk Analysis > Setup**, lists every failure mode in the risk analysis and assigns each its consequence function. Selecting
**Risk Analysis** in the module navigation opens it.

The page holds, from top to bottom, the **Non-failure consequences** row, the setup table, the compute status with **Export to TotalRisk**, and the
**Mean Risk Plot for Excess Societal Risk** preview, which sits beside the table on wide screens.

### Non-failure consequences

The **Non-failure consequences** row names the non-failure function chosen on the Results Data page, which represents the conditions when the dam
does not fail and applies to every failure mode. It is read-only here; **Change on Results Data** opens that page. With no non-failure function, the
row reads "None selected: taken as zero", and the background consequences are taken as zero.

### The setup table

The setup table has one row per failure mode, with a row beneath it for each of its locations, and a **Total** row at the bottom.

<TableReference tableKey="dst-users-guide-table-risk-setup-columns" /> lists its columns. The one input on the page is the **Consequence Function** of
each failure mode; it saves when chosen (see [Saving](./04-working-in-dst.mdx#saving)). The locations share their failure mode's function.

The failure mode rows show marginal risk. The **Total** row is the system-combined (adjusted) result, computed once every row is complete. An
incomplete row has an amber edge, and the page messages give the reason, such as "no consequence function" or "no active system response curve".

### Compute status and export

The status beside the table reads "Computing…", "Computed [time]", "[K] of [N] failure modes need input" or "Not computed". Results reflect the
current inputs and recompute when anything upstream changes.

**Export to TotalRisk** downloads an RMC-TotalRisk project (.tra) with the system diagram and one diagram for each failure mode location, for life
loss and economic cost. It does not need a computed result.

### Risk preview

The **Mean Risk Plot for Excess Societal Risk** plots each failure mode, once its inputs are complete, and the **Total (adjusted)**, as annual
probability of failure against expected life loss given failure, with the tolerable risk guideline line for EALL = 1E-03. Failure modes with an
APF below 1E-07 are not plotted and are listed in a footnote. The full results are on the Results page.

## Results

The Results page, at **Risk Analysis > Results**, shows the risk of the screening. It has no inputs; its toggles only change the view. While the risk
computes, the page reads "Computing risk results…", and values not yet computed show "—".

### Excess Risk Summary

Four tiles summarize the excess risk: **Total APF** (the adjusted annual probability of failure), **Total EALL** (the expected annual life loss),
**Total EAD** (the expected annual damages) and **Individual Risk**, which is the total APF times a fatality rate. The fatality rate is the highest
fatality rate of the failure functions in use, from the loading level or table row it comes from, or 71%, the LifeSim average fatality rate for a high
hazard individual, when none of the functions has one.

### Societal Excess Life Safety Risk

This section shows the life safety risk of failure, above the background risk:

- **Mean Risk Plot for Excess Societal Risk** plots each failure mode and the **Total (adjusted)** as APF against expected life loss given failure.
  **TRG line** (on by default) shows the EALL = 1E-03 line, and **Adjusted PFM values** (off by default) plots the failure modes' adjusted values in
  place of their marginal ones.
- **Loss Exceedance Curve for Expected Annual Life Loss** plots the annual exceedance probability of each excess life loss.
- **Risk Contribution** lists the share of the adjusted total APF and EALL from each failure mode, the top eight and then "All others". Resting the
  pointer on a row highlights its series on the plots.

### Societal Excess Economic Risk

This section shows the same views for damages: the **Mean Risk Plot for Excess Economic Risk**, with expected damages given failure, the **Loss
Exceedance Curve for Expected Annual Damages**, and the failure modes' **Risk Contribution** to EAD.

### Total Risk

This section adds the background risk from the non-failure function to the excess risk. The **Loss Exceedance Curves for Annual Life Loss** and
**Loss Exceedance Curves for Annual Damages** plot the **Excess**, **Background** and **Total** curves.

<TableReference tableKey="dst-users-guide-table-risk-components" /> lists the rows of the risk components table, which gives each as life (EALL) and
economic (EAD) risk. **Risk Contribution** bars show the excess and background risk as shares of the total.
