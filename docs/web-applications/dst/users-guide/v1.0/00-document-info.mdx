reportAbstract: The Dam Screening Tool (DST) is a web application for screening-level risk analysis of dams. This User's Guide explains how to operate DST to create a screening, enter its information, evaluate its potential failure modes, assemble its risk results and take it through review. It documents every page, input and status indicator in the application and the workflow that connects them. The engineering methods behind the calculations are documented separately in the DST Technical Reference Manual and the System Response Library manuals.
