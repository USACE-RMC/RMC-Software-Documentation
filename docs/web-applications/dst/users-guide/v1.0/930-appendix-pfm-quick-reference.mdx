# Appendix: PFM Quick Reference

DST evaluates 19 potential failure modes, each on its own page under **Response > Failure Mode Evaluation**.

<TableReference tableKey="dst-users-guide-table-pfm-quick-reference" /> lists each one with its name as shown in DST, its loading, the nodes for which
the page takes a probability, and the page of this guide that documents it.

Every failure mode page also takes a location name, and most take a cross section, characterization inputs and a rationale for each estimate. Pages
marked "System response nodes" build the system response from nodal tables (see
[System Response](./343-system-response.mdx)); pages marked "Event tree nodes" build it from an event tree evaluated at a
set of stages (see [Event Trees](./344-event-trees.mdx)). Every page can instead take a user-defined system response curve.
