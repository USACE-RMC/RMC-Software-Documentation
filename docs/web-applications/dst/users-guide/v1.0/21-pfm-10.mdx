# PFM-10: Foundation Backward Erosion Piping

Potential failure mode 10 (PFM-10) is backward erosion piping in a sand layer of the foundation: seepage under the embankment exits downstream, erodes
the sand at an unfiltered exit, and a pipe works back toward the reservoir. The loading is the reservoir (headwater), which drives the seepage. The
PFM-10 page characterizes the foundation sand, any confining layer above it, the upstream and downstream seepage path, the support for the pipe roof
and the observed seepage, and produces the system response probability (SRP) curve for each location. [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#the-failure-mode-page) describes the parts of the page that every failure mode page shares.

The user opens a PFM-10 location from the Failure Mode Evaluation page (**Response > Failure Mode Evaluation**, then the location under PFM-10; see
[Opening a location](./11-failure-mode-evaluation.mdx#opening-a-location)). The page heading reads **10 - Foundation Backward Erosion Piping**. The
characterization is laid out as eight numbered sections, and each answer decides which inputs the later sections show.

## Downstream Seepage Berm

Section 6, **Downstream seepage berm**, is read-only and comes from the seepage berm drawn in the selected cross section on the Dam Information page
(see [Chapter 9, Cross-Section Editors](./09-cross-section-editors.mdx#berm-tab)). With a berm it shows **Berm length from downstream embankment
toe** (ft) and **Berm-toe ground elevation** (ft), and a "Drawn berm geometry is incomplete" notice when the berm has no usable length. Without one it
shows "No drawn seepage berm"; without a usable cross section it shows "Cross section required".

## Pipe Roof Support

Section 7, **Pipe roof support**, sets what holds up the roof of a developing pipe. With a confining layer (**Yes**) it reads "The confining layer
supports the pipe roof" and "No embankment material needs to be selected." With **No** or **Unknown** it shows **Materials that can support the pipe
roof**, a set of material cards from the selected cross section, each with its name and material type ("Type not assigned" when none). The defaults,
marked "(Default)", are the materials along the embankment base, and they are selected to start. The user selects or clears cards; at least one is
required. Any other selection is an override (see [Characterization](./11-failure-mode-evaluation.mdx#characterization)). When no material qualifies, the section reads "No materials in the cross section can support a pipe roof yet." with a link
to the Dam Information page.

## System Response

The **System Response** section shows the PFM-10 SRP curve, its table and the seven nodal tables, as described in Chapter 11, Failure Mode Evaluation ([System Response](./11-failure-mode-evaluation.mdx#system-response), [SRP charts](./11-failure-mode-evaluation.mdx#srp-charts), [Nodal tables](./11-failure-mode-evaluation.mdx#nodal-tables)). When the seepage system has a daylight exit as well as the toe exit, DST evaluates two
exit pathways, and the section reads "Two exit pathways are evaluated — the toe path and the daylight exit. The governing curve is the per-pool
maximum of the two." The table then has the columns **Headwater Elevation (ft)**, **Toe Pathway**, **Daylight Pathway** and **Governing**; with a
single exit it has **Headwater Elevation (ft)**, **DST Estimate** and **Revised Estimate**. <FigReference figKey="dst-users-guide-fig-pfm-10-system-response" />
shows the two-pathway table and chart.

## User-Defined SRP

With **User Defined SRP** selected, the page replaces the characterization and system response sections with a grid of headwater elevations and
probabilities and its chart, with **Headwater Elevation (ft)** on the x axis. [User-defined SRP](./11-failure-mode-evaluation.mdx#user-defined-srp) and [Active SRP](./11-failure-mode-evaluation.mdx#active-srp) describe the grid and the switch between modes.
