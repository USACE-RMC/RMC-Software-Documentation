# Getting Started

Every session in the Dam Screening Tool (DST) begins on the Dashboard. The Dashboard lists the screenings the user works on, the review assignments the
user holds, and a catalog of every official screening in DST. From the Dashboard the user creates new screenings, opens existing ones, manages each
screening's team, and requests access to screenings owned by others.

This chapter describes the Dashboard and the actions available from it. Working inside a screening — navigation, automatic saving, verification and
the other behaviors shared by every screening page — is described in [Chapter 4, Working in DST](./04-working-in-dst.mdx).

### My Screenings

The **My Screenings** tab lists every screening on which the user is the Facilitator, a Team Member or a Viewer. Screenings on which the user is only a
reviewer appear on the My Reviews tab instead. Selecting a screening's name opens that screening.

Selecting a column heading sorts the table by that column, and selecting it again reverses the order. The table opens sorted by **Modified**, newest
first. **Status** sorts in workflow order rather than alphabetically.

A screening's **Type** is set when it is created:

- **Official** — a formal screening that can be submitted for review and approval.
- **Testing** — a practice screening. A Testing screening cannot be submitted for review, never appears in the Search Catalog, and shows **N/A** for
  its status.

An Official screening shows one of these statuses:

- **In Progress** — the screening team is entering and evaluating the screening. A screening also returns to In Progress if a review lead rejects it.
- **Submitted** — the Facilitator has submitted the screening. Submission starts the first review level immediately, so this status is usually brief.
- **Under Review** — one of the screening's review levels is in progress. Inputs are locked except during a review level's resolution period.
- **Complete** — every review level is approved.
- **Needs Facilitator** — the screening lost its Facilitator, for example because the Facilitator's account was deactivated. Inputs stay locked until an
  administrator assigns a new Facilitator.

The review process behind these statuses is described in Chapter 27, Review.

#### Finding a screening

The filter bar narrows the list:

- **Status** — All, In Progress, Submitted, Under Review, Complete or Needs Facilitator.
- **Type** — All, Official or Testing.
- **Per page** — 15, 25 or 50 screenings per page.
- **Search** — matches any part of the screening name, dam name or description, and a whole number also matches that screening ID. Pressing the **/**
  key moves the cursor to the search box.
- **All screenings** (administrators only) — lists every screening in DST, not only the administrator's own.

Each active filter appears as a chip below the bar; × on a chip removes that filter, and **Clear all** removes them all. When more screenings match than
fit on one page, the page controls below the table move between pages.

### My Reviews

The **My Reviews** tab lists every review level on which the user is a reviewer
(<FigReference figKey="dst-users-guide-fig-dashboard-my-reviews" />). It is organized into three tables:

- **Active Reviews** — review levels in progress now, or about to start because every earlier level is approved. Rows that need the user's action are
  listed first.
- **Upcoming Reviews** — review levels that will start after an earlier level finishes.
- **Completed Reviews** — approved review levels, newest first. The **Show** drop-down sets how far back the list reaches: the last 90 days (the

The **Dam** field searches the NID as the user types, by dam name, state, NID ID or county. Each match shows the dam's Federal ID and name with its
county and state beneath. The last choice in the list is always **Use "…" as entered**, for a dam that is not in the NID
(<FigReference figKey="dst-users-guide-fig-dashboard-new-screening-dam-search" />).

  screening will not be linked to the NID and that the dam information will be entered manually
  (<FigReference figKey="dst-users-guide-fig-dashboard-new-screening" />).

### USACE dams

An Official screening of a dam owned by USACE needs a USACE Facilitator. When the user selects a USACE dam from the NID, the **USACE Facilitator** field
appears (<FigReference figKey="dst-users-guide-fig-dashboard-new-screening-usace-facilitator" />). It searches the members of the USACE Facilitators
group by name or email; the user selects a person, and **Change** replaces the selection.

<Figure
  figKey="dst-users-guide-fig-dashboard-new-screening-usace-facilitator"

The selected Facilitator becomes the screening's Facilitator and is notified, and the user who created the screening joins its team as a Team Member.
For every other screening — any non-USACE dam, and any Testing screening — the user who creates it becomes its Facilitator. If the USACE Facilitators
group has no members, DST reports "No USACE Facilitators available. Contact your administrator." and the screening cannot be created until an
administrator adds one.

### After the screening is created

DST opens the new screening's Screening Information page. No confirmation message appears. Every new screening starts with two review levels, Level 1 and
Level 2. DST also begins collecting background data for the dam — reservoir data for the stage-duration curve, and seismic hazard data where the dam's
location supports it — which may take a few minutes to appear on the Hazards pages.

## Managing Screenings

### Managing the screening team

**Manage Team** in a screening's row actions opens the Manage Team dialog (<FigReference figKey="dst-users-guide-fig-dashboard-manage-team" />). It is
available to the screening's Facilitator and to administrators.

<Figure
  figKey="dst-users-guide-fig-dashboard-manage-team"
  src="figures/web-applications/dst/users-guide/v1.0/figures/dashboard-manage-team.png"
  alt="The Manage Team dialog. The Facilitator section shows Automation Test with an email address and a Replace link. The Team Members section lists Team Member Two with a role drop-down set to Team Member and a remove icon. The Add Member section has a search box reading 'Search by name or email...' and a role drop-down set to Team Member."
  caption="The Manage Team dialog."

- **Facilitator** — shows the screening's Facilitator. An administrator can select **Replace** to assign a different Facilitator while the screening
  is In Progress or Testing. The previous Facilitator loses access to the screening.
- **Team Members** — lists the screening's Team Members and Viewers. The role drop-down switches a person between Team Member and Viewer, and the remove
  icon removes the person from the screening.
- **Add Member** — searches active users by name or email. The user chooses the role in the drop-down beside the search box and selects
  **+ Add as Team Member** or **+ Add as Viewer** on the person.

Every change in this dialog takes effect immediately, with no confirmation step, and DST confirms each one. Reviewers are not managed here; they are
assigned to each review level on the screening's Review page.

While a screening is under review, Team Members and Viewers can still be added and removed, but the Facilitator stays fixed. Once a screening is Complete,
or while it needs a Facilitator, only Viewer access can be changed. The dialog states which of these applies.

### Copying a screening

**Copy** creates a new screening from an existing one. Anyone on the screening can copy it. The **Copy Screening** dialog names the copy "(Copy)"
followed by the original name and asks for its **Type**, which defaults to the original's. The user becomes the Facilitator of the copy, except for an
Official copy of a USACE dam, which needs a USACE Facilitator as described in [USACE dams](#usace-dams).

A copy carries over the screening's name, description, vertical datum, units and dam data. It does not carry over hazards, the information
entered on the Dam Information pages, failure mode screening, selection or evaluation, consequences, risk analysis, Major Findings, documents, the
screening team, or review history, and the dam data in the copy is unverified. The copy starts with its own Level 1 and Level 2 review levels and opens
on its Screening Information page.

### Renaming a screening

**Rename** opens a dialog with the screening's current name. The user edits the name (up to 200 characters) and selects **Rename**; DST confirms the new
name. A screening can be renamed only while it is In Progress or Testing. If another user changed the screening at the same moment, DST reports that the
page was refreshed and the rename is not applied; the user renames it again.
