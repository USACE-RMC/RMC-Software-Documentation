# PFM-05: CLE due to Poor Compaction Adjacent to a Conduit

Use this page to estimate the system response probability (SRP) for concentrated leak erosion (CLE) along a flaw in poorly compacted fill beside a
conduit through the embankment. Potential failure mode 05 (PFM-05) is loaded by the reservoir pool, and the page plots the SRP against headwater
elevation. [Failure Mode Pages](./342-failure-mode-pages.mdx) and
[System Response](./343-system-response.mdx) describe the parts every failure mode page shares.

The user opens a PFM-05 location from **Response > Failure Mode Evaluation** (see [Opening a location](./341-locations.mdx#opening-a-location)).
The page heading reads **05 - CLE due to Poor Compaction Adjacent to a Conduit**. To evaluate a location:

### Pathway figure and readings

The drawing shows the selected cross section with the conduit and the pathway along it. The readings show **Observed leakage**
(Yes, No, Unknown or Not answered, from Failure Mode Screening question 13, with a link to step 13), **Conduit base** and **Embankment base**
(elevations from the Dam Information page, with a note when the conduit lies below an embankment toe) and **Diaphragm filter** (the conduit filter
material, Recorded when a filter exists without a description or type, or None).

### Node assumption cards

One card per node states how DST treats it at this location: **Flaw** (when leakage is observed), **Initiation**, **Filter
compatibility**, **Roof support**, and, when it reduces the probability, **Crack filling**.

description reads "Screening defaults come from the governing initiation material and stay locked until a site-specific distribution is chosen."

## Common problems

Problems every failure mode page shares, such as a system response that does not calculate, no usable cross sections or a refused verification,
are described in [Common problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages page. This page adds its own.

**The Conduit construction drop-downs are disabled.** Failure Mode Screening question 13 reports leakage adjacent to the conduit, so DST carries the
flaw as certain and does not use the four construction inputs. To use them, the user changes the answer to question 13 on
[Failure Mode Screening](./320-failure-mode-screening.mdx).

**The Initiation material drop-down reads "No usable materials".** The note below it reads "No selected pathway material carries a USCS
classification with a default critical shear stress. Adjust the Pathway materials selection." The user adds a classified material to **Pathway
materials**, or assigns a supported USCS classification to the material on the Dam Information page.

**"Select at least one plastic or cohesive pathway material for the critical shear stress model."** None of the selected pathway materials is
plastic or cohesive. The user adds one to **Pathway materials**, such as the core material.

**"The initiation material selected for this location is no longer one of the conduit pathway materials. The model default is in use again."** The
chosen initiation material is no longer among the pathway materials, for example after the user removed it from **Pathway materials**. DST has
returned to the default; the user chooses the material again if the override still applies.

**A warning says the entered seepage path length is longer than the derived length.** A longer path lowers the calculated initiation. The user
selects the reset button beside **Seepage path length** to restore the derived length, or keeps the value when site information supports it.

**"Select the Conduit Filter material type on the Dam Information page so filter continuation can be evaluated."** The Dam Information page records a
conduit filter without a material type. The user selects the type on [Dam Information](./310-dam-information.mdx).

**Warnings say the conduit base is below the embankment toes or the lowest point of the cross section.** The conduit base on the Dam Information page
lies below the embankment base. DST still calculates with the conduit base as entered; the user confirms that elevation on the Dam Information page.
