# PFM-05: CLE due to Poor Compaction Adjacent to a Conduit

A conduit through the embankment can leave poorly compacted fill beside it, and a flaw in that fill offers a path for CLE.
PFM-05 covers this mechanism. It is loaded by the reservoir pool, and its page estimates the SRP against headwater elevation. [Failure Mode Pages](./342-failure-mode-pages.mdx) and [System Response](./343-system-response.mdx) describe the
parts every failure mode page shares.

The user opens a PFM-05 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).
The page heading reads **05 - CLE due to Poor Compaction Adjacent to a Conduit**. To evaluate a location:

**Copy location** copies a location with all of its inputs, overrides and results (see [Locations](./341-locations.mdx)).

### Pathway Figure and Readings

The drawing shows the selected cross section with the conduit and the pathway along it. The readings show **Observed leakage**
(Yes, No, Unknown or Not answered, from Failure Mode Screening question 13, with a link to step 13), **Conduit base** and **Embankment base**
(elevations from the Dam Information page, with a note when the conduit lies below an embankment toe) and **Diaphragm filter** (the conduit filter
material, Recorded when a filter exists without a description or type, or None).

### Node Assumption Cards

One card per node states how DST treats it at this location: **Flaw** (when leakage is observed), **Initiation**, **Filter
compatibility**, **Roof support**, and, when it reduces the probability, **Crack filling**.

### Advanced Initiation Overrides

**Advanced initiation overrides** holds site-specific distributions that replace the screening defaults for the two initiation
parameters. Its
description reads "Screening defaults come from the governing initiation material and stay locked until a site-specific distribution is chosen."

[Verifying a Location](./342-failure-mode-pages.mdx#verifying-a-location)).
