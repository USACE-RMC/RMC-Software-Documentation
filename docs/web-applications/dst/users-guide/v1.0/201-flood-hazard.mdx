## Source

The control at the right of the toolbar chooses where the curve comes from. **DST Based** is shown but not yet available; resting the pointer on it
shows "DST Based flood hazard is not available yet. Enter the curve using User Defined." The user enters the curve with **User Defined**.

## Flood hazard curve

The user enters the curve in the table, one point per row, from the most frequent flood to the rarest. The table works like the other tables in DST,
including pasting a block of rows from a spreadsheet (see [Tables](./040-working-in-dst.mdx#tables)), and it saves shortly after each change (see
[Saving](./040-working-in-dst.mdx#saving)). <TableReference tableKey="dst-users-guide-table-hazards-flood-hazard-inputs" /> describes its columns.

The chart plots stage against AEP on a probability scale, with the rarest floods at the right. Horizontal lines mark the **Normal pool**, **Spillway
crest** and **Top of dam** elevations from the Dam Data page, where they are entered; lines at the same elevation are folded into one labeled line.
The chart redraws as rows save.

Until the table holds a point to plot, the chart area reads "Enter exceedance probabilities and stages in the table to plot the hazard curve."
When the page is read-only, it reads "No flood hazard curve has been entered." instead. Once the curve is plotted, the chart zooms and pans (see
[Charts](./040-working-in-dst.mdx#charts)). The chart has no download button; the values are in the table.

## Flood hazard summary

The summary tray, **Flood hazard summary**, holds one required section, **Basis of the flood hazard curve**: "The source study or analysis, how the
upper tail was extended, and any judgment applied." The tray status reads "No justification yet" until the user enters it, and "Justification on
file" afterwards. The tray ends with the page's supporting documents (see
[Supporting Documents](./150-documents.mdx#supporting-documents)).
