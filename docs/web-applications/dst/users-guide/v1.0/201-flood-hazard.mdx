# Flood Hazard

The flood hazard curve relates the reservoir stage to its annual exceedance probability (AEP) and serves as the loading of the flood-loaded
failure modes. The Flood Hazard page (**Hazards > Flood Hazard**) holds the curve.

<FigReference figKey="dst-users-guide-fig-flood-hazard-user-defined" /> shows the page, and
<TableReference tableKey="dst-users-guide-table-hazards-flood-hazard-regions" /> describes each numbered region.

## Source

The source control at the top of the page chooses where the curve comes from. **DST Based** is not yet available; resting the pointer on it shows
"DST Based flood hazard is not available yet. Enter the curve using User Defined." The user enters the curve with **User Defined**.

## Entering the Curve

The user enters the curve in the table, one point per row, from the most frequent flood to the rarest.
<TableReference tableKey="dst-users-guide-table-hazards-flood-hazard-inputs" /> describes the columns.

<ProcessList
  items={[

:::tip
A curve kept in a spreadsheet can be copied as a block and pasted into the table; the table adds the rows it needs. Pressing Tab in the last cell
also adds a row (see [Tables](./040-working-in-dst.mdx#tables)).
:::

## Reading the Chart

The chart plots stage against AEP on a probability scale, with the rarest floods at the right. Horizontal lines mark the **Normal pool**, **Spillway
crest** and **Top of dam** elevations entered on the Dam Data page, showing where the curve crosses each one. The chart zooms and pans (see
[Charts](./040-working-in-dst.mdx#charts)).

Until the table holds a point to plot, the chart reads "Enter exceedance probabilities and stages in the table to plot the hazard curve." On a
read-only page with no curve, it reads "No flood hazard curve has been entered."

## Flood Hazard Summary

The summary tray, **Flood hazard summary**, holds one required section, **Basis of the flood hazard curve**: "The source study or analysis, how the
upper tail was extended, and any judgment applied." The tray status reads "No justification yet" until the user enters it, and "Justification on
file" afterwards. The tray also holds the page's supporting documents (see [Supporting Documents](./150-documents.mdx#supporting-documents)).

[Page Messages](./040-working-in-dst.mdx#page-messages)). <TableReference tableKey="dst-users-guide-table-hazards-flood-hazard-messages" /> lists
