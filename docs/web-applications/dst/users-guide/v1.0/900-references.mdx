# References

This guide describes the use of DST. The documents below describe the methods behind its calculations and the programs it uses.

## Dam Screening Tool

The DST Technical Reference Manual documents the methods behind DST's calculations.

- U.S. Army Corps of Engineers, Risk Management Center. _Dam Screening Tool Technical Reference Manual_. Lakewood, CO: U.S. Army Corps of
  Engineers, Risk Management Center. In preparation.

## System Response Library

The System Response Library manuals document the screening models that DST uses to estimate system response for its potential failure modes. All are
published by the U.S. Army Corps of Engineers, Risk Management Center, Lakewood, CO, and are in preparation.

- _Overtopping Erosion Screening Technical Reference Manual_.
- _Backward Erosion Piping Screening Technical Reference Manual_.
- _Continuation (Filter Evaluation) Screening Technical Reference Manual_.
- _Concentrated Leak Erosion Common Methods Screening Technical Reference Manual_.
- _CLE Cross-Valley Settlement Screening Technical Reference Manual_.
- _CLE Wall/Cliff Settlement Screening Technical Reference Manual_.
- _CLE Core Compaction Screening Technical Reference Manual_.
- _CLE Conduit Compaction Screening Technical Reference Manual_.
- _CLE Wall/Cliff Compaction Screening Technical Reference Manual_.
- _CLE Foundation/Abutment Compaction Screening Technical Reference Manual_.
- _CLE Desiccation Screening Technical Reference Manual_.
- _CLE Freezing Screening Technical Reference Manual_.
- _Gravity Dam Stability Screening Technical Reference Manual_.

## Programs Used by DST

DST runs HEC-RAS for its flood simulations, LifeSim for its consequence simulations and RMC-TotalRisk for its risk calculations.

- Hydrologic Engineering Center. _HEC-RAS Documentation_. Davis, CA: U.S. Army Corps of Engineers, Hydrologic Engineering Center. Available at
  https://www.hec.usace.army.mil/software/hec-ras/documentation.aspx.
- Risk Management Center. _LifeSim User's Guide_. Davis, CA: U.S. Army Corps of Engineers, Institute for Water Resources, 2021. Available at
  [LifeSim User's Guide](/docs/desktop-applications/lifesim/users-guide/v1.0/document-info).
- C. H. Smith and W. L. Fields. _RMC-TotalRisk User's Guide_. Lakewood, CO: U.S. Army Corps of Engineers, Risk Management Center, 2025. Available
  at [RMC-TotalRisk User's Guide](/docs/desktop-applications/rmc-totalrisk/users-guide/v1.0/document-info).
