# PFM-13: Embankment Slope Instability

An unstable earth embankment slope can lead to breach in two ways: the initial slope failure either lowers the crest and releases the reservoir at
once, or it continues as retrogressive instability through the crest. The PFM-13 page estimates the system response probability (SRP) of this
potential failure mode 13 (PFM-13), Embankment Slope Instability, at one location with an event tree that follows both outcomes. The loading is the
reservoir pool, evaluated at the normal pool, the spillway crest and the top of dam.

The user opens a PFM-13 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).
[Event Trees](./344-event-trees.mdx) describes the parts that every event-tree page shares, and
[Failure Mode Pages](./342-failure-mode-pages.mdx) the parts that every failure mode page shares. To evaluate a location:

location keeps the cross section, stages, node probabilities and rationales of the original (see [Copying a Location](./341-locations.mdx#copying-a-location)).

changes the value on its source page, then selects **Move stage to** in the notice that appears on this page. [Stages](./344-event-trees.mdx#stages) describes the zero point and adding, editing and deleting stages.

## User-Defined SRP

With **User defined** selected in the toolbar, the user enters the SRP curve as **Pool Elevation (ft)** and **Probability** pairs in place of the
event tree. DST keeps the stages, node probabilities and rationales, and shows them again when the user selects **Event tree** (see
[User-Defined SRP](./343-system-response.mdx#user-defined-srp)).

## Common Problems

PFM-13 has no problems of its own beyond those every event-tree page shares, such as "No system response curve yet", a stage that reads
Source missing or a default stage that cannot be edited (see [Common Problems](./344-event-trees.mdx#common-problems) on the Event Trees
page), and those every failure mode page shares (see [Common Problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages
page).
