# Screening Activity

Use the Screening Activity page to see who moved the screening through each stage of its life and review, and when, and who joined or left the team.
The user reaches it from **Screening Information > Screening Activity**. The page is a read-only history, oldest first, and everyone on the screening
can view it. <FigReference figKey="dst-users-guide-fig-screening-activity" /> shows the page, and
<TableReference tableKey="dst-users-guide-table-screening-information-activity-regions" /> describes each numbered region.

The timeline records two kinds of entry:

- **Milestones** — the screening created or copied; submitted for review; each review period started and ended; backcheck submitted or returned; a
  tentative decision submitted or retracted; each review level approved or rejected; and the screening completed. Other recorded events, such as an
  access request, also appear. Some milestones add a line of detail beneath the description.
- **Team changes** — members added or removed, role changes, and the Facilitator assigned, replaced or claimed.

Each entry names the user who acted, except the assignments DST makes on its own when a screening is created or copied. A screening with no
recorded activity shows "No activity recorded."

Four or more team changes in a row collapse into a single row that reads, for example, "6 team changes". Selecting the row shows each change, and
selecting it again hides them. <VideoReference videoKey="dst-users-guide-video-screening-activity-runs" /> shows a run of team changes expanded and
collapsed.

## Common problems

- **A recent change does not appear.** The page loads the history when it opens and does not update while it stays open. The user reloads the page,
  or leaves it and opens it again.
