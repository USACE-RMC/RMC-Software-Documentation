# Screening Activity

The Screening Activity page is a read-only history of the screening, oldest first. The user reaches it from
**Screening Information > Screening Activity**. Everyone on the screening can view it.

The page is the screening's audit trail. It lets the team and the reviewers see who moved the screening through each stage of its life and of its
review, when, and who joined or left the team. DST records each entry as the event happens; the page only displays them.

The timeline records two kinds of entry:

- **Milestones** — the screening created or copied; submitted for review; each review period started and ended; backcheck submitted or returned; a
  tentative decision submitted or retracted; each review level approved or rejected; and the screening completed. An approval and the completion
  have a green icon, a rejection a red one, and a returned backcheck or a submitted tentative decision an amber one. Other recorded events, such as an
  access request, appear as cards with a general activity icon. Some milestones add a line of detail beneath the description.
- **Team changes** — members added or removed, role changes, and the Facilitator assigned, replaced or claimed.

Each entry names the user who acted, except the assignments DST makes on its own when a screening is created or copied. A screening with no
recorded activity shows "No activity recorded."

Team changes are often made in bursts, for example when a team is set up, so four or more of them in a row collapse into a single row that reads, for
example, "6 team changes". Selecting the row expands it to show each change as a smaller row on the timeline line, and selecting it again collapses
it. Fewer than four team changes in a row are always shown in full.

The page loads the history once, when it opens, and does not update while it stays open. Events that happen in the meantime, by this user or
anyone else, appear when the user reloads the page or leaves it and opens it again.
