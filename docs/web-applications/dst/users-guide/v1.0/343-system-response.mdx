# System Response

The **System Response** section shows the location's SRP: the probability of the failure mode's system response at each headwater elevation (or at
each overtopping depth, on PFM-01). DST calculates it automatically once the characterization is complete.

While the system response recalculates, the chart shows a placeholder curve. Some pages show an input above the table that sets the range of the curve, such
as the maximum depth evaluated; each failure mode's page in this guide describes it.

## Active SRP

The SRP mode in the toolbar chooses the location's active SRP: the curve DST passes to the Risk Analysis module and shows in the System Response
Preview.

- **DST Based SRP** (**Event tree** on the event-tree pages): the curve DST calculates from the page's inputs, including any nodal revisions.
- **User Defined SRP** (**User defined**): a curve the user enters in a table (see [User-defined SRP](#user-defined-srp)). The page
  replaces its characterization and system response sections with the table and its chart.

DST keeps both curves. Switching the mode back restores the inputs, results and revisions of the other mode. Switching the mode clears the location's
verification. In DST Based SRP mode, the active SRP is ready only when the results are current (see [Calculation currency](#calculation-currency)).

## SRP charts

Every system response chart works the same way:

- The legend inside the plot names each curve: **DST Estimate**, and **Revised Estimate** once a node is revised. Pages with more than one pathway
  plot one curve per pathway, such as **Toe Pathway** and **Daylight Pathway**.
- Resting the pointer on a curve shows its values at that point.
- The mouse wheel, or a pinch on a touch screen, zooms the chart; dragging pans it. **Reset zoom** restores the full view.
- **Copy SRP curve data for spreadsheets** copies the curve values to the clipboard, and **Download SRP curves as a CSV file** downloads them. Both
  appear only when the results are current.

## Nodal tables

A system response is built from a sequence of nodes, each the probability of one event in the failure mode. The SRP table summarizes the total at
up to eight headwaters, which DST chooses to preserve the shape of the full curve; a curve with few distinct points has fewer rows. The table has the
columns **Headwater Elevation (ft)** (or the page's horizontal axis) and **System Response Probability**. Once a node is revised, the second column
becomes **DST Estimate** and **Revised Estimate**, and the cells of revised rows are tinted. The table is read-only; the Revised Estimate column fills
from the nodal revisions.

Below the table, **Nodal System Response** opens to show one card per node. Each card names its node and what it represents, shows its probability
range across the eight headwaters (or its single probability, for a node that does not vary with headwater), and carries a **DST** tag, or a
**Revised** tag once the node is revised. A revised card also reads **Needs justification** or **Justification provided**.

## Nodal revisions

A nodal revision replaces DST's estimate for a node with the team's own, at some or all of the headwaters. Selecting a node card opens the node's
dialog (<FigReference figKey="dst-users-guide-fig-failure-mode-evaluation-nodal-detail" />), with the node's table on the left and its chart on the
right; <TableReference tableKey="dst-users-guide-table-failure-mode-evaluation-nodal-inputs" /> describes its inputs. The information icon beside
the dialog's title explains how the eight headwaters are chosen.

The chart and the
Revised Estimate column of the SRP table update as the user types, and the revisions save shortly after each change. Revisions do not recalculate the
system response; DST combines the revised nodes into the Revised Estimate curve, which becomes the active SRP.

Three buttons undo revisions, each after a confirmation dialog whose **Continue and revert** button proceeds:

- **Revert to DST Estimates** in the node dialog clears that node's revised estimates and keeps its headwaters.
- **Revert to DST Headwaters** in the node dialog replaces that node's custom headwaters with DST's.
- **Revert to DST Estimates** beside the Nodal System Response heading clears every revised estimate and custom headwater of the location.

:::caution

Nodal revisions belong to the calculated results. When an input on this page or another page changes and the system response recalculates, DST clears the location's
nodal revisions together with its results and verification. DST reports a change on another page in a notice; one example reads "Dam Information,
Operational Data or Failure Mode Screening inputs changed since these results were calculated. The results, nodal adjustments, and SRP
verification were cleared; the analysis will recalculate automatically." The first sentence differs between failure modes. The justifications of revised nodes are kept.

:::

## Calculation currency

DST records which version of the System Response calculation produced each result. When stored results cannot be confirmed as current, the System
Response section shows a notice in place of the results; DST withholds the chart and the copy and download buttons; and the location's status is not
Defined. <TableReference tableKey="dst-users-guide-table-failure-mode-evaluation-currency" /> lists the notices.

a notice when it next opens, and recalculates. Out-of-date results cannot be verified or exported, and they keep the screening from being submitted
(see [Submission Readiness](./040-working-in-dst.mdx#submission-readiness)).

## User-defined SRP

In **User Defined SRP** mode the page shows a table of points and a chart of the curve they define. The user enters the curve directly, or pastes it
from a spreadsheet (see [Tables](./040-working-in-dst.mdx#tables)).

The table starts with two rows. Until it holds values the chart reads "Enter values in the table to plot the system response curve." The table saves
shortly after each change and becomes the active SRP. DST reports these warnings in the page messages: "SRP curve is empty."; a first headwater above
the lowest hazard headwater, suggesting a point at or below it with probability 0; a probability that decreases between two points ("SRP curves
should be monotonically non-decreasing."); a probability below 0 or above 1 ("Probabilities must be between 0 and 1."); and headwaters that are not
strictly increasing.
