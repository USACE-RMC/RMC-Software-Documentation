# PFM-20: Concrete Dam Overtopping

Potential failure mode 20 (PFM-20), Concrete Dam Overtopping, is overtopping of a concrete dam, where intervention fails to prevent overtopping and the monoliths slide downstream, with or without erosion of the material that resists them. The loading is the reservoir pool above the top of dam, evaluated at stages from the top of dam to 10 ft above it.

[Event Trees](./344-event-trees.mdx) describes the parts of the page that every failure mode page shares.

The user opens the page by selecting a PFM-20 location on the Failure Mode Evaluation page (see [Opening a location](./341-locations.mdx#opening-a-location)).

Inputs on this page save automatically (see [Saving](./040-working-in-dst.mdx#saving)), and the results recalculate automatically when an input changes (see

the message "The event tree has no system response yet. Complete every node's probabilities and resolve the errors on this page, then verify."

## Stages to Evaluate

The **Stages to evaluate** section lists the pool elevations at which DST evaluates the PFM-20 event tree, lowest first. PFM-20 has
two default stages, which DST places from other pages. <TableReference tableKey="dst-users-guide-table-pfm-20-default-stages" /> lists them with the
text of their **Source** column. The user cannot edit a default stage's elevation on this page. When its source is missing, the stage's elevation reads
"Source missing" and the page messages name the input to complete (see [Page Messages](#page-messages)).

## User-Defined SRP

With **User defined** selected in the toolbar, the page replaces Stages to evaluate, Event tree evaluation and System Response with a table of
**Pool Elevation (ft)** and **Probability** pairs and its chart, and the entered curve becomes the location's SRP. DST keeps the stages, node
probabilities and rationales, and shows them again when the user selects **Event tree** (see [User-defined SRP](./343-system-response.mdx#user-defined-srp)).
