# PFM-20: Concrete Dam Overtopping

Use this page to estimate the system response probability (SRP) of potential failure mode 20 (PFM-20), Concrete Dam Overtopping, at one location
with an event tree. PFM-20 is overtopping of a concrete dam, where intervention fails to prevent overtopping and the monoliths slide downstream, with or
without erosion of the material that resists them. The loading is the reservoir pool above the top of dam, evaluated at stages from the top of dam to
10 ft above it.

The user opens a PFM-20 location from **Response > Failure Mode Evaluation** (see [Opening a location](./341-locations.mdx#opening-a-location)).
[Event Trees](./344-event-trees.mdx) describes the parts that every event-tree page shares, and
[Failure Mode Pages](./342-failure-mode-pages.mdx) the parts that every failure mode page shares. To evaluate a location:

## Stages to Evaluate

The **Stages to evaluate** section lists the pool elevations at which DST evaluates the PFM-20 event tree, lowest first. DST places the two default
stages in <TableReference tableKey="dst-users-guide-table-pfm-20-default-stages" /> from other pages. To change a default stage's elevation, the user
changes the value on its source page, then selects **Move stage to** in the notice that appears on this page. [Stages](./344-event-trees.mdx#stages) describes the zero point and adding, editing and deleting stages.

## User-Defined SRP

With **User defined** selected in the toolbar, the user enters the SRP curve as **Pool Elevation (ft)** and **Probability** pairs in place of the
event tree. DST keeps the stages, node probabilities and rationales, and shows them again when the user selects **Event tree** (see
[User-defined SRP](./343-system-response.mdx#user-defined-srp)).

## Common problems

Problems every event-tree page shares, such as "No system response curve yet", a stage that reads Source missing, a default stage that
cannot be edited or a refused cross section, are described in [Common problems](./344-event-trees.mdx#common-problems) on the Event Trees
page. Problems every failure mode page shares, such as no usable cross sections or a deleted cross section, are described in
[Common problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages page. This page adds its own.

**Only one stage takes probabilities.** With the zero point on Top of Dam, the Top of Dam + 10 ft stage is the only stage above it. The user adds
stages between the two for intermediate overtopping depths.
