# Recommendations

Use the Recommendations page, at **Major Findings > Recommendations**, to record the actions or path forward the team recommends. The page is
optional. Its purpose statement reads "Recommend actions or a path forward for this dam."

**What to consider** lists:

- Investigations or data that would reduce the major uncertainties
- Monitoring, further analysis or other next steps

While the editor is empty, it shows "List recommendations or the path forward…". For writing, saving and verifying the text, see [Writing a Major Findings Page](./600-major-findings.mdx#writing-a-major-findings-page).

:::note

An empty Recommendations page has nothing to verify, shows no verification badge and does not hold back submission. Once it holds text, it must be
verified like the other pages.

:::
