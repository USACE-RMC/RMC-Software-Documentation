# Seismic Hazard

A seismic hazard curve gives the annual exceedance probability (AEP) of each level of ground motion. The Seismic Hazard page (**Hazards > Seismic
Hazard**) holds one or more such curves, obtained either from the USGS (**DST Based**) or from the user (**User Defined**).
<FigReference figKey="dst-users-guide-fig-seismic-hazard-dst-based" /> shows the page with DST-based curves, and
<TableReference tableKey="dst-users-guide-table-hazards-seismic-hazard-regions" /> describes each numbered region.

## Source

**DST Based** retrieves the curves from the USGS dynamic seismic hazard web service for the dam's coordinates on the Dam Data page. It is available
when the coordinates lie in a region the USGS models cover, and a screening opens in DST Based mode where it is available. **User Defined** accepts
curves the user enters.

## Fetching USGS Curves (DST Based)

Before the first fetch, the page reads "No seismic hazard data fetched yet". The user selects **Fetch USGS data**; the fetch runs in the background,
and the page shows "Fetching Seismic Hazard Data…" with its progress and the site class being queried. The page cannot be verified until a fetch
succeeds.

Once the curves are in place, the status line reads **Last fetched:** and the date. Its information icon, **USGS Data Source**, lists the **NSHM
Model**, the **Coordinates** and the **Service**, with a **Dam location** map. To fetch again, the user selects **Re-fetch** and confirms in the
**Re-fetch from USGS?** dialog; the fresh curves for the dam's current coordinates replace the current ones.

### Choosing Which Curves to Show

The **Chart Filters**, **Site Classes**, **Source Components** and **Intensity Measure Types (IMTs)**, each take one or more values. The table and
chart show one curve for every combination of the selected values: two site classes and two IMTs with **Total**, for example, plot four curves. A
new screening starts with **BC**, **Total** and **PGA**, which plots one curve, as in <FigReference figKey="dst-users-guide-fig-seismic-hazard-dst-based" />.
The choices save with the page.

The filters control only what the page displays: "These filters only control data visualization for this page. They do not select hazard curves for
any seismic potential failure modes."

<VideoReference videoKey="dst-users-guide-video-seismic-hazard-filters" /> shows two site classes added in the **Site Classes** filter: a curve and a
summary column appear for each.

The chart plots **Annual Exceedance Probability** against **Ground Motion (g)** and zooms and pans (see [Charts](./040-working-in-dst.mdx#charts)).
**Export to CSV** saves the plotted curves as a CSV file with the columns Curve Name, Ground Motion (g) and Annual Exceedance Probability.

## Entering Curves (User Defined)

In User Defined mode, the user enters each curve in its own table. The curve chips list the curves; selecting a chip shows that curve's table, and
the chart plots every curve with the selected one emphasized (<FigReference figKey="dst-users-guide-fig-seismic-hazard-user-defined" />). A dot on
a chip marks a curve without a justification.

- **Add curve** opens the **Add hazard curve** dialog with **Name**, **Description** and **Justification**; **Add** adds the curve.
- The menu on a chip offers **Edit**, which opens the same fields in **Edit hazard curve**, and, when there is more than one curve, **Delete**.
  **Delete curve** in the confirmation removes the curve and its points permanently.
- **Add justification** (or **Justification**) beside the chips edits the selected curve's justification.

<TableReference tableKey="dst-users-guide-table-hazards-seismic-hazard-inputs" /> lists the inputs of a curve. The curve table works like the other
tables in DST, including pasting a block of rows from a spreadsheet (see [Tables](./040-working-in-dst.mdx#tables)). At least one curve is
required, and a screening holds at most 20.

Until a curve has points to plot, the chart reads "Enter values in the curve table to plot the hazard curves." **Export to CSV** saves every curve's
points.

## Common Return Periods

The **Summary Table for Common Return Periods** reads each curve at return periods of 145, 225, 475, 975, 2,475 and 10,000 years, in both modes, with
one column per curve. DST interpolates each value between the curve's points; the DST Technical Reference Manual describes the method.

A curve is never extended past its own points. When a return period falls outside the curve's range of AEPs, the cell shows "—". For example, a
curve whose smallest AEP is 1E-4 shows "—" at 10,000 years, because the AEP of that return period is slightly below 1E-4.

## Seismic Hazard Summary

The summary tray, **Seismic hazard summary**, holds in DST Based mode the optional section **Basis of the DST based seismic hazard**: "Anything a
reviewer should know about the USGS hazard curves, such as the site class chosen and why." In User Defined mode each curve carries its own
justification instead. The tray also holds the page's supporting documents (see [Supporting Documents](./150-documents.mdx#supporting-documents)).
