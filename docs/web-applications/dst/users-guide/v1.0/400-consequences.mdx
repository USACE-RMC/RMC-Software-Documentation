# Consequences

The Consequences module estimates what happens downstream when the dam fails, and when it does not. The screening team builds a two-dimensional
hydraulic model of the area below the dam, simulates the flood at each loading level with HEC-RAS, and then simulates life loss and economic damages
in each flood with LifeSim. The results become the consequence functions that the Risk Analysis module combines with the hazard and system
response (see [Risk Analysis](./500-risk-analysis.mdx)).

The module has six pages, reached from **Consequences** in the module navigation, in the order the work is done:

- [Inundation Geometry](./401-inundation-geometry.mdx) builds the hydraulic model: its area, dam, rivers, terrain, land cover and mesh.
- [Inundation Analysis](./402-inundation-analysis.mdx) sets the loading levels, boundary conditions and breach of each analysis, and runs the flood simulations.
- [Consequence Data](./403-consequence-data.mdx) holds the structure inventory, the Emergency Response ratings and an optional non-failure hazard zone.
- [Consequence Analysis](./404-consequence-analysis.mdx) sets when each hazard occurs and how much notice people have, and runs the consequence simulations.
- [Results Map](./405-results-map.mdx) shows the consequences of one loading level on the map, structure by structure.
- [Results Data](./406-results-data.mdx) shows each consequence function as graphs and tables and holds functions entered by hand.

None of these pages is verified. Their inputs are read-only to users who are not on the screening team and while the screening's inputs are locked
(see [Input Lock](./040-working-in-dst.mdx#input-lock)). The methods behind the simulations are described in the HEC-RAS and LifeSim documentation
and in the DST Technical Reference Manual.
