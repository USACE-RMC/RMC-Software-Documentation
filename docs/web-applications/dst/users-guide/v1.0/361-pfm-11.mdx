# PFM-11: Internal Migration into the Conduit

Embankment soil can erode into open defects in a conduit, pipe or culvert that passes through an earth embankment. The PFM-11 page evaluates this
mechanism, potential failure mode 11 (PFM-11), Internal Migration into the Conduit, at a location. The loading is the reservoir pool, evaluated at the
normal pool, the spillway crest and the top of dam. The screening team estimates a probability for each node of an event tree, and DST multiplies
them into the system response probability (SRP) at each stage. [Event Trees](./344-event-trees.mdx) describes the parts that every event-tree page shares, and
[Failure Mode Pages](./342-failure-mode-pages.mdx) the parts that every failure mode page shares.

The user opens a PFM-11 location from **Response > Failure Mode Evaluation** (see [Opening a Location](./341-locations.mdx#opening-a-location)).

## Stages to Evaluate

The **Stages to evaluate** section lists the pool elevations at which DST evaluates the event tree, lowest first. PFM-11 has three default stages,
which DST places from other pages; <TableReference tableKey="dst-users-guide-table-pfm-11-default-stages" /> lists them with the text of their
**Source** column. A default stage's elevation cannot be edited on this page: to change it, the user changes its source. When the source is missing,
the elevation reads "Source missing" and the page messages name the input to complete.

## Event Tree Evaluation

The **Event tree evaluation** section shows the PFM-11 event tree and the panel of the selected node, and counts the complete nodes out of 6. The user
selects a node, enters a probability at each stage with the box or the slider, writes the **Estimate rationale**, and moves on with **Next node**.

## User-Defined SRP

With **User defined** selected in the toolbar, the page replaces Stages to evaluate, Event tree evaluation and System Response with a table of
**Pool Elevation (ft)** and **Probability** pairs and its chart, and the entered curve becomes the location's SRP. DST keeps the stages, node
probabilities and rationales, and shows them again when the user selects **Event tree** (see [User-Defined SRP](./343-system-response.mdx#user-defined-srp)).

## Common Problems

Problems every event-tree page shares, such as "No system response curve yet", a stage that reads Source missing, a default stage that
cannot be edited or a refused cross section, are described in [Common Problems](./344-event-trees.mdx#common-problems) on the Event Trees
page. Problems every failure mode page shares, such as no usable cross sections or a deleted cross section, are described in
[Common Problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages page. This page adds its own.
