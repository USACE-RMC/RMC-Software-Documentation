# PFM-13: Embankment Slope Instability

Potential failure mode 13 (PFM-13), Embankment Slope Instability, is instability of an earth embankment slope, where the initial slope failure either lowers the crest and releases the reservoir at once or continues as retrogressive instability through the crest. The loading is the reservoir pool, evaluated at the normal pool, the spillway crest and the top of dam.

[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#event-trees) describes the parts of the page that every failure mode page shares.

The user opens the page by selecting a PFM-13 location on the Failure Mode Evaluation page (see [Opening a location](./11-failure-mode-evaluation.mdx#opening-a-location)).

PFM-13 reads the top of dam from one earth embankment cross section. The **Cross Section** drop-down lists only the dam's earth embankment
cross sections from the Dam Information page (see [Chapter 8, Dam Information](./08-dam-information.mdx)). The selected section's crest becomes the Top
of Dam stage; when the section has no drawn crest, DST uses the dam crest elevation from the Dam Data page. Choosing a different section moves the Top of
Dam stage to that section's crest.

When the selected section is deleted on the Dam Information page, DST removes it from the location. The Top of Dam stage then reads "Source missing",
the page shows "Select a cross section for this location.", the system response disappears until the user selects another section, and the location's
verification clears.

Each location of PFM-13 has its own cross section, stages, node probabilities and results. PFM-13 has no limit on the number of
locations, and a copied location keeps the cross section, stages, node probabilities and rationales of the location it copies
(see [Locations](./11-failure-mode-evaluation.mdx#locations) and [Copying a location](./11-failure-mode-evaluation.mdx#copying-a-location)).

text of their **Source** column. The user cannot edit a default stage's elevation on this page. When its source is missing, the stage's elevation reads

## User-Defined SRP

With **User defined** selected in the toolbar, the page replaces Stages to evaluate, Event tree evaluation and System Response with a table of
**Pool Elevation (ft)** and **Probability** pairs and its chart, and the entered curve becomes the location's SRP. DST keeps the stages, node
probabilities and rationales, and shows them again when the user selects **Event tree** (see [User-defined SRP](./11-failure-mode-evaluation.mdx#user-defined-srp)).
