# PFM-13: Embankment Slope Instability

The PFM-13 page evaluates potential failure mode PFM-13, Embankment Slope Instability: instability of an earth embankment slope, where the initial slope failure either lowers the crest and releases the reservoir at once or continues as retrogressive instability through the crest. The loading is the reservoir pool, evaluated at stages from the normal pool to the top of dam. The user estimates a probability for each node
of the PFM-13 event tree at each stage, and DST combines them into the location's system response probability (SRP) at each stage, which Risk
Analysis uses for the location.

The page layout, locations and the parts every event tree page shares are described in [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#event-trees).
This chapter documents what is particular to PFM-13: its cross section, stages, nodes and results.

The user opens the page from the Failure Mode Evaluation page by selecting a PFM-13 location (see [Opening a location](./11-failure-mode-evaluation.mdx#opening-a-location)).
The page opens only when PFM-13 is selected for evaluation on the Failure Mode Selection page; otherwise it reads "PFM-13 isn't being evaluated".
<FigReference figKey="dst-users-guide-fig-pfm-13-page" /> shows the page, and <TableReference tableKey="dst-users-guide-table-pfm-13-regions" /> describes each numbered region.

PFM-13 reads the top of dam from one earth embankment cross section. The **Cross Section** drop-down lists only the dam's earth embankment
cross sections from the Dam Information page (see [Chapter 8, Dam Information](./08-dam-information.mdx)). The selected section's crest becomes the Top
of Dam stage; when the section has no drawn crest, DST uses the dam crest elevation from the Dam Data page. Choosing a different section moves the Top of
Dam stage to that section's crest.

Each location of PFM-13 has its own cross section, stages, node probabilities and results. PFM-13 has no limit on the number of
locations, and a copied location keeps the cross section, stages, node probabilities and rationales of the location it copies
(see [Locations](./11-failure-mode-evaluation.mdx#locations) and [Copying a location](./11-failure-mode-evaluation.mdx#copying-a-location)).

## Stages to Evaluate

The **Stages to evaluate** section lists the pool elevations at which the PFM-13 event tree is evaluated, lowest first. PFM-13 has three
default stages, which DST places from other pages. <TableReference tableKey="dst-users-guide-table-pfm-13-default-stages" /> lists them with the text of their
**Source** column. The user cannot edit a default stage's elevation on this page. When its source is missing, the stage's elevation reads
"Source missing" and the page messages name the input to complete (see [Page Messages](#page-messages)).

zero point is the lowest stage; the user may choose another stage. Nodes take probabilities at every stage above the zero point.

## Event Tree Evaluation

The **Event tree evaluation** section shows the PFM-13 event tree and, below it, the panel of the selected node. The tree starts at the Flood loading
on the left and ends at breach, marked by a red triangle, on the right. The section header counts the complete nodes, for example "4 of 5 nodes complete"; a node is
complete when it has a probability at every stage above the zero point and an estimate rationale. <FigReference figKey="dst-users-guide-fig-pfm-13-event-tree" /> shows
the tree with Node 2 selected.

## System Response

The **System Response** section shows the location's SRP at each stage. It appears once every node has a probability at every stage above the zero
point and the stages and probabilities have no errors; until then the section reads "No system response curve yet". To its left is a table of
the results, described in <TableReference tableKey="dst-users-guide-table-pfm-13-results" />, and to its right a chart of the same values. The information icon in each
column heading explains the column, and the section's layout is described in [Event tree system response](./11-failure-mode-evaluation.mdx#event-tree-system-response).

The chart plots Branch a, Branch b and the Total SRP against Pool Elevation (ft) on a logarithmic System Response
Probability axis. **Download SRP curves as a CSV file** saves the plotted values (see [SRP charts](./11-failure-mode-evaluation.mdx#srp-charts)). The Total SRP is the curve
DST sends to Risk Analysis for the location (see [Active SRP](./11-failure-mode-evaluation.mdx#active-srp)). If the Total SRP decreases from one stage to the next, the table and
chart still show, but the page messages report an error and the curve is not sent to Risk Analysis.

## User Defined SRP

With **User defined** selected in the toolbar, the page replaces Stages to evaluate, Event tree evaluation and System Response with a table of
**Pool Elevation (ft)** and **Probability** pairs and its chart, and the entered curve becomes the location's SRP. The stages, node probabilities and
rationales stay saved and return when the user selects **Event tree** again. The table and chart are described in
[User-defined SRP](./11-failure-mode-evaluation.mdx#user-defined-srp).

## Failure Mode Summary

The failure mode summary tray at the bottom of the page includes a **Node probabilities** section for PFM-13. It shows a table of every node, its
status (Not started, Started or Complete) and its probability at every stage, with one column per stage headed by its elevation and name. A shaded cell
marks a stage that is not one of the node's stages, and "—" marks a stage at or below the zero point. A pool-independent node shows its single value under every stage above the zero point. The tray itself is
described in [Summary Tray](./04-working-in-dst.mdx#summary-tray), and its other sections, including the **System response rationale**, in
[Failure mode summary](./11-failure-mode-evaluation.mdx#failure-mode-summary).
