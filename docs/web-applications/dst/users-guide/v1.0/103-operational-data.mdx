# Operational Data

The Operational Data page holds the reservoir's operating relationships: stage-storage, stage-outflow and tailwater. The user reaches it from
**Screening Information > Operational Data**. No curve on the page is required for submission. The Consequences module uses the stage-storage and stage-outflow
curves for 1D reservoir routing, and a tailwater relationship is needed when a concrete gravity or RCC dam is evaluated for sliding stability.

The page opens on the Stage-Storage card. A link from another page can open it on the Stage-Outflow or Tailwater card. Each relationship is entered in a
table with at least two rows, which works like the other DST tables (see [Tables](./040-working-in-dst.mdx#tables)); its chart beside the table
updates as the rows save, and resting the pointer on the chart shows the values at that point. Entries save automatically, and any change clears
the page's verification and can clear the verification of failure mode locations that use the curves.

## Stage-Outflow

The **Stage-Outflow** card holds the total project outflow as a function of stage
(<TableReference tableKey="dst-users-guide-table-screening-information-operational-data-outflow" />): the combined discharge from all project
outlets, such as spillways and outlet works. A note above the table reads "Enter the combined discharge from all project outlets. Do not include
overtopping flows over the dam crest. Start at the lowest outlet's invert with zero outflow, and carry the curve up to the top of dam." The chart plots outflow on the horizontal axis and
stage on the vertical axis, with the Dam Data reference lines.

## Tailwater

The **Tailwater** card defines the tailwater relationship by one of two methods, chosen with the **Rating Curve** and **Direct HW/TW** buttons above
the table (<FigReference figKey="dst-users-guide-fig-operational-data-tailwater" />). Only one method is active at a time; DST keeps the data of the
other method when the user switches. If no rows are entered for the selected method, no tailwater is assumed.

- **Rating Curve** (the default) — tailwater elevation as a function of total project discharge. DST combines it with the Stage-Outflow curve to find
  the tailwater for any headwater, so it needs at least two valid points in the Stage-Outflow curve. Beyond its last point, tailwater stays at the last
  entered value. The chart's corner control switches between **Rating Curve**, the entered curve, and **Derived HW/TW**, the headwater and tailwater
  curves DST derives from the two relationships.
- **Direct HW/TW** — tailwater elevation entered directly as a function of headwater elevation. The chart plots a **Headwater** line, one to one with
  the horizontal axis, and the **Tailwater** curve.

## Operational data summary

The **Operational data summary** tray at the bottom of the page holds a notes box for each relationship and the page's supporting documents (see
[Summary Tray](./040-working-in-dst.mdx#summary-tray)). Its status counts the notes written, for example "1 note", or reads "No notes yet".

- **Stage-Storage**, **Stage-Outflow** and **Tailwater** sections, each **Optional**, hold a notes box for the source of the relationship and anything
  a reviewer should know. The Tailwater notes belong to the method selected, Rating Curve or Direct HW/TW. Notes save when the user leaves the box.
- **Supporting documents** links files from the screening's Documents to this page (see
  [Supporting Documents](./150-documents.mdx#supporting-documents)).

## Operational data messages

The page messages button reports the problems DST finds in the curves (see [Page Messages](./040-working-in-dst.mdx#page-messages)), and the cell that
causes an error is tinted red. Errors name the curve, the value and the row; the examples below show the pattern, with "Stage-Storage",
"Stage-Outflow" or "Headwater/Tailwater" as the curve name and Stage or Headwater as the column. The required input appears only while the
Stage-Outflow card is selected, when the Stage-Outflow curve has fewer than two valid points or has an error. When the Rating Curve method has rows
but the Stage-Outflow curve cannot support it, the warning appears instead, whichever card is selected.
