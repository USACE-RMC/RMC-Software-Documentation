# Operational Data

The Operational Data page holds the reservoir's stage-storage, stage-outflow and tailwater curves. The user reaches it from
**Screening Information > Operational Data**. No curve is required for submission. The Consequences module uses the stage-storage and stage-outflow
curves for 1D reservoir routing, and a tailwater relationship is required when a concrete gravity or RCC dam is evaluated for sliding stability.

## Entering a Curve

Each relationship is entered in a table with at least two rows, which works like the other DST tables (see [Tables](./040-working-in-dst.mdx#tables)).
The user selects a relationship card, then types or pastes the points into its table. The chart updates as the rows save, and resting the pointer on
the chart shows the values at that point. Until a table has rows to plot, its chart reads, for example, "Enter stage / storage rows in the table to
plot the curve."

:::tip

A curve kept in a spreadsheet can be copied and pasted into the table in one step: the user selects the first cell and pastes, and the table adds
rows as needed. Pressing Tab in the last cell also adds a row.

:::

Entries save automatically. Any change clears the page's verification and can clear the verification of failure mode locations that use the curves
(see [Human Verification](./040-working-in-dst.mdx#human-verification)).

### Checking the Curve against Dam Data

Resting the pointer on a Dam Data marker compares the Dam Data value with the curve. The tooltip shows the level name with "(Dam Data)" and its stage
and storage, followed by a **Stage-Storage Curve** block with the curve's storage at the same stage. When the marker lies outside the curve, the
second block reads "Storage: below the curve's lowest stage" or "Storage: above the curve's highest stage". A large difference between a marker and
the curve points to a value to check on one page or the other.

tooltip comparing the Dam Data value with the curve.

## Tailwater

The **Tailwater** card defines the tailwater relationship by one of two methods, chosen with the **Rating Curve** and **Direct HW/TW** buttons above
the table (<FigReference figKey="dst-users-guide-fig-operational-data-tailwater" />). Only one method is active at a time; DST keeps the data of the
other method when the user switches. If no rows are entered for the selected method, no tailwater is assumed.

  caption="The Tailwater relationship by the Rating Curve method, with the derived headwater-tailwater curve."
  width="100%"

- **Rating Curve** (the default) — tailwater elevation as a function of total project discharge. DST combines it with the Stage-Outflow curve to find
  the tailwater for any headwater, so it needs at least two valid points in the Stage-Outflow curve. Beyond its last point, tailwater stays at the last
  entered value. The chart's view control switches between **Rating Curve**, the entered curve, and **Derived HW/TW**, the headwater and tailwater
  curves DST derives from the two relationships.
- **Direct HW/TW** — tailwater elevation entered directly as a function of headwater elevation. The chart plots a **Headwater** line, one to one with
  the horizontal axis, and the **Tailwater** curve.

## How the Inundation Analysis Uses the Curves

Every dam boundary condition of type **1D Reservoir**, on every loading level, uses the Stage-Storage and Stage-Outflow curves. The Reservoir tab of
that boundary condition shows them read-only under **Storage & outflow curves**, with a link back to this page (see
[Dam](./402-inundation-analysis.mdx#dam)). Editing a curve here changes every 1D reservoir in the screening's analyses the next time they run.

- **Stage-Storage** — used when the curve has at least two rows with both a stage and a storage; incomplete rows are skipped. Without it, each
  reservoir uses a straight line from zero storage at the top of dam less the **Dam Height** to the **Max storage** at the top of dam, both from Dam
  Data.
- **Stage-Outflow** — used when the curve has at least two complete rows; the reservoir then releases water through it as well as over the dam crest.
  Without it, the reservoir releases only over the crest. With an inflow hydrograph, the curve also enables DST to estimate the highest pool before a run
  (see [What the Inflow Hydrograph Does](./402-inundation-analysis.mdx#what-the-inflow-hydrograph-does)).

## Operational Data Summary

The **Operational data summary** tray at the bottom of the page records the source of each relationship and holds the page's supporting documents
(see [Summary Tray](./040-working-in-dst.mdx#summary-tray)). Its status counts the notes written, for example "1 note", or reads "No notes yet".

- **Stage-Storage**, **Stage-Outflow** and **Tailwater** sections, each **Optional**, hold a notes box for the source of the relationship and anything
  a reviewer should know. The Tailwater notes belong to the method selected, Rating Curve or Direct HW/TW. Notes save when the user leaves the box.
- **Supporting documents** links files from the screening's Documents to this page (see
  [Supporting Documents](./150-documents.mdx#supporting-documents)).

## Operational Data Messages

The page messages button reports the problems DST finds in the curves (see [Page Messages](./040-working-in-dst.mdx#page-messages)), and the cell that
causes an error is marked red. Errors name the curve, the value and the row; the examples below show the pattern, with "Stage-Storage",
"Stage-Outflow" or "Headwater/Tailwater" as the curve name. The required input appears only while the Stage-Outflow card is selected, when the
Stage-Outflow curve has fewer than two valid points or has an error. When the Rating Curve method has rows but the Stage-Outflow curve cannot
support it, the warning appears instead, whichever card is selected.
