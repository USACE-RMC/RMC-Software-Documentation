# Dam Data

The Dam Data page records the dam's identity, types, dimensions, key elevations and reservoir data, together with the justification for any value
that differs from the National Inventory of Dams (NID). The user reaches it from **Screening Information > Dam Data**. For a dam taken from the NID, DST
fills the page from the dam's NID record when the screening is created, and each value shows whether it still matches the NID. For a dam entered
manually, the team enters every value.

Inputs on this page save automatically (see [Saving](./040-working-in-dst.mdx#saving)): text and number fields when the user leaves them, and
selections as soon as they are made. Changing any value clears the page's verification (see
[Human Verification](./040-working-in-dst.mdx#human-verification)) and can change other pages (see [What a change affects](#what-a-change-affects)).
The Facilitator, Team Members and administrators can edit the page while the screening's inputs are open for editing; everyone else sees it
read-only.

## NID values and overrides

For an NID dam, the label of every field filled from the NID carries a badge that shows whether the value still matches the NID:

- **NID** — the value matches the NID record.
- **Edited** — the team changed the value. Resting the pointer on the badge shows the NID value and the date DST fetched it.

To return a field to the NID value, the user selects its **Edited** badge. A panel opens with the **Current** value and the **NID** value
(<FigReference figKey="dst-users-guide-fig-dam-data-reset-to-nid" />). **Reset to NID** returns the field to the NID value, and **Cancel** closes the
panel. Some fields reset together: Latitude and Longitude, the dam types, and the spillway types. When more than one of them changed, the panel lists
each one under "Reset these fields to NID values?".

The page does not show the dam's hazard potential classification. For an NID dam, DST copies it from the NID, and a re-fetch can update it
(**Hazard Class** in the comparison). It cannot be entered in DST, so a dam entered manually has none.

### Justifying a changed value

Each changed value requires a justification when the NID supplied a value for the field. The justification chip beside the field's label shows a
pencil while the justification is missing and a check mark once it is written. To write one, the user selects the chip, which opens a box headed by
the field name with the note "The NID value is" followed by the NID value
(<FigReference figKey="dst-users-guide-fig-dam-data-override-justification" />), and enters the reason, up to 4,000 characters. The justification
saves when the box closes. The same justifications can be written in the [Dam data summary](#dam-data-summary) tray. A field the NID left blank needs
no justification when the team fills it in.

<Figure
  figKey="dst-users-guide-fig-dam-data-override-justification"
  src="figures/web-applications/dst/users-guide/v1.0/figures/dam-data-override-justification.png"
  alt="The Physical Data section with the justification box of Structural Height open. The box is headed Structural Height, reads 'The NID value is 100.' and holds the text 'Survey of 2025 shows a lower crest.', with a count of 35 / 4000."
  caption="The justification for a value that differs from the NID."
  width="100%"

A justification is kept when its field is reset to the NID value or re-fetched, and it is required again if the field is changed again. A missing
justification leaves the Dam Data page Incomplete on the Submission Readiness page (see
[Submission Readiness](./040-working-in-dst.mdx#submission-readiness)). Writing or changing a justification clears the page's verification.

## Re-fetching from the NID

**Re-fetch from NID** brings the screening up to date with the current NID record and allows the team to choose which of its edits to keep. When the
NID has changed a field this screening uses, a note titled "The NID has newer data for this dam" appears below the NID data bar, with the date of the
NID update and the number of fields changed. The button is available to the Facilitator, Team Members and administrators while the screening's
inputs are open for editing, for a dam with a Federal ID.

The comparison has two lists and a summary line:

- **NID updates** — fields whose NID value changed and that the team has not edited, with the **Current** and **NID** values. Applying replaces them.
  The list can include NID fields the page does not show, such as **Hazard Class**, **City**, **NID Height**, **USACE Dam** or **DSAC Class**.
- **Your edits** — fields the team changed, with **Your value** and the **NID** value. **Keep mine** is selected to start. "NID changed since your
  edit" marks a field whose NID value changed after the team edited it.
- The summary line counts the updates that will apply, the edits kept and the edits that will be replaced. When nothing differs, it reads "No values
  differ from the NID. Applying updates this screening's NID record date."

**Apply** also updates the NID record date and the fetch date. Applying a comparison that changes any value clears the page's verification and has
the same effects on other pages as editing those values. A change to **USACE Dam** changes who can be chosen as a new Facilitator for an Official
screening (see [Team management](./104-screening-management.mdx#team-management)).

<VideoReference videoKey="dst-users-guide-video-dam-data-refetch" /> shows a re-fetch comparison: setting a row to **Use NID** or **Keep mine**
updates the counts in the summary line, and **Cancel** discards the comparison.

## Dam & spillway types

which cross sections, materials and potential failure modes apply to the screening on the Response pages.

## Dam data summary

describes how the tray opens and closes. For an NID dam, its status reads "No NID overrides", or counts the overrides and any that still need a
justification, for example "2 NID overrides · 1 needs justification".

## What a change affects

Because other modules draw on Dam Data, a change here can alter other pages:

- Changing the **Latitude** or **Longitude**, on this page or on the Overview map, retrieves the seismic hazard data for the new location (see
  [Seismic Hazard](./203-seismic-hazard.mdx)).
- Changing the **Normal Pool** elevation changes the default normal pool on the Stage Duration page and can clear that page's verification (see
  [Stage Duration](./202-stage-duration.mdx)).
- Changing the dam types or the **Dam Crest** elevation can change which potential failure modes apply and update Failure Mode Screening (see
  [Failure Mode Selection](./330-failure-mode-selection.mdx)).
- Changes to Dam Data can clear the verification of failure mode locations whose evaluation uses the changed values (see
  [Verifying a location](./342-failure-mode-pages.mdx#verifying-a-location)).
