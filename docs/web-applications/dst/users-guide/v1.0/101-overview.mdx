## Screening details

The **Screening Details** card holds the screening's description and a read-only summary of the screening and its dam
(<TableReference tableKey="dst-users-guide-table-screening-information-details-inputs" />). The description saves when the user leaves the box
(see [Saving](./040-working-in-dst.mdx#saving)).

[Creating a Screening](./030-getting-started.mdx#creating-a-screening)). The team is managed on the
[Screening Management](./104-screening-management.mdx) page.

## Dam location map

The map shows the dam's location from the **Latitude** and **Longitude** on the Dam Data page, marked with a blue pin. It opens on a satellite view
with street labels, zoomed to the dam. The controls at the upper right switch the map style among streets, satellite with streets and outdoors,
reset the map's rotation, and zoom in and out. A scale bar sits at the lower right. While the screening stays open, DST remembers the map's position and style, and returns to the dam if its location
changed in the meantime.

The Facilitator, Team Members and administrators can set the dam's location on the map while the screening's inputs are open for editing:

For a dam linked to the National Inventory of Dams (NID), **Reset Dam Location** beside Set Location returns the latitude and longitude to the NID
values. It is unavailable, with the note "Location matches NID — nothing to reset", while the location already matches the NID. Moving the dam
has the same effects as changing its coordinates on the Dam Data page (see [Dam data messages](./102-dam-data.mdx#dam-data-messages)).
