# Overview

Use the Overview page to read a summary of the screening, edit its description and set the dam's location on the map. The user reaches it by
selecting **Screening Information** in the module navigation, or **Screening Information > Overview**.

## Screening details

Use the **Screening Details** card to edit the screening's description and to check its datum, units and dam summary
(<TableReference tableKey="dst-users-guide-table-screening-information-details-inputs" />). The description saves when the user leaves the box
(see [Saving](./040-working-in-dst.mdx#saving)).

Vertical Datum and Units cannot be changed after the screening is created (see
[Creating a Screening](./030-getting-started.mdx#creating-a-screening)). To change the dam summary, the user edits the
[Dam Data](./102-dam-data.mdx) page; to change the team, the [Screening Management](./104-screening-management.mdx) page.

## Dam location map

The map shows the dam at the **Latitude** and **Longitude** entered on the Dam Data page. DST also uses this location to find the screening's
seismic hazard data (see [Seismic Hazard](./203-seismic-hazard.mdx)), to compare the dam with the Stage Duration data source, and to open the
Consequences maps on the dam.

The map controls change the map style, reset its rotation and zoom in and out. The map style button opens a **Map Style** popup with three styles,
**Streets**, **Satellite Streets** and **Outdoors**, and an **Elevation Scale** slider from x0.0 to x5.0 that exaggerates the terrain when the map is
tilted. **Reset** returns the slider to its default, x1.5. The style and elevation scale change only the picture and are not saved with the
screening.

For a dam linked to the National Inventory of Dams (NID), **Reset Dam Location** returns the latitude and longitude to the NID values. It acts at
once, with no confirmation step. Moving the dam by either button has the same effects as changing its coordinates on the Dam Data page: DST
retrieves new seismic hazard data and can clear verification on pages that use the location (see
[What a change affects](./102-dam-data.mdx#what-a-change-affects)).

## Common problems

- **Set Location and Reset Dam Location do not appear.** Only the Facilitator, Team Members and administrators see them, and only while the
  screening's inputs are open for editing (see [Input Lock](./040-working-in-dst.mdx#input-lock)).
- **Reset Dam Location is unavailable, with "Location matches NID — nothing to reset".** The location already matches the NID.
- **The description cannot be edited.** The screening has been submitted; the description stays fixed from then on.
- **The map area reads "Map not available".** The map service is not set up for this DST installation. The user enters the location as
  **Latitude** and **Longitude** on the Dam Data page instead.
