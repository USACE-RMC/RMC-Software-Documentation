# Failure Mode Evaluation

Each selected potential failure mode (PFM) is evaluated at one or more locations on the dam. The Failure Mode Evaluation page adds those locations,
opens each location's failure mode page and compares the system response probability (SRP) curves of every location. The page lists the failure
modes the screening team selected for evaluation on the Failure Mode Selection page (see [Failure Mode Selection](./330-failure-mode-selection.mdx)).
On each location's failure mode page the team characterizes the location and defines its SRP, the curve that the Risk Analysis module uses.

The pages under this one describe what every failure mode page shares:

- [Locations](./341-locations.mdx): adding, copying, renaming, deleting and opening locations.
- [Failure Mode Pages](./342-failure-mode-pages.mdx): the toolbar, characterization inputs, parameter overrides, justifications, the Failure mode
  summary, verification and Submission Readiness, with the common problems of every failure mode page.
- [System Response](./343-system-response.mdx): the SRP table and chart, nodal revisions and the User-Defined SRP.
- [Event Trees](./344-event-trees.mdx): the event tree used by PFM-11, PFM-12, PFM-13, PFM-17, PFM-18, PFM-20, PFM-22 and PFM-23, and by PFM-21 for
  a concrete dam with no Gravity or RCC dam type.

The pages from [PFM-01](./351-pfm-01.mdx) through [PFM-23](./369-pfm-23.mdx) describe each failure mode's own inputs. The DST Technical Reference
Manual and the System Response Library manuals document the methods behind each SRP.

### The failure mode table

The **Selected Failure Modes** table shows every location and its status. It lists the failure modes in the order of the Failure Mode
Selection page, each named by number and name, for example **01 - Embankment Overtopping Erosion**. A failure mode with two or more locations has a
parent row followed by one row per location, labeled with a letter after the number, for example **02a - Left Abutment** and **02b - Right Abutment**.

### The system response preview

The **System Response Preview** compares the active SRP of every Defined location on one chart. The chart is read-only; the team defines each
curve on its own failure mode page. The subtitle counts the curves shown, for example "Showing 3 of 3 curves · read-only". The horizontal axis is
**Headwater Elevation (ft)**; DST places curves defined against overtopping depth on it using the location's crest elevation.

on the chart.

- **Showing and hiding curves.** The check box beside each curve shows or hides it; a failure mode's group check box shows or hides all of its
  locations. **Show all** and **Hide all** act on every curve. The choice is not saved and resets when the page reloads.
- **Curves not yet drawn.** The list shows a location that is Incomplete or Not started with its status and an **Open** link to its failure mode
  page.
- **Highlighting.** Resting the pointer on a curve in the list or in the key below the chart highlights that curve.
- **Reading values.** Resting the pointer on the chart lists each shown curve's probability at that headwater, highest first.
- **Scale.** **Linear** and **Log** switch the **Probability** axis between a linear and a logarithmic scale. DST selects the scale that suits the
  curves when the page opens; a selection lasts until the page reloads. The logarithmic axis stops at 1E-06: a lower probability is drawn on the
  bottom edge, with a small triangle marking its headwater, and the pointer still lists its true value.
- **Zooming.** The chart zooms and resets in the same way as the SRP charts on each failure mode page (see
  [SRP charts](./343-system-response.mdx#srp-charts)). Other chart behaviors are described in [Charts](./040-working-in-dst.mdx#charts).

## Common Problems

- **A failure mode is dimmed and shows Needs confirmation.** The DST recommendation for the failure mode changed after the team made its selection.
  Resting the pointer on the link shows "The DST recommendation changed. Confirm your decision on the Failure Mode Selection page to evaluate this
  failure mode." Selecting **Needs confirmation** opens the Failure Mode Selection page, where the team confirms its decision (see
  [Failure Mode Selection](./330-failure-mode-selection.mdx)).
- **The table is empty.** The preview reads "Complete Failure Mode Screening and Failure Mode Selection to choose failure modes for evaluation." No
  failure mode is selected for evaluation yet; the team completes those two pages first.
- **A location's curve is missing from the preview.** Only Defined locations have a curve. The **Curves** list shows the location's status with an
  **Open** link; the location's page messages list what it still needs (see
  [Common problems](./342-failure-mode-pages.mdx#common-problems) on the Failure Mode Pages page). Before any location is Defined, the chart reads
  "No system response defined yet".
- **A location shows a No crest tag in the Curves list.** Its cross section has no crest elevation, so DST cannot place its overtopping curve on the
  elevation axis. The team checks that cross section's drawing on the Dam Information page (see
  [Cross-Section Editors](./311-cross-section-editors.mdx)).
- **The chart reads "All curves are hidden. Use Curves to show them."** Every curve was hidden in the **Curves** list. **Show all** in the list, or
  reloading the page, shows them again.
- **The dot after Failure Mode Evaluation stays amber.** At least one location is unverified. The team opens each location whose page shows an
  **Unverified** badge and verifies it.
- **The row menu or the Add location button is missing.** See [Locations](./341-locations.mdx) for when each location action is available.
