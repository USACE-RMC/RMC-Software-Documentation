# Failure Mode Evaluation

The Failure Mode Evaluation page, under the Response module, lists every potential failure mode (PFM) the screening team selected for evaluation on
the Failure Mode Selection page (see [Failure Mode Selection](./330-failure-mode-selection.mdx)). From it, the
user adds the locations at which each PFM is evaluated and opens each location's failure mode page. On that page the user characterizes the
location and defines its system response probability (SRP), the curve that the Risk Analysis module uses for that location.

This page describes the Failure Mode Evaluation page itself. The pages under it describe the parts that every failure mode page shares:

- [Locations](./341-locations.mdx): adding, copying, renaming, deleting and opening the locations of each failure mode.
- [Failure Mode Pages](./342-failure-mode-pages.mdx): the page toolbar, the characterization pattern, parameter overrides and justifications, the
  Failure mode summary, verification and Submission Readiness.
- [System Response](./343-system-response.mdx): the system response with its charts, nodal tables and nodal revisions, and the User-Defined SRP.
- [Event Trees](./344-event-trees.mdx): the event tree used by PFM-11, PFM-12, PFM-13, PFM-17, PFM-18, PFM-20, PFM-22 and PFM-23, and by PFM-21 for
  a concrete dam with no Gravity or Roller-Compacted Concrete type.

The Potential Failure Modes pages, from [PFM-01](./351-pfm-01.mdx) through [PFM-23](./369-pfm-23.mdx), describe each failure mode page's own
inputs and refer back to these pages for the shared parts. The DST Technical Reference Manual and the System Response Library manuals document the
methods behind each SRP.

## The Failure Mode Evaluation Page

The user opens the page from **Response > Failure Mode Evaluation**. The page has two columns: the table of selected failure modes on the left and
the System Response Preview on the right. On tablets and phones only the table is shown.

### The failure mode table

The table, headed **Selected Failure Modes**, lists the failure modes in the order of the Failure Mode Selection page. Each row names its failure
mode by number and name, for example **01 - Embankment Overtopping Erosion**. A failure mode with one location has one row. A failure mode with two
or more locations has a shaded parent row, followed by one indented row per location, labeled with a
letter after the number, for example **02a - Left Abutment** and **02b - Right Abutment**.

When the DST recommendation for a failure mode changes after the team made its selection, the failure mode's rows are dimmed, and an amber
**Needs confirmation** link replaces the status and menu. Resting the pointer on it shows "The DST recommendation changed. Confirm your decision on
the Failure Mode Selection page to evaluate this failure mode." Selecting it opens the Failure Mode Selection page (see
[Failure Mode Selection](./330-failure-mode-selection.mdx)).

### The system response preview

The **System Response Preview** card plots the active SRP of every Defined location on one chart, so the team can compare them. The chart is
read-only; the team defines each curve on its own failure mode page. The subtitle counts the curves, for example "Showing 3 of 3 curves · read-only". The
horizontal axis is **Headwater Elevation (ft)**; DST places curves defined against overtopping depth on it using the location's crest elevation.

chart's upper right corner.

- **Showing and hiding curves.** A check box beside each curve shows or hides it; a failure mode's group check box shows or hides all of its
  locations. **Show all** and **Hide all** act on every curve. When every curve is hidden, the chart reads "All curves are hidden. Use Curves to show
  them." The choice is not saved and resets when the page reloads.
- **Curves not yet drawn.** The list shows a location that is Incomplete or Not started with its status and an **Open** link to its failure mode page. A
  location whose cross section has no crest elevation shows a **No crest** tag: DST cannot place its overtopping curve on the elevation axis.
- **Highlighting.** Resting the pointer on a curve in the list or in the key below the chart highlights that curve.
- **Empty chart.** Before any location is Defined the chart reads "No system response defined yet". When no failure mode is selected for evaluation it
  reads "Complete Failure Mode Screening and Failure Mode Selection to choose failure modes for evaluation."

**Linear** and **Log**, in the chart's upper right corner, switch the **Probability** axis between a linear and a logarithmic scale; DST picks
the scale that suits the curves when the page opens. The chart zooms and resets in the same way as the SRP charts on each failure mode page (see
[SRP charts](./343-system-response.mdx#srp-charts)).

DST chooses the scale from the probabilities of the curves, ignoring zeros:

- **Log** when the largest probability is 0.01 or less, so that every curve is low.
- **Log** when two or more probabilities are below 0.01 and the largest is at least 100 times the smallest, so that low curves would otherwise
  flatten against the axis beside high ones.
- **Linear** otherwise, and when no curve has a probability above zero.

Selecting **Linear** or **Log** overrides DST's choice until the page reloads. The logarithmic axis stops at 1E-06. A point below it, such as a
probability of 1.00E-16, is drawn on the bottom edge of the plot, and a small triangle in the curve's color at the bottom edge marks its
headwater. Resting the pointer on the chart lists each shown curve's probability at that headwater, highest first, at its true value rather than
the floor. Other chart behaviors are described in [Charts](./040-working-in-dst.mdx#charts).
