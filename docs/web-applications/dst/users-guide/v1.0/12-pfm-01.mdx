# PFM-01: Embankment Overtopping Erosion

Potential failure mode (PFM) 01 evaluates erosion of an earth embankment by flow over its crest during a flood, through to breach. The loading is the
depth of overtopping, so the page's system response is plotted against overtopping depth rather than headwater elevation. The locations, toolbar,
overrides, justifications, Failure mode summary, nodal tables and nodal revisions work as described in
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#the-failure-mode-page).

The user opens a PFM-01 location from **Response > Failure Mode Evaluation** by selecting **01 - Embankment Overtopping Erosion** or one of its
locations. The page heading reads **01 - Embankment Overtopping Erosion**. <FigReference figKey="dst-users-guide-fig-pfm-01-page" /> shows the page,
and <TableReference tableKey="dst-users-guide-table-pfm-01-page-regions" /> describes each numbered region.

The drawing beside the inputs shows the selected cross section to scale, with the zones of the selected material highlighted, so the team can judge
whether the material is representative. Choosing a different material changes the badge to **Manual**; the revert button ("Revert to drawing
default") restores the drawing's material. A material other than the default needs a justification (see
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#justifications)). Changing the material resets the Advanced erodibility
overrides to their defaults.

### Advanced erodibility overrides

The collapsed **Advanced erodibility overrides** section holds three parameters whose screening defaults come from the erodibility category of the
downstream shell material. Its description reads "Screening defaults come from the downstream shell material's erodibility category and stay locked
until a site-specific distribution is chosen." <TableReference tableKey="dst-users-guide-table-pfm-01-overrides" /> lists the parameters.

For each parameter, the **Distribution** drop-down offers the default, labeled with its distribution type, for example **PERT (Default)**, and
**Deterministic**, **Uniform**, **Triangular**, **PERT** and **Normal**. Choosing one of these unlocks its parameter boxes. The minimum must be
greater than zero and less than the maximum. Each chosen distribution counts as an override and needs a justification. The section works as described
in [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#parameter-overrides).

Changing any input in this section recalculates the system response (see
[Chapter 4, Working in DST](./04-working-in-dst.mdx#automatic-calculation)) and clears the location's verification (see
[Chapter 4, Working in DST](./04-working-in-dst.mdx#human-verification)).

## System Response

The **System Response** section shows the SRP against **Overtopping Depth (ft)**, as a table of eight depths and a chart. The SRP table, chart, node
cards and nodal revisions work as described in [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#system-response). DST
calculates the system response once a cross section, a downstream shell material and the overtopping duration are set.

### Max overtopping depth evaluated

The **Max overtopping depth evaluated (ft)** box above the table sets the largest overtopping depth the curve covers.

Entering a value changes the badge to **Manual**; the reset button ("Reset to auto") restores the computed value. A depth below the default needs a
justification when the system response at that depth is less than 1.0.

:::caution

When the location has nodal revisions, changing the maximum depth opens the dialog **Clear nodal probability adjustments?**, which states the old
and new depths and that the change "will rerun the system response calculation" and clear all manual nodal probability adjustments. **Continue and
clear adjustments** applies the change; **Cancel** keeps the earlier depth. The cleared adjustments cannot be recovered.

:::

## User-Defined SRP

With **User Defined SRP** selected, the page replaces its sections with a table of **Overtopping Depth (ft)** and **Probability** and its chart. The
table works as described in [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#user-defined-srp).
