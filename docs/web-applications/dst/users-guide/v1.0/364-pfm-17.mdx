# PFM-17: Unlined Spillway Failure

Potential failure mode 17 (PFM-17), Unlined Spillway Failure, is erosion of an unlined spillway, where flow removes the vegetal cover or channel protection and a headcut advances through the control point. The loading is the reservoir pool above the spillway crest, evaluated at stages from the spillway crest to the top of dam.

[Event Trees](./344-event-trees.mdx) describes the parts of the page that every failure mode page shares.

The user opens the page by selecting a PFM-17 location on the Failure Mode Evaluation page (see [Opening a location](./341-locations.mdx#opening-a-location)).

Inputs on this page save automatically (see [Saving](./040-working-in-dst.mdx#saving)), and the results recalculate automatically when an input changes (see
[Automatic Calculation](./040-working-in-dst.mdx#automatic-calculation)). Any change on the page clears the location's verification (see
[Verifying a location](./342-failure-mode-pages.mdx#verifying-a-location)). In Event tree mode, DST refuses to verify a location that has no system response yet, with
the message "The event tree has no system response yet. Complete every node's probabilities and resolve the errors on this page, then verify."

Each location of PFM-17 has its own stages, node probabilities and results. PFM-17 has no limit on the number of
locations, and a copied location keeps the stages, node probabilities and rationales of the location it copies
(see [Locations](./341-locations.mdx) and [Copying a location](./341-locations.mdx#copying-a-location)).

## Stages to Evaluate

The **Stages to evaluate** section lists the pool elevations at which DST evaluates the PFM-17 event tree, lowest first. PFM-17 has
three default stages, which DST places from other pages. <TableReference tableKey="dst-users-guide-table-pfm-17-default-stages" /> lists them with the
text of their **Source** column. The user cannot edit a default stage's elevation on this page. When its source is missing, the stage's elevation reads
"Source missing" and the page messages name the input to complete (see [Page Messages](#page-messages)).

## User-Defined SRP

With **User defined** selected in the toolbar, the page replaces Stages to evaluate, Event tree evaluation and System Response with a table of
**Pool Elevation (ft)** and **Probability** pairs and its chart, and the entered curve becomes the location's SRP. DST keeps the stages, node
probabilities and rationales, and shows them again when the user selects **Event tree** (see [User-defined SRP](./343-system-response.mdx#user-defined-srp)).
