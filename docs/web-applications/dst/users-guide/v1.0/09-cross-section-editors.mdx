# Cross-Section Editors

The cross-section editors define the geometry of each embankment and concrete cross section listed on the Dam Information page. The embankment
editor draws the zones of an earth or rockfill section and its seepage berm; the concrete editor draws the outline of a concrete monolith, or the
weir and pier of a gated overflow section, with its gate, drain and applied forces. Both editors share the same drawing canvas, the same reference
image tools and the same Save and Cancel controls. The failure mode pages read each section's geometry, materials and derived crest, toe and slope
measures from what the user saves here.

This chapter describes the editors and the gestures used on their canvas. The list of cross sections, and the card each section has on the Dam
Information page, are described in [Chapter 8, Dam Information](./08-dam-information.mdx#cross-sections). Named cross sections have no editor.

## Opening an Editor

Selecting the drawing on an embankment or concrete cross section's card opens its editor over the Dam Information page. A section added with
**Add Earth Section** or **Add Concrete Section** opens its editor at once. The editor fills the screen: its title bar holds the section's name and
status, the canvas takes the left side and a panel of the section's properties takes the right.

- **Name.** The section's name, or "Unnamed cross section" when it has none. **Edit name** (the pencil) or a double-click on the name makes it
  editable; Enter or leaving the box keeps the new name, and Escape restores the previous one. A name holds up to 200 characters. The name saves at
  once, without Save.
- **Issue chip.** A pill such as **3 issues** that counts the section's messages. It is red when any of them is an error and amber otherwise, and it
  disappears when the section has no messages. Selecting it lists every message, errors first. DST checks the drawing again after each completed
  gesture, so the chip updates as the user works.
- **Status.** **Unsaved changes**, with an amber dot, while the section holds edits not yet saved. The same place shows an edit DST refused and the
  editing conflict notice described in [Saving and Canceling](#saving-and-canceling).

The × at the top right, Escape, or a selection outside the editor closes it. Users who cannot edit the screening, and every user while its inputs are
locked (see [Input Lock](./04-working-in-dst.mdx#input-lock)), open the editors read-only: they can view the drawing, select points and read their
coordinates, but the tools, panels and Save are unavailable.

## Saving and Canceling

The cross-section editors are the one place in DST where edits wait for the user to save them. Every change to a section's geometry and its
settings in the editor, such as points, zones and their materials, the seepage berm, the foundation, the concrete section type, the gate, the drain
and the forces, stays in the editor until the user selects **Save**. Two things save at once instead: the section's name and its reference image (see
[Reference Images](#reference-images)).

**Save** and **Cancel** appear at the right end of the toolbar above the canvas as soon as the section has unsaved changes:

- **Save** stores the section. While the save is in progress the button shows a spinner.
- **Cancel** ("Discard the changes since the last save") returns the section to its last saved state.

Saving a section clears the verification of the Dam Information page (see [Human Verification](./04-working-in-dst.mdx#human-verification)). When
the change makes the results of a failure mode page out of date, DST clears those results and says so in a notice (see
[Automatic Calculation](./04-working-in-dst.mdx#automatic-calculation)).

When another user saves Dam Information while the editor is open, the status reads "Dam Information changed in another session. Your drawing is
kept — Save applies it to the latest version; Cancel discards it." If another user deletes the section, the editor closes with the notice "The cross
section you were editing was deleted, so its editor closed." When the editor held unsaved changes, the notice reads instead "The cross section you
were editing was deleted, so its editor closed and its unsaved changes were discarded."

### Unsaved changes

Closing an editor that holds unsaved changes opens the **Unsaved changes** dialog, which reads "This cross section has changes that have not been
saved." **Save** saves the section and closes the editor, **Discard** closes it without saving, and **Keep editing** returns to the editor. After an
editing conflict, the dialog explains instead that Save applies the drawing to the latest version and Discard drops it.

Leaving the Dam Information page with an unsaved section opens the **Unsaved Cross Section Changes** dialog: "You have unsaved cross-section edits.
If you leave this page, your changes will be lost." Its buttons are described in [Saving](./04-working-in-dst.mdx#saving).

### Starting a drawing

A section with no geometry opens with a box titled **Define the cross-section** over the empty canvas
(<FigReference figKey="dst-users-guide-fig-dam-information-section-start" />). Each card in the box is a way to start:

- **Simple embankment** ("Enter crest and slopes."), in the embankment editor only, opens the generator described in
  [Generating a simple embankment](#generating-a-simple-embankment).
- **Upload or paste a drawing** ("File or screenshot.") opens a second step, **Add a drawing**, with **Upload a file** (a PNG or JPEG image) and
  **Paste a screenshot** (from the clipboard). Ctrl+V anywhere in the editor also pastes an image while the section has none. **Back** returns to
  the first step. The image becomes the section's reference image (see [Reference Images](#reference-images)).
- **Paste coordinates** ("X, Y pairs from a table.") opens the **Import points** dialog (see [Import Points](#import-points)).
- **Blank canvas** ("Click to place points.") closes the box so that clicks on the canvas place points. In the concrete editor it also starts the
  outline of the section's main component (see [Outline tabs](#outline-tabs)).

### Moving around the canvas

The mouse wheel zooms in and out about the pointer. Dragging on empty canvas, or dragging with the middle mouse button anywhere, pans the view.
**Re-center** fits the view to the drawing. When a drawing first arrives on an empty canvas, for example from the generator or an import, DST fits
the view to it; later edits never move the view.

### Placing and moving points

Points are the corners of every zone, outline and berm. One point can belong to several zones, so a boundary shared by two zones is drawn once.

- **Placing.** With no drawing tool active, a click on empty canvas places a free point. A click on a point that already exists at the same
  coordinates selects that point instead of placing a second one.
- **Inserting on an edge.** When the pointer rests on the edge of a zone or outline, the pointer changes to a copy cursor and a faint point shows
  where it will land. A click there adds a point on the edge, shared by every zone that uses that edge.
- **Moving.** Dragging a point moves it. When the pointer comes within reach of another point while dragging, the moved point jumps onto it, and
  releasing there merges the two points into one. Escape during a drag returns the point to where it started.
- **Reading coordinates.** Resting the pointer on a point shows its coordinates, for example "X 120.00 · Y 1,050.00".

DST refuses an edit that would break the drawing, such as a move that makes two zones overlap or a deletion that leaves a zone with fewer than three
points, and shows the reason in an amber note at the top of the canvas, for example "This edit would delete 'Zone 2'. Delete the component itself if
that is the intent." A section holds at most 200 points.

### Selecting points

A click on a point selects it. Ctrl+click adds a point to the selection or removes it. Holding Shift and dragging draws a selection rectangle; the
points inside it are selected when the button is released. When two or more points are selected, a chip at the top of the canvas reads, for example,
"4 selected · 18 unselected", with a **Delete** button that deletes the selected points. Escape, or a click outside the canvas, clears the
selection.

### Point and region menus

A right-click on a point opens the point editor (<FigReference figKey="dst-users-guide-fig-dam-information-point-menu" />). On a touch screen,
pressing and holding a point for half a second opens it. The editor is headed **Point**, in some cases followed by a role the point holds, such
as **Heel**. Its **X** and **Y** boxes take exact coordinates to 0.01; a value applies when the user leaves the box or presses Enter. Below them are the
point's actions:

- **Use as upstream crest**, **Use as downstream crest**, **Use as upstream toe** and **Use as downstream toe**, in the embankment editor, for the
  roles the point is eligible for (see [Crest and toe points](#crest-and-toe-points)).
- **Add to Monolith outline** (or the Weir or Pier outline), in the concrete editor, for each outline the point is not yet part of.
- **Delete point**.

A right-click inside a zone opens a menu headed by the zone's name and its number of points, with **Select zone**, **Merge with adjacent zone** and
**Delete zone**. Inside the seepage berm the menu offers **Select berm** and **Delete berm**, and inside a concrete outline it offers **Delete
region**. Escape or a click elsewhere closes a menu. Users who cannot edit see the point's coordinates in the menu and no actions.

### Exporting points

**Export points** downloads a CSV file named for the section. The file lists the X and Y coordinates of each point in blocks, one block per zone
or outline, and states the units. With points selected, the file holds only those points.

## Reference Images

A reference image is a drawing or screenshot of the cross section placed under the canvas so the user can trace it. The image is a drafting aid: it
saves with the screening as soon as it is added or changed, never needs Save, and adding, changing or removing it does not clear the page's
verification. Each section holds at most one image. The image controls are on the **Image** tab of the editor's right panel
(<FigReference figKey="dst-users-guide-fig-dam-information-image-calibration" />).

### Adding an image

With no image, the **Image** tab shows **Reference Image**, the note "Saved with the screening", and the buttons **Upload image** and **Paste
screenshot**. The image must be a PNG or JPEG file of 10 MB or less, no more than 16,384 pixels on a side and 40,000,000 pixels in all. A file that
fails these limits is refused with a notice, such as "That image is larger than 10 MB — downscale it and try again."

Once an image is in place, the top of the tab holds these controls:

- **Show** hides or shows the image.
- **Flip** mirrors the image left to right, for a drawing with upstream on the right. It is unavailable while the image is hidden, and when the image
  is calibrated from three known points, which sets the orientation itself; its tooltip then reads "Three-point calibration sets the orientation
  automatically."
- **Replace image**, **Replace with a pasted screenshot** and **Remove image and calibration** (the icon buttons).

While a shown image is not yet calibrated, the drawing tools are unavailable, and the Body and Berm tabs read "Drawing tools are disabled until the
visible reference image is calibrated. Finish calibration on the Image tab, or hide or remove the image." Clicks on the canvas place calibration
marks instead of points.

**Calibrate by** chooses the calibration method: **Scale + datum** or **Known points**. DST keeps the entries of both methods. A line of guidance
under the choice names the next step, for example "Start with Level — mark two points along something horizontal (base, water line, crest).", and
reads "Calibrated — …" when calibration is complete. Each step has a **Place** button, which becomes **Move** once the mark is placed; while a step
waits for a click on the image, its button reads **Cancel**, and a note over the canvas says what to click. After each mark the panel moves on to the
next step. Escape pauses calibration.

The datum points fix the drawing in place; the tooltips on **Datum X** and **Datum Y** note that accuracy is highest at the datum. If the two marks
of D1 sit almost directly above one another, or the two marks of D2 at almost the same height, the guidance line turns red and says so.

### Calibrating by known points

The **Known points** method uses up to three points whose coordinates can be read off the drawing, labeled **A**, **B** and **C**. For each, the
user places the mark on the image and enters its **X** and **Y**. Two points, A and B, calibrate the image; the guidance then reads "Calibrated
from A and B. Add C to correct skew or stretch, or start tracing." A third point, C, corrects skew and stretch as well.

### Body tab

The **Body** tab lists the section's zones under **Zones**. Each row shows the zone's color swatch, which matches its fill on the canvas, its name,
and its material, or **Unassigned** in amber. Selecting a row or a zone on the canvas selects the zone and shows **Selected Zone Name**, **Selected
Zone Material** and **Delete selected zone** ("Remove the zone — its points stay in the drawing"). With no zones, the tab reads "No zones yet. Place
points on the canvas, then connect them with Draw zone in the toolbar."

### Drawing, splitting and merging zones

The Body tab's toolbar holds three tools. Selecting an active tool again, or pressing Escape, cancels it.

- **Draw zone** ("Draw a zone outline — click points in order, click the first point to close"). The button reads **Drawing** while active. The user
  clicks the zone's corners in order; a click on an existing point uses that point. A click on the first point, or Enter after three or more
  points, closes the zone, and Backspace removes the last point. A zone drawn over existing zones is cut out of them. When the zone closes, the right
  panel shows a **New zone** card that says how the new zone affects existing zones, for example "The new zone is cut out of 2 existing zones.", with
  **Zone Name** and **Material** boxes and the buttons **Cancel**, **Skip assignment** (adds the zone without a name or material) and **Apply
  zone**.
- **Split** ("Cut zones in two along a line drawn between boundary points"), available once a zone exists. The user starts the cut on a zone
  boundary, adds any corner points, and ends on a boundary; Enter ends the cut after two or more points. The **Split** card reads, for example, "1
  zone will be split into 2 zones. Names and material assignments are inherited.", with **Cancel** and **Apply split**.
- **Merge** ("Combine two zones that share an edge"), available once a zone is selected. The user selects a zone, then **Merge**, then the adjacent
  zone. The two must share a full edge. The **Merge** card lists both zones, and the user chooses the one that keeps its name and material, then
  selects **Apply merge** or **Cancel**.

While a tool is active, a note at the top of the canvas describes the next click, for example "Click points in order; click the first point to close
the zone". A drawing holds at most 20 zones and berms.

### Berm tab

The **Berm** tab holds the seepage berm, a separate component downstream of the embankment toe. Its toolbar shows **Draw berm**, or **Redraw berm**
once a berm exists, and **Delete berm**. The berm is drawn the same way as a zone. When it closes, the **Seepage berm** card reads "The body zones
are unchanged. Assign one main embankment material to the berm.", with **Berm Material**, **Cancel**, **Skip assignment** and **Apply berm**.

The tab shows **Berm Material** for an existing berm, or "No berm yet — use Draw berm in the canvas toolbar." Under **Derived berm measures** it
shows the read-only **Berm Length** and **Berm Toe Elevation** that DST measures from the drawing.

### Crest and toe points

DST finds the upstream and downstream crest points and toe points of the embankment from its outline and marks them on the canvas as **US Crest**,
**DS Crest**, **US Toe** and **DS Toe**. When DST cannot tell which point is which, the section shows the warning "The crest or toe boundary is
ambiguous — review the resolved semantic points." The user fixes a role by opening the point editor on the right point and selecting, for example,
**Use as upstream crest**. Only points eligible for a role offer it.

### Generating a simple embankment

**Simple embankment** on an empty canvas opens the **Generate embankment drawing** dialog
(<FigReference figKey="dst-users-guide-fig-dam-information-embankment-generator" />), which builds a starting drawing from the crest and the face
slopes. **Homogeneous** builds a single zone; **Zoned** adds a core and enables the **Core** tab ("Choose Zoned to add a core."). A preview at the

### Section type

**Section Type** sets the kind of concrete section: **Overflow (Gated)**, **Overflow (Ungated)** or **Non-Overflow**. An ungated overflow or
non-overflow section has one outline, the **Monolith**, and the tabs **Monolith**, **Drain**, **Forces** and **Image**. A gated overflow section has
two outlines, the **Weir** and the **Pier**, and the tabs **Weir**, **Pier**, **Gate**, **Drain**, **Forces** and **Image**. Changing the section type
keeps the section's points and other entries: leaving the gated type turns the weir back into a monolith and keeps the pier and gate entries in case
the user returns to it. The section card on the Dam Information page names the type, for example **Concrete Non-Overflow**.

### Outline tabs

The **Monolith**, **Weir** and **Pier** tabs each define one outline. The tab shows the outline's status, its number of points or **Not defined**, and
these controls:

- **Define by clicking**, or **Redefine by clicking** once the outline exists, starts the outline. The user clicks its corners in order; a click on
  empty canvas places a new point and a click on a point uses it. A click on the first point closes the outline, as does **Finish region** after three
  or more points. Backspace undoes the last point, and Escape or **Cancel** stops without changing the outline. The note over the canvas repeats these
  rules.
- The trash icon ("Delete region (points are kept)") deletes the outline and leaves its points on the canvas.
- **Width, into page** is the width of the component measured along the dam axis.
- **Upstream end of crest** and **Downstream end of crest**, on the Monolith and Weir tabs, show the coordinates of the points that bound the crest.
  **Pick** (or **Change**) waits for a click on a point of the outline, and × clears the choice.

The tab also reads "Edit the outline on the canvas — drag points to move them, right-click a point to type exact coordinates or delete it, click an
edge to add a point on it." DST marks the **Heel**, **Toe** and crest points on the canvas. The base of the section must be flat: the heel and toe
must share one elevation, with no base point between them above it.

### Gate tab

The **Gate** tab, on a gated overflow section, defines the **Tainter Gate**. Its heading's tooltip explains that the gate face is drawn as a circular
arc about the trunnion between the sill-contact and top-of-gate elevations. **Trunnion** shows the trunnion point's coordinates; **Place trunnion**
(or **Move trunnion**) waits for a click on the canvas, which places a new point or uses an existing one, and **Cancel placement** stops.

### Drain tab

The **Drain** tab defines an optional drain, at most one per cross section. **Top** and **Bottom** each show a point's coordinates with a **Place**
(or **Move**) button that waits for a click on the canvas. **Clear drain** removes the drain.

### Forces tab

The **Forces** tab lists optional applied forces. **Add force** adds a row, numbered **F1**, **F2** and so on. In each row the crosshair button
waits for a click on the canvas at the force's application point, on or off the structure; a click on a point uses it. The row then shows the
point's coordinates. The trash icon (**Remove force**) removes the force; while a point is being placed, × (**Cancel placing**) stops
placing it. A section holds at most 100 forces. With no forces, the tab explains these steps.

## Import Points

The **Import points** dialog adds points from a block of coordinates copied from a spreadsheet, a CSV file or any two-column text
(<FigReference figKey="dst-users-guide-fig-dam-information-import-points" />). It opens from **Paste coordinates** on an empty canvas or from the
**Import points** button on the canvas.

The user pastes the block into **Pasted coordinates**: two values per line, X then Y, separated by a tab, a comma or spaces. A header row is skipped,
blank lines and lines beginning with # are ignored, and coordinates are rounded to 0.01. A pasted point at the coordinates of an existing point uses
that point instead of adding a second one. DST lists each line it cannot read under "N issues found", for example "Line 4: expected two values (X and
Y), found 3.", and **Import** stays unavailable until every line reads. The section must still hold no more than 200 points after the import.

- **In the embankment editor**, the dialog reads, for example, "12 points will be imported." The imported points are free points; the user then
  draws zones through them with **Draw zone**.
- **In the concrete editor**, the dialog adds two choices. **Connect as** is **None — just add points** or an outline, such as **Monolith outline**,
  and connects the points in paste order; a closing point repeated at the end is folded into the outline. When that outline already exists, a note
  explains that the import replaces its point order and keeps its points. **Replace all existing points** removes every existing point first, and
  everything that refers to those points. A **Summary** lists the **Rows**, the **New points**, the **Matched existing points (reused)** and, when
  connecting, the number of vertices in the outline. "Too many points" appears when the import would exceed 200 points.

**Import** adds the points and closes the dialog; the import, like any other edit, waits for **Save**. Closing the dialog without **Import** adds
nothing.
