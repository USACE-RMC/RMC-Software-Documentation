# PFM-04: CLE due to Poor Compaction within the Core

Potential failure mode 04 (PFM-04) evaluates concentrated leak erosion (CLE) along a flaw left in the core by poor compaction, or along a path where
leakage through the embankment has been observed. The loading is the reservoir pool, and the page plots the system response against headwater
elevation. [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#the-failure-mode-page) describes the parts of the page that every failure mode page shares.

The user opens a PFM-04 location from **Response > Failure Mode Evaluation**. The page heading reads **04 - CLE due to Poor Compaction within the
Core**. <FigReference figKey="dst-users-guide-fig-pfm-04-page" /> shows the page, and
<TableReference tableKey="dst-users-guide-table-pfm-04-regions" /> describes each numbered region.

## Core Flaw and Seepage Pathway

The **Core flaw and seepage pathway** section characterizes the flaw in the core and the path erosion would follow through the embankment. DST
places the flaw from the screening answers and the cross section: at the observed leakage elevation when leakage through the embankment has been
observed, and otherwise one third of the way from normal pool to the crest. <TableReference tableKey="dst-users-guide-table-pfm-04-inputs" />
describes the inputs.

The revert button beside the initiation material ("Revert to the most erodible material") restores the default; a different material is an override
with a justification (see [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#characterization)). The section's inputs save automatically (see [Chapter 4, Working in DST](./04-working-in-dst.mdx#saving)).

### Readings

The readings show the values DST derives, or a dash until the system response has been calculated: **Core compaction** (Well compacted, Poorly
compacted, Very poorly compacted or Unknown, from Failure Mode Screening question 4, with a link to step 4), **Height** and **Width-to-height ratio** (the base
width up to the first drain or filter, divided by the embankment height; both shown only when leakage is not observed), **Base of flaw elevation**
and **Seepage path length**.

### Pathway figure

The drawing shows the selected cross section to scale, with a legend of its materials and the pathway along the flaw. The pathway is read from the
drawing on the Dam Information page: DST cuts the section at the flaw elevation and follows the cut downstream from the upstream face. Where the cut
meets a drain or filter zone the pathway stops there, and the seepage path length is the distance to that filter; otherwise the pathway spans the
full width of the embankment. Changing the drawing changes the pathway.

### Node assumption cards

Below the drawing, one card per node states how DST treats it at this location: **Flaw** (when leakage is observed, the flaw is assigned a
probability of 1), **Initiation**, **Filter compatibility**, **Roof support**, and, when they reduce the probability, **Flow limitation** and
**Crack filling**.

### Advanced initiation overrides

The collapsed **Advanced initiation overrides** section holds two initiation parameters. Its description reads "Screening defaults come from the
governing initiation material and stay locked until a site-specific distribution is chosen."

For each parameter, the **Distribution** drop-down offers the default, labeled for example **Default (Triangular)**, and **Deterministic**,
**Uniform**, **Triangular** and **PERT**. The minimum must
be greater than zero and less than the maximum, and for Triangular and PERT the most likely value must lie between them. The section works as
described in [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#parameter-overrides).

Changing any input in this section recalculates the system response (see
[Chapter 4, Working in DST](./04-working-in-dst.mdx#automatic-calculation)) and clears the location's verification (see
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#verifying-a-location)).

## User-Defined SRP

With **User Defined SRP** selected, the page replaces its sections with a table of **Headwater Elevation (ft)** and **Probability** and its chart.
The table works as described in [Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#user-defined-srp).

## Failure Mode Summary

The **Failure mode summary** tray lists the screening answers this location reads that were answered Unknown, the overrides and the nodal revisions (see
[Chapter 11, Failure Mode Evaluation](./11-failure-mode-evaluation.mdx#failure-mode-summary)). For PFM-04, an Unknown embankment compaction is
treated as between bulldozer compaction and no formal compaction, and an Unknown embankment leakage is treated as not observed.
