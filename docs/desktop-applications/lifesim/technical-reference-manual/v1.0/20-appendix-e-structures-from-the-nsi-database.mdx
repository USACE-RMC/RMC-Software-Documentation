# Appendix E - Structures from the NSI Database

All National Structure Inventory (NSI) technical documentation and references are available 
from the U.S. Army Corps of Engineers (USACE) Hydrologic Engineering 
Center (HEC) <a href="https://www.hec.usace.army.mil/confluence/nsi/technicalreferences/latest" target="_blank" rel="noopener noreferrer">NSI Technical References</a> webpage <Citation citationKey="NSItechdoc2026" />.

<a href="https://www.hec.usace.army.mil/confluence/nsi/technicalreferences/latest/release-notes" target="_blank" rel="noopener noreferrer">Release Notes</a> for the NSI 2026 update
document the major changes from the NSI 2022 base dataset.

## Purpose

The NSI is a collection of point-based structure inventories used to support natural and technological hazard consequence analysis. 
The NSI provides consistent structure locations and attribution, including occupancy type, square footage, foundation characteristics, population estimates, and 
economic value estimates. Flood risk analysis is the primary use case, but the data structure also supports consequence analysis for other natural and man-made hazards.

The 2026 base dataset is a nationally consistent modeled 
inventory. It is intended to provide a practical starting point for consequence analysis where more detailed local inventories are unavailable, too costly to produce,
or infeasible within study time constraints.

## Background

The NSI base layer was created and is maintained by USACE. It was originally developed to simplify 
geospatial preprocessing for consequence modeling, but it has since been used in a variety of USACE, Federal Emergency Management Agency (FEMA), and interagency applications.

The NSI includes point locations for structures and a standardized set of attributes required by hazard consequence models. These attributes are exposed through
downloadable datasets and a RESTful API. The standardized schema allows analysts and software tools to work with inventories from different locations and sources 
using a common set of fields.

## Accessing the NSI

Data from the NSI can not only locate structures, but also populate structures with the attributes included 
in a structure inventory. The NSI dataset is separate from the LifeSim program but can 
be <Link to="/docs/desktop-applications/lifesim/users-guide/v1.0/structure-inventories#import-from-national-structure-inventory-nsi">imported directly in LifeSim</Link> as 
a sole source or to 
supplement a user-defined inventory. 

The NSI is available in GeoPackage, GeoParquet, and GeoJSON formats. State-level GeoPackage and GeoParquet files can be downloaded from 
the <a href="https://nsi.sec.usace.army.mil/downloads/" target="_blank" rel="noopener noreferrer">NSI Download Tool</a>. GeoJSON 
files can be requested for individual counties or user-specified bounding boxes through the NSI API.

## Data

### Attribute Fields

The NSI API uses a standardized set of public fields to describe each structure record. These fields support common consequence modeling workflows, 
including structure damage estimation, life safety analysis, population exposure, and economic loss estimation.

Datasets added to the NSI must conform to the required schema. When values are not directly observed, analysts are responsible for providing
reasonable estimates and documenting the assumptions used to populate those fields. At present, the publicly available NSI Base layer is maintained 
by the NSI development team. Future upload functionality is expected to allow additional inventories to be added using the same 
schema. <TableReference tableKey="table-NSI-fields" /> lists the public fields currently exposed in the NSI Base schema.

Private fields restricted to Federal users and mission partners may be found at 
the <a href="https://www.hec.usace.army.mil/confluence/nsi/technicalreferences/latest/technical-documentation#id-.TechnicalDocumentationv2026-PrivateFields" target="_blank" rel="noopener noreferrer">NSI Technical References</a> webpage.

### Occupancy Types

Source categories are mapped to NSI occupancy types, which are broadly consistent with FEMA Hazus occupancy classifications and USACE consequence 
modeling needs. Residential occupancy types are further refined during processing based on estimated housing units, number of stories, and basement 
status. For example, a single-family residential structure is assigned a RES1 subtype that reflects stories and basement condition.

Content values are estimated by multiplying depreciated structure value by an occupancy-specific content-to-structure value ratio. 
These ratios are shown <TableReference tableKey="table-occ-types-2026" />. Applying the ratio to depreciated structure value implicitly 
assumes a similar degree of depreciation for contents.

The content-to-structure value ratios are based on averages from studies that include expert elicitation, survey data, and claims data. Ratios 
tend to be higher for occupancy types with specialized equipment or relatively low structure costs. For RES1 structures, the NSI uses a ratio of 0.5. 
This differs from the 1.0 ratio assumed 
in USACE <a href="https://planning.erdc.dren.mil/toolbox/library/EGMs/egm04-01.pdf" target="_blank" rel="noopener noreferrer">Economic Guidance 
Memorandum (EGM) 04-01</a>. Users 
applying EGM damage functions calibrated to structure value should use the EGM ratio. 
For most other applications, the NSI ratio is intended to better approximate typical content value.

occupancy type</Link> in LifeSim.

### Structure Values

The NSI provides both full, non-depreciated, replacement value and depreciated replacement value. These values represent the estimated cost to 
rebuild the structure and may differ significantly from market value. NSI values exclude land value and do not account for market conditions such 
as demand or location desirability.

USACE analyses typically use depreciated replacement values, while FEMA Hazus applications often use full replacement values.
