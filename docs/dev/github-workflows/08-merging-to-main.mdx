## Merge Process

**GitHub web interface (recommended):**

<ProcessList
  items={[
    { title: 'Click "Merge"' },
    { title: 'Edit the commit message to be clear and descriptive' },
    { title: 'Confirm merge' },
    { title: 'Delete the source branch automatically (check the box)' },
  ]}
  numberStyle="plain"

Use the repository's protected pull-request merge control. Do not bypass it by pushing a local merge to `main`.

## Post-Merge

**Immediately after merging:**

<ProcessList
  items={[
    { title: 'Delete the feature branch (automated via GitHub)' },
    { title: 'Verify main branch builds successfully' },
    { title: 'Monitor for any issues in deployed environments' },
    { title: 'Close any linked issues if not automatically closed' },
  ]}
  numberStyle="plain"
/>

For the RMC Software Documentation repository, only administrators merge to `main`. Conversation replies and thread resolution are not mandatory gates. A successful merge starts the automatic `main` production build, which still requires administrator environment approval.
