reportAbstract: Technical reference documenting the Backward Erosion Piping (BEP) screening model in the System Response library. The model computes a system response probability (SRP) for backward erosion piping at each headwater level using a seven-node event tree. The probability of a continuous foundation flaw is estimated by Bayesian updating of a geology-based prior with subsurface and seepage-observation evidence. Unfiltered-exit and initiation probabilities are computed from blanket theory with a companion defect-survival model for the downstream confining layer, and progression is evaluated with the Schmertmann critical-gradient method. The model applies screening-level simplifications appropriate for the Dam Screening Tool.
